# `C_QT` と `Cp/Cq/Cr` の同定 — 既存ログで出せる上界と、最小工数の実験計画

- **対象**: F1404 Kv2900 + GEMFAN-3630-3、`nmpc_params.hpp` の `CQ / Cp / Cq / Cr`
- **前提**: [`20260905_damping_unidentifiable_flight_logs.md`](ai/decisions/20260905_damping_unidentifiable_flight_logs.md)（飛行ログからの回帰は失敗済み）、
  [`20260904_cq_estimated_from_bench.md`](ai/decisions/20260904_cq_estimated_from_bench.md)（`CQ` は 2 経路で推定済み）

---

## 0. ★ まず、追加実験ゼロで分かること

**`Cr ≤ 2.1×10⁻⁴`。既存の `0904_100Hz_v3.csv` だけから厳密に言える。**

モデルの恒等式

```
Cr·r|r| = tau_z − (Iy−Ix)·p·q − Iz·rdot
```

の右辺は全部ログにある（`tau_z` は指令 duty → 実測推力曲線 → `C_QT Σ s_i T(u_i)`）。よって

```
Cr ≤ ( |tau_z| + |gyro| + Iz·|rdot| ) / r²
```

が**どの時刻でも**成り立つ。接触トルクが入る接地後（`t = 19.15 s`）とフェイルセーフ後を除いた
`t < 18.90 s` の 1890 点で、いちばん厳しい点を取ると:

| `C_QT` の仮定 | `Ix,Iy,Iz` | **`Cr` 上界** | 時刻 | その時の `r` |
|---|---|---|---|---|
| 推定値 0.01113 | params 1.8/1.9/3.0e-3 | **2.10×10⁻⁴** | 18.42 s | 220 deg/s |
| 推定値 0.01113 | REPORT 6.1/6.5/11.6e-3 | **2.10×10⁻⁴** | 18.42 s | 220 deg/s |
| ×3.4 = 0.0378（最悪ケース） | params | 5.95×10⁻⁴ | 18.89 s | 257 deg/s |
| ×3.4 = 0.0378（最悪ケース） | REPORT | 7.14×10⁻⁴ | 18.42 s | 220 deg/s |

**慣性モーメントの 3.9 倍の不確かさにも、`C_QT` の 3.4 倍の不確かさにも、上界はほとんど動かない。**

### `nmpc_params.hpp` の `Cr = 0.005` は物理的にありえない

`Cr = 0.005` が正しいとすると、減衰トルクはモータの最大ヨートルクに対して

| `r` | `Cr·r\|r\|` | D90S の最大ヨートルク比 | GEMFAN の最大ヨートルク比 |
|---|---|---|---|
| 57 deg/s | 0.00495 Nm | 24 % | 18 % |
| 150 deg/s | 0.03427 Nm | **165 %** | **122 %** |
| 259 deg/s | 0.10535 Nm | **507 %** | **375 %** |

**150 deg/s で既に全開のヨートルクを超える。**つまり機体は 150 deg/s より速く回れないはずだが、
`0904_100Hz_v3.csv` では**接地前に 259 deg/s まで回っている**。`Cr = 0.005` は 2 桁大きい。

### これは前回の結論を反転させる

前回の評価（[`20260905_relaxed_hover_eval_cr_decides.md`](ai/decisions/20260905_relaxed_hover_eval_cr_decides.md)）では
公称値 `Cr = 0.005` を使って「relaxed hover の利得はゼロ」と書いた。
**上界 2.1×10⁻⁴ はその境目（約 1.1×10⁻³）の 5 分の 1 で、成立側にある。**

`(Cp=Cq) × Cr` の 2 次元掃引（GEMFAN duty 0.95, m = 350 g。値は `最良 rho [%] / そのときの Omega [deg/s]`）:

| `Cp=Cq` \ `Cr` | 1e-4 | 3e-4 | 1e-3 | 3e-3 | 1e-2 |
|---|---|---|---|---|---|
| 0.005 | **+9.7 / 610** | −2.1 / 0 | −2.1 / 0 | −2.1 / 0 | −2.1 / 0 |
| 0.025 | **+14.9 / 550** | **+11.7 / 320** | +1.0 / 220 | −2.1 / 0 | −2.1 / 0 |
| 0.050 | **+16.0 / 530** | **+14.1 / 300** | +8.6 / 190 | −2.1 / 0 | −2.1 / 0 |
| 0.100 | **+15.1 / 550** | **+14.8 / 310** | +12.3 / 180 | +3.7 / 120 | −2.1 / 0 |

⚠ ただし**成立する平衡はどれも `Omega = 300〜610 deg/s` を要求する**。
現行フェイルセーフの角速度しきい値 300 deg/s と正面衝突する。**成功した瞬間に止められる。**
`Cr` が小さいほど必要 `Omega` は上がるので、これは「`Cr` が小さくて嬉しい」だけの話ではない。

**したがって次の一手は「`Cr` を実測して上界を点推定に変えること」。**

## 2. ★ 試験 A — ヨー軸吊り試験（最優先・追加ハードは釣り用スイベル 1 個）

### なぜこれが最初か

- **go/no-go を決めるのは `Cr` だけ**（§0 の表）。`Cr` が大きければ `Cp/Cq` を測る必要すらない。
- **ファームが使う量がそのまま出る。** `nmpc_model.cpp` のヨー行は
  `Bu(4) = kS·C_QT·T_max/Iz`、減衰は `−Cr·r|r|/Iz` で、**どちらも `Iz` との比**。
  この試験は比を直接測るので、**`Iz` の 3.9 倍の不確かさを通らずにヨー軸を正しくできる。**
- 1 軸拘束なので `p = q = 0`、ジャイロ結合項が消えて回帰が素直になる。

### 治具

**機体を上下逆さに吊る。** プロペラが下向きになるので推力が糸を張る方向に働き、
**ホバー以上の回転数でも糸が緩まない。** 正立で吊ると推力がホバーを超えた瞬間に糸が緩んで暴れる。

- 糸と機体の間に **釣り用スイベル**を入れる。糸のねじり戻りトルクを消すため。これが無いと復元トルクが混じる。
- 床から十分離す（地面効果と再循環を避ける）。
- ヨー軸（機体 z 軸）が鉛直、重心が糸の直下になるよう吊る。

### 加振の作り方（ここが肝）

**全 6 発を common duty `u0` に置き、`u_i = u0 + s_i·Delta`（`s = [−1,+1,+1,−1,−1,+1]`）を与える。**

`Sum s_i = 0` なので**合計推力は変わらず、純粋なヨートルクだけが出る**。吊りが安定したまま加振できる。

```
tau_z = C_QT · Sum s_i·T(u0 + s_i·Delta)  ~  6·C_QT·T'(u0)·Delta
```

GEMFAN の設計値:

| `u0` | 6 発合計 | `T'(u0)` | `Delta` | `tau_z` |
|---|---|---|---|---|
| 0.45 | 2.84 N (289 g) | 0.849 N/duty | 0.02 | 0.00113 Nm |
| 0.45 | 〃 | 〃 | 0.05 | 0.00283 Nm |
| 0.60 | 3.57 N (364 g) | 0.781 N/duty | 0.02 | 0.00104 Nm |
| 0.60 | 〃 | 〃 | 0.05 | 0.00261 Nm |

### 手順（1 本の記録に全部入れる）

1. **全 6 発 common duty `u0` のみ**（ヨートルクゼロ）。数秒静止させて `tau_bias` とオフセットを見る。
2. **`Delta` をステップで入れる。** `r = 0` の瞬間は**減衰項も `(Iy−Ix)pq` も厳密にゼロ**なので

   ```
   rdot(0) = tau_z / Iz        →  C_QT/Iz が減衰モデルなしで直接出る
   ```

   立ち上がり 0.3 s の傾きを使う。この時点での減衰の寄与は `Cr = 2e-4` なら **0.5〜1.0 %** で無視できる。
   （`Iz = 3.0e-3` なら `rdot(0) ≈ 100 deg/s²`、0.3 s 後 `r ≈ 30 deg/s`。`Iz = 1.16e-2` なら 26 deg/s²）
   **ステップ応答の立ち上がり形状から、モータ一次遅れ `tau` も同時に読める。**
3. **`r` が 150〜200 deg/s に達したら `Delta` を 0 に戻す**（common duty のまま）。
   以後は自由減衰:

   ```
   Iz·rdot = −b·r − Cr·r|r|
   ```

   **減衰は `r` を広い範囲で掃くので、`b`（線形）と `Cr`（二乗）を分離できる。**
   定常状態まで回し切る必要がないので安全。
4. **`u0` を 3 水準（0.35 / 0.45 / 0.60）、`Delta` の符号も正逆両方**で繰り返す。
   減衰がロータ回転数に依存するかどうかがこれで分かる。

⚠ **定常回転まで待つ方法は勧めない。** `Delta = 0.05`, `Cr = 1e-4` だと定常 `r` が
**約 300 deg/s**（`Cr = 1e-5` なら 900 deg/s 超）になる。吊った機体をその速度で回すのは危険。
自由減衰なら同じ情報がもっと安全に取れる。

### 回帰式

```
Iz·rdot = C_QT·Sum s_i·T(u_i) − b·r − Cr·r|r| − tau_bias
```

未知数は `C_QT/Iz`, `b/Iz`, `Cr/Iz`, `tau_bias/Iz` の 4 つ。**全部 `Iz` との比で出る。**

**`b`（線形項）を必ず入れること。** ロータの面内力（H 力）は小前進比では速度に比例するので、
物理的には**低回転域の減衰は `r` に線形**である。`r|r|` だけで当てはめると、
低回転域の線形分を無理に二乗項へ押し込んで `Cr` を過大評価する。
（[`20260904_relaxed_hover_equilibrium_design.md`](ai/decisions/20260904_relaxed_hover_equilibrium_design.md) の追記も
`tau_bias + b·omega + C·omega|omega|` の形を指定している）

### 所要

治具 10 分（糸・スイベル・吊り点）+ 計測 20 分（6 本程度）+ 解析はスクリプト。

## 3. 試験 B — `CQ` の裏取り（追加作業ゼロ）

`CQ = 5.8e-9` は既に**独立な 2 経路**で推定済み（電気入力 `η·V·I/ω³` と運動量理論 `T^1.5/(√(2ρA)·FM)/ω³`）。
**試験 A のステップ 2 が 3 つ目の独立経路**になる。3 経路が揃えば十分で、
**トルク計や専用治具を作る必要はない。**

ただし試験 A が出すのは `C_QT/Iz` なので、`C_QT` 単独の値が欲しければ `Iz` が要る（§5）。
**ファームウェアに入れる分には比のままで正しい。**

⚠ `0904_100Hz_v3.csv` では実測ヨー角加速度が指令ヨートルクの 3.4 倍あった。
`C_QT` が 3 倍程度小さすぎる可能性がある。試験 A はこれを直接決着させる。

## 4. 試験 C — `Cp, Cq`（後回しでよい）

**go/no-go には不要。** §0 の表のとおり、`Cr` が 3e-4 以下なら `Cp=Cq` が 0.005 でも 0.1 でも成立する
（`rho` は +9.7 % 〜 +16.7 %）。余裕の見積もり精度が変わるだけである。

やるなら**重心を通す 1 軸ジグ**（重心を貫く棒を 2 点で支持し、その軸まわりだけ自由にする）。
軸が重心を通っていれば重力の復元トルクが出ないので、試験 A と同じ手順がそのまま使える。
機体を 90° 倒し替えてロールとピッチを取る。**半日仕事。**

## 5. 前提となるファーム側の小改造（ここが本丸）

**NMPC を通さず duty ベクトルを直接書く「ベンチ加振モード」が要る。** 現状これは無い
（`ESC_calib` は固定値を出すだけ）。`set_duty_fr()` 等は既にあるので、
common duty と差動パターンを時刻で切り替えるテーブルを回すだけの数十行で足りる。

**これが無いと、前回失敗した回帰をもう一度やることになる。**
[`20260905_damping_unidentifiable_flight_logs.md`](ai/decisions/20260905_damping_unidentifiable_flight_logs.md) の
失敗原因は 3 つ — **閉ループ共線性・50 Hz チャタリング・モータ遅れ未同定**。
開ループで duty を直接書けば、**3 つとも同時に消える**（指令 = 実出力の関係が一意になり、
チャタリングは NMPC を通らないので発生せず、遅れはステップ応答から同時に同定できる）。

100 Hz リングログはそのまま使える。

⚠ **リングバッファは 22 列で 21.8 s しか持たない。** `Iz = 1.16e-2` かつ `Cr` が小さいと
自由減衰が数十秒かかることがある。その場合は 200 deg/s → 100 deg/s の部分減衰で打ち切ってよい
（フィットには十分）。足りなければ記録列を減らす。

## 6. `Ix, Iy, Iz` の食い違い（副次だが放置できない）

| 出典 | `Ix` | `Iy` | `Iz` |
|---|---|---|---|
| `nmpc_params.hpp`（`repository_rules` 上の唯一の正） | 1.8e-3 | 1.9e-3 | 3.00e-3 |
| `NMPC_REPORT.md` | 6.10e-3 | 6.53e-3 | 1.16e-2 |

**3.4〜3.9 倍食い違っており、どちらも実測記録がない。**
`bifilar_inertia_method.md` に手順書と設計表（`L ≈ 1 m, D ≈ 0.2 m` で周期 2.6〜3.6 s）が既にあるので、
**糸 2 本とストップウォッチで 30 分**。10〜20 周期を計時して割ればよい。

- **ファームウェアには影響しない**（比しか使わないため）。試験 A だけでヨー軸は正しくなる。
- **relaxed hover の平衡計算には絶対値が要る**（ジャイロ項 `(Iz−Iy)qr` 等）。
  ただし §0 の表のとおり、**go/no-go の境目は慣性の 3.9 倍の違いでほとんど動かない。**急がなくてよい。

---

## 7. やらなくてよいこと

- **飛行ログからの回帰。** 180 条件で試して識別不能と確定済み。同じことを繰り返さない。
- **トルク計の購入。** 電流 + 推力の 2 経路と、試験 A の 3 経路目で足りる。
- **CFD や空力係数の理論計算。** 上界が既に出ているので、点推定だけが必要。
- **`Cp/Cq` を先に測ること。** `Cr` が決まるまでは、測っても判断が進まない。

## 8. 順序（推奨）

```
① ファームにベンチ加振モードを足す        （半日）
② 試験 A：ヨー吊り                        （30 分）→ C_QT/Iz, Cr/Iz, b/Iz, tau_motor
      ↓
   Cr が 1e-3 を超えた → relaxed hover は No-Go。ここで終わり。Cp/Cq は測らない。
   Cr が 3e-4 以下     → 成立側。ただし必要 Omega が 300-610 deg/s
      ↓
③ フェイルセーフのしきい値とジャイロ範囲を平衡解と対で設計し直す
④ 二線振り子で Ix/Iy/Iz を確定             （30 分）
⑤ 試験 C：Cp/Cq                            （半日）
```

⚠ ①の前に **50 Hz チャタリング**（[`20260904_duty_chatter_50hz_nullspace.md`](ai/decisions/20260904_duty_chatter_50hz_nullspace.md)）を
潰しておくと、飛行ログ側の検証にも同じ加振モードが使えるようになる。
