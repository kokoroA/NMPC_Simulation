# ヨー吊り試験：バイアス計測は「電源投入の 1 回だけ」。逆さ吊りは**アーム前に**作ること

- **日付**: 2026-09-14
- **種別**: investigation
- **対象**: `Benzen_NMPC/control.cpp`（`loop_400Hz` の `Arm_flag==1` 枝 / `failsafe_check`）、`docs/20260905_yaw_damping_experiment_protocol.md`
- **タグ**: #Cr #yaw #sysid #bench #failsafe #bias #arm #実験手順 #Pico

## 背景 / 症状

ヨー軸吊り試験（`Cr` 同定）の実施直前に次の 2 点が未定義だった。

1. 「電源投入直後のバイアス計測」は**地上固定で行うべきか、宙吊りのまま行ってよいか**
2. 地上で電源を入れてから宙吊りにして**上下逆さにひっくり返すと、姿勢フェールセーフに引っかかるか**

要領書（`20260905_yaw_damping_experiment_protocol.md`）§9 は
「加振モードでは姿勢の脱出条件（60°）を無効にする」としか書いておらず、
**バイアス計測の実施タイミングそのものが書かれていなかった。**

## 原因 / 判断根拠（すべてソース確認済み）

### (a) バイアス計測は電源投入直後の一度きりで、再アームでは走らない

`pico_copter.cpp:71` で `Arm_flag=1`（`start_wait=5` 秒のカウントダウン直後）。
`control.cpp` の `Arm_flag==1` 枝が `BiasCounter` を進めながら

| 区間 | サンプル数 @400 Hz | 実時間 | 中身 |
|---|---|---|---|
| `BiasCounter < AVERAGE(2000)` | 2000 | **5.0 s** | `Pbias/Qbias/Rbias` = `Wp/Wq/Wr` の静止平均。モータ停止 |
| `< KALMANWAIT(6000)` | 4000 | **10.0 s** | EKF を回して `Phi_bias/Theta_bias/Psi_bias` を積算 |

を実行し、終わると `Arm_flag=3`（緑の遅い点滅 = アーム待ち）へ抜ける。

**`BiasCounter` はどこでもリセットされない。** 再アーム（`Arm_flag` 3→2）は
`ekf_reinit_on_arm()` を呼ぶだけで、`Pbias/Qbias/Rbias` は**電源を切るまで固定**。

→ **ジャイロバイアスは「電源投入後 20 秒間に機体が置かれていた状態」で決まり、やり直すには電源再投入しかない。**

### (b) 誤ったバイアスはログの `r` にそのまま乗り、`Cr` を汚す

ログの列は生値ではなく差分（`control.cpp:2483`）。

```cpp
L[k++] = Wr - Rbias;   //  5 r
```

`r̃ = r + ε` のとき、回帰行列（要領書 §5-2）の 3 列目は

```
∫r̃|r̃| dt ≈ ∫r|r| dt + 2ε·∫|r| dt
```

200→90 deg/s を 10 s で掃く場合 `∫|r|dt ≈ 24 rad`、`∫r|r|dt ≈ 65` なので
**相対摂動 ≈ 0.75·ε（ε は rad/s）**。一部は `tau_f`/`b` 列に吸収されるので上限見積もりだが、

| `ε` | `Cr` 誤差（上限） |
|---|---|
| 1 deg/s | 約 1 % |
| 5 deg/s | 約 6 % |

要領書の目標精度が「10 s 掃引で 1 %」なので、**`ε ≲ 1 deg/s` を満たす必要がある。**
差分 `r(t1)−r(t0)` は定数オフセットで不変、`∫r dt` 列の誤差は `Δt` 列（`tau_f`）と完全に共線なので
そちらへ吸収される。**効くのは二乗項だけ**、というのが上式の意味。

→ **危険なのは「回転しながら電源投入すること」。** 揺れ（`p,q` のペンデュラム振動）は
ゼロ平均なので平均には効かない。効くのは**ヨー方向のゆっくりした回り**だけ。

### (c) 姿勢フェールセーフは 90°（要領書の 60° は誤り）で、しかも**アーム中しか評価されない**

```cpp
static const float FS_ATTITUDE_LIMIT = 90.0f * M_PI/180.0f;   // 要領書 §9 は 60° と書いている（誤り）
static const float FS_RATE_LIMIT     = 360.0f * M_PI/180.0f;
static const float FS_ACC_LIMIT      = 150.0f;                // ≈15 g
```

`failsafe_check()` は冒頭で `if (Arm_flag != 2) return;` している。
さらに姿勢判定だけが `Bench_mode == BENCH_OFF &&` で括られている。

| 状況 | 姿勢 90° | 角速度 360 deg/s | 過大G 15 g |
|---|---|---|---|
| `Arm_flag==3`（アーム前・緑点滅） | **評価されない** | **評価されない** | **評価されない** |
| `Arm_flag==2` かつ加振モード | 無効 | **有効** | 有効 |
| `Arm_flag==2` かつ通常飛行 | 有効 | 有効 | 有効 |

→ **アーム前にひっくり返す限り、どのフェールセーフにも触れない。**
アーム後にひっくり返す場合だけ、角速度 360 deg/s が生きているため
180° を 0.5 s で返すと平均 360 deg/s に達して `FS_RATE` がラッチする（解除は一度ディスアーム）。

## 対応

要領書へ「フェーズ −1（電源投入）」として次を追記する方針を決めた。

1. **吊り具に取り付け、上下逆さにし、完全に静止させてから電源を入れる。**
   逆さのまま電源投入してよい。むしろそれが最善（後述の g 感度も消える）。
2. 電源投入から約 20 秒（5 s カウントダウン + 15 s バイアス窓）、**機体に触れない。**
   緑の遅い点滅に変わったら完了。
3. どうしても地上で電源を入れる場合、**アーム前に、2 秒以上かけてゆっくり**反転させる。
   コスト: MEMS ジャイロの g 感度（重力ベクトルが Z 軸で 2 g 変化する）。
   典型 0.1〜0.5 deg/s/g なので `ε ≈ 0.2〜1 deg/s`、`Cr` 誤差 1 % 程度。許容範囲だが不要なリスク。
4. **どちらを選んでも、各電源サイクルの先頭で「ゼロ確認ラン」を 1 本取る。**
   アーム → LOG ON → スロットルを上げないまま 10 秒 → ログ吸い出し。
   モータ停止・静止のはずなので、この区間の `r` の平均が残留 `ε` そのもの。
   `|ε| > 1 deg/s` なら電源を入れ直す。`ε` は電源サイクル内で共通なので、
   このラン 1 本でその後の全ランを後処理で補正できる。

### 却下した案

- **加振ランの先頭に静止窓を含める**: リングバッファは `DATANUM=30` で **2176 行 = 21.8 s** しか持たず
  （`control.cpp:212-214`、ラップして直近のみ保持）、加振シーケンス自体が
  `t_spin 3 + t_step 6 + t_decay 20 = 29 s` で既に溢れている。先頭に足した静止窓は必ず上書きされて消える。
  → **別ランに分ける**（`BiasCounter` が電源サイクル内で固定である性質を逆に利用する）。
- **`BiasCounter` をリセットして再アーム毎にバイアスを取り直す**: 実験のためだけに
  アーム手順の意味を変えることになり、通常飛行の挙動まで動く。実験手順側で吸収できるので触らない。

## 次に触る人へ

- ⚠ **要領書 §9 の「姿勢の脱出条件（60°）」は誤り。実体は 90°**（`FS_ATTITUDE_LIMIT`）。
  どちらにせよ加振モードでは無効なので実害は無いが、数値を信じて設計しないこと。
- ⚠ **ピンクの 10 Hz 点滅を目視するまでスロットルに触れないこと。**
  `Bench_mode` の書き換えを忘れて通常飛行のまま逆さでアームすると、`minimum_duty=0.1` の持ち上げが生き、
  NMPC が逆さ姿勢に対して制御を始める。加振モードのガードは全部 `Bench_mode != BENCH_OFF` が前提。
- 副次的に見つけた軽微な不整合: `Phi_bias` は 4000 サンプルの和を `KALMANWAIT(6000)` で割っており、
  真の平均の 2/3 になる（`control.cpp:797-807`）。ただし地上（`common_duty < Disable_duty`）では
  `Phi_bias = Phi` が 400 Hz で毎周期上書きするため（`control.cpp:1972`）**現状は無害**。直すなら別件で。
