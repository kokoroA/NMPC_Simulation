# Benzen_NMPC を NX=5/N=14（DC6）へ戻し、実機合わせシミュで遅れ補償 DC0/DC6 を比較した

- **種別**: design（構成の巻き戻し）+ investigation
- **対象**: `Benzen_NMPC/*`（コミット `9a9cdad` のソースへ）、`program/NMPC_simulation/nmpc_simulation_stress.py`
- **タグ**: #Benzen_NMPC #NX5 #N14 #DC6 #遅れ補償 #NX8退避 #シミュ実機合わせ #推力曲線 #ホバーduty

## 判断（ユーザ指示）
- 作業コピーの NX=8/N=12 変更を破棄し、`9a9cdad`（NX=5, N=14, `delay_comp_steps=6`）へ戻した。
  NX=8 はブランチ `claude/benzen-nmpc-nx8-n12`（`8ef7b1d`、作業コピーと同一内容を確認済み）に残っている。
- 背景: ストレス版シミュで NX=8 は計算遅延 1 周期で崩れた（`20261006_stress_sim_nx8_breaks_with_one_cycle_compute_delay.md`）。
- `build_fresh` を再ビルド: text 687,704 / bss 422,776。`#params` 書式に `NX=`・`tau_act` が無い（NX=5 版）ことを ELF の文字列で確認。
- `重量-推力計算.xlsx`（ユーザの変更）と未追跡の `tests/nmpc_actuator_lag_test.cpp` は触っていない。

## シミュの実機合わせ（確認済みの値）
- NMPC 側: NX=5, N=14, Q=1000/1000/80/80/40, R_u=620, terminal ×10, ADMM ρ=1・4 反復, reset_period=100 — `nmpc_params.hpp` と同値。
- プラント: 質量 0.285 kg（誤差倍率 1.05→1.0）。推力は飛行較正曲線 `Tf(u)=0.8389(−0.2265u²+1.0525u+0.0452)` N/モータ
  （`20260916_bench_thrust_curve_overstates_flight_thrust_ftc_has_no_authority.md`）。ホバー duty 0.5499（実測 0.5506）、飛行中の平均 duty 0.548–0.555。
  NMPC モデルは実機と同じく線形 `T_max=0.75`（ホバー点のプラント傾き 0.674 → プラント/モデル ≈ 0.90）。
- 遅れ補償は実機 `nmpc_delay_predict()` を移植（直近 n 周期の出力 duty で RK2・4 分割、角度 0.35 rad / 角速度 10 rad/s で棄却）。
- 慣性の誤差倍率（Ix 1.2 / Iy 0.85 / Iz 1.1）とセンサ雑音・遅延は元シミュのまま。

## 結果（3 シード、2 m ホバー + t=8 s ロール 5°、15 s。R = 計算遅延 n 周期 + 再構築保持 3 + ジャイロバイアス）
| | DC0（補償なし） | DC6（補償あり） |
|---|---|---|
| 発散 | 0/15 | 0/15 |
| RMS φ | 0.74–1.00° | 0.87–1.01° |
| p の 2–5 Hz 帯 | base 10–16 % → R3 26–37 %、R1+効き2倍 29–40 % | **3.5–13 %**（遅延に依らない） |
| p,q ピーク | 10.7–15.8 deg/s | 7.5–10.5 deg/s |
| du の 5 Hz 超 | 13–45 % | **54–79 %**（base 64–72 %） |
| 0.95/0 張り付き | 0 % | 0 % |

- **DC6 は 2–5 Hz の振れを 1/3 程度に抑える代わりに、5 Hz 超の指令を約 2 倍に増やす。**
- ✅ DC6 base の du 5 Hz 超 64–72 % は、実機 0919_v8 巡航の 69 %（`20261006_du_above_5hz_85pct_not_reproducible_69pct.md`）とほぼ同じ。
  🔶 実機で指令の大半が 5 Hz 超だったのは DC6 の前方予測が雑音を増幅しているため、という仮説と整合する。
- 2–5 Hz の大振幅モード（前回 NX=5 で出た 30–75 deg/s）は「効き約 2 倍かつ遅延 2–3 周期」でしか出ない。今回の R2/R3 は効き 0.9 倍なので出なかった。
  これは 0910 のホスト閉ループ試験（`20260910_delay_compensation_new_solver.md`）の結論と一致する。
- **実機の墜落はこのシミュでは再現しない。** 張り付き 0 %・ホバーのみで、実機の墜落はいずれも大きな操縦入力・貨物・飽和の後に起きている。
  シミュに無いもの: 操縦入力、貨物、重心ずれ、実機並みの雑音（2–4 倍）、EKF 本体。

## 次に触る人へ

- DC6 は雑音が大きいほど 5 Hz 超の指令を増やす可能性がある（未検証）。DC の段数（4/6）と雑音の組で掃引する価値がある。
