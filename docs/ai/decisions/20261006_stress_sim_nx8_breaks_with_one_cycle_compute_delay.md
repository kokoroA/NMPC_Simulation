# ストレス版シミュ: NX=8/N=12 は「計算遅延 1 周期」だけで崩れ、NX=5 は 3 周期でも崩れない

- **日付**: 2026-10-06
- **種別**: investigation
- **対象**: `program/NMPC_simulation/nmpc_simulation_stress.py`（新規。`nmpc_simulation.py` NX=8 版の複製 + 悪条件 4 種）
- **タグ**: #NMPC_simulation #NX8 #N12 #計算遅延 #delay_comp #効き2倍 #再構築 #ジャイロバイアス #T_max #pwm_ascent #シミュと実機

## 背景
「シミュの NMPC モデルにはモータ遅れが無いのに飛ぶ。何が足りないか」を受け、実機との差（計算遅延 1〜3 周期／効き 2 倍／再構築中の指令保持 3 周期／ジャイロバイアスのドリフト）を足したストレス版を作って回した。

## 事前に判明したこと（確認済み）
- **コミット済みのシミュ（S1〜S8 検証済み）は別の機体**: `T_max=2.725 N`・`mass=0.200 kg`（ホバー duty≈0.12、T/W≈8）、`N=30, R_u=14, ADMM 1 反復, Cr=0.005`。
  実機は `T_max=0.75`・0.285–0.31 kg・ホバー duty≈0.62。「シミュで飛ぶ」はこの機体での結果。
- **NX=8 版のシミュ（作業コピー）は離陸できない**: `pwm_ascent=0.145` が旧 T_max 用のまま。上昇フェーズで落下し続け control に入らないので、
  S1〜S8 は NX=8 では一度も閉ループで回っていない（NX8 実装時の「Python サニティ PASS」は単体チェックのみ）。ストレス版は高度 2 m のホバーから始めた。
- シミュのジャイロ雑音は実機より小さい: 15 Hz 超の rms は シミュ ≈0.48 deg/s に対し 実機 0.9–1.8 deg/s（0919_v6/v8 巡航。実機側は機体応答を含む）。

## 結果（3 シード、高度 2 m ホバー + t=8 s にロール 5° ステップ、15 s）
| 条件 | NX=8 / N=12 | NX=5 / N=14（遅れ補償なし） |
|---|---|---|
| 悪条件なし | RMS φ 1.1° / θ 0.2°、張り付き 0 % | RMS φ 0.75° |
| 計算遅延 1 周期のみ | **RMS 9–28°、張り付き 46–66 %**（発散判定には至らずとも飛行不能） | — |
| 効き 2 倍のみ / 再構築保持のみ / バイアスのみ | すべて健全（RMS ≤ 1.6°） | — |
| 全部 + 遅延 1 / 2 / 3 周期 | 発散 1/3・2/3・3/3、残りも RMS 18–45°・張り付き 67–97 % | **全部健全**（RMS ≤ 2.5°）。ただし遅延 2–3 で p の 2–5 Hz 帯が 85–96 %（30–75 deg/s の 2–5 Hz 振動） |

- 不安定な条件の数値はシード間・実行間でばらつく（BLAS の加算順程度の差でカオス的に分岐）。安定な条件は完全に再現する。
- NX=8 は悪条件なしでも du の 85 % が 5 Hz 超（NX=5 は 40 %）。遅れを打ち消そうと高い帯域まで指令を出す＝遅延余裕が小さい、という解釈と整合（🔶 推測）。
- NX=5 に遅延 2–3 周期を入れると出る 2–5 Hz 振動は、実機 NX=5 で 1 か月続いた 3–5 Hz モードと同じ帯域（🔶 同一機構かは未確認）。

## 実機ログとの突き合わせ（ざっと見ただけ）
NX=8 の実機ログ 0920_v1/v4/v5 は u_base>0.45 の区間で 0/0.95 張り付き 24–68 %（NX=5 の 0919_v8 巡航は 0 %）。
ストレス版の「NX=8 + 遅延で張り付きが急増」と方向が一致する。⚠ 接地中の区間を含む可能性があり、詳細解析は未実施。

## 次に触る人へ
- 実機の計算遅延は約 1 周期（状態取得 → iter_us 8–10 ms 後に duty 書き込み）。**NX=8 は DC=0 のままではこの遅延を予測に持っていない。**
  NX8 設計 decision の「純遅延 1–2 周期だけを別途検証する」を先に試す価値が高い（ストレス版の `compute_delay_cycles` と組で評価できる）。
- 元シミュの `pwm_ascent` を直さない限り、`nmpc_simulation.py` の S1〜S8 は NX=8 で意味を持たない。
