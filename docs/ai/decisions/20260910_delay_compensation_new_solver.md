# 遅れ補償（x0 の前方予測）を実装し、現行ソルバ（定数項 c 直接計算）へ戻した

- **日付**: 2026-09-10
- **種別**: design | tuning
- **対象**: `nmpc.cpp/.hpp`(nmpc_delay_predict)、`control.cpp`(duty 履歴・x0 予測・`#delay_comp:` ヘッダ)、`nmpc_params.hpp`(delay_comp_steps=4, NMPC_LEGACY_SOLVER=0, R_u=1200, Q_p=Q_q=30, Q_r=40)
- **タグ**: #Benzen_NMPC #遅れ補償 #予測 #x0 #位相余裕 #4Hz #モータ遅れ #新ソルバ #delay_comp_steps

## 問い

「定数項 c を直接計算する現行ソルバに遅れ補償を入れれば正常に飛ぶ可能性が高いか」。

## 判断（正直に）

**可能性はあるが、「高い」とは言えない。** 根拠と限界:

- 現行ソルバの墜落（v7, v8）は、推定器・ソルバ・再構築・弁がすべて健全な状態での **3–5 Hz 遅れ限界モード**だった。
  同定した実効遅れは 40–50 ms。遅れ補償はこの機構に対する直接の対策で、方向は正しい。
- **ホストで初めて「安定側へ動く」結果が出た**（下記 B）。今日の R_u 調整（4 回）は全てホストでも実機でも
  安定限界を動かせなかったので、これは今日初めての質的な進展。
- しかし**ホストは実機の 3–5 Hz モードそのものを再現できていない**（機体 1.0–1.5× では発振しない）。
  ホストが示せるのは「遅れに対する余裕が増えた」ことまで。実機で 40–50 ms が本当に「遅れ」として
  補償可能なものか（ディザで飛べた事実が示唆する ESC/モータの小信号特性かもしれない）は飛ばないと分からない。
- 旧ソルバは 3–5 Hz を出さない代わりに零空間ディザの時限爆弾を持ち、γ で片側だけ消す試みは失敗した
  （[`20260910_v9_legacy_nullspace_growth_gamma.md`](20260910_v9_legacy_nullspace_growth_gamma.md)）。
  正しい制御器＋遅れ補償は、その袋小路を避ける唯一の筋。

## 実装

- `nmpc_delay_predict(x0, hist[n], n, dt, x_pred)`: 直近 n 周期に出した duty（古い順）で `model_f` を
  RK2・1 周期 4 分割で積分し、x0 を n 周期ぶん前方へ進める。**健全性判定**: 予測変化が角度 20°・角速度 10 rad/s を
  超えたら補償せず x0 をそのまま使う（記録状態リプレイで、墜落域を 1 周期刻みで積分すると 1e9 deg まで発散したため）。
- `control.cpp`: 出力 duty の 8 段リング `g_duty_hist`（NMPC 停止中も更新）。`x0` 組立の直後に予測を適用。
  棄却回数 `g_delay_pred_nonfinite` を `#delay_comp:` ヘッダに出す。
- `delay_comp_steps = 4`（40 ms）。0 で無効。過補償も不安定化するので同定値の下側から始める。
- ソルバは現行（`NMPC_LEGACY_SOLVER=0`）、重みは 0910_v8 と同じ `R_u=1200, Q_p=Q_q=30, Q_r=40`
  （遅れ補償の効果を単独で見るため）。旧ソルバ用の `Q_r=8` は `#if` 内に残る。

## 検証（実機ソースそのものをホストでビルド）

**(B) 閉ループ安定限界（モータ 50 ms 一次遅れ ＋ 純遅延 ＋ 雑音、ロール 5° 初期偏差）:**

| 機体効き × 純遅延 | 補償なし | 補償 4 周期 |
|---|---|---|
| 2.0× / 5 周期 | 発散傾向（rms 5.5°） | 収束（2.0°） |
| 2.0× / 7 周期 | rms 32° | 収束（2.2°） |
| 3.0× / 3 周期 | ★破綻 4.5 s | 収束 |
| 3.0× / 5 周期 | rms 35°、飽和 5% | 収束 |
| 3.0× / 7 周期 | ★破綻 5.0 s | 収束 |
| 4.0× / 3, 5, 7 周期 | ★破綻 1.7–3.6 s | 収束（最悪 rms 13°） |

補償なしで発散した 9 条件が全て収束した。

**(C) 記録状態リプレイ（履歴は実機が出した duty）:** 補償棄却 1–5 回／飛行（墜落域のみ）、正常飛行域での予測角度変化は最大 5–9°、
`nonfinite` は墜落・FAILSAFE 域のみ、`|U_lin|max` 0.7–4.6。

**(D) 静的ゲイン:** 0.335e-3 / 0.287e-3（変更なし）。`text 680496 / bss 422340`。**実機未検証。**

## 次に触る人へ
