## 1. EKF バイアス発散ガード

**機構**: `Xe(4..6)` は EKF のジャイロバイアス状態（`state_equation` で `dp,dq,dr`、`beta=0` のランダムウォーク）。
これが静止平均 `Pbias` から δ だけ流れると、姿勢出力だけが −δ でランプし、NMPC が見る `Wp−Pbias` はゼロのまま。

**検知**: 100 Hz で `d(Phi)/dt − φ̇_gyro`、`d(Theta)/dt − θ̇_gyro` を計算（オイラー角運動学
`φ̇ = p + sinφ tanθ q + cosφ tanθ r`, `θ̇ = cosφ q − sinφ r`、|θ|>60° では判定停止）、τ=0.3 s の LPF。
**|残差| > 5 deg/s が 0.2 s 連続**で `ekf_bias_reset()`（`Xe(4..6)=Xp(4..6)=Pbias,Qbias,Rbias`）。

**閾値の根拠（全 100 Hz ログでオフライン再現、同じ式）**:

| 閾値 / 連続 | 飛べていた飛行での飛行中誤発火 | 偽の傾き 2 件の検知 |
|---|---|---|
| 3 deg/s / 0.1 s | 0904_v2 ×2、0904_v4 ×5、0904_v5 ×2 | あり |
| 4 / 0.2 | 0904_v5 ×2（着陸域） | あり |
| **5 / 0.2** | **0904_v5 ×1（6.5 s、着陸バウンド域）のみ** | **0910_v2: 18.4 s（離陸 ~19.5 の 1 s 前）、0910_v5: 10.7 s（離陸 ~11.5 の 0.8 s 前）** |
| 6 / 0.2 | 0 | あり（同時刻） |

5 deg/s を採用。正常飛行の LPF 残差は 3–4 deg/s に達することがあり、3 では誤発火する。

**未検証**: 実機での発火とその後の再収束。`#ekf:` ヘッダに `bias_reset=` を出す。

## 4. （追加）線形化点を `ws.U` → `ws.z` へ

3 の重みで 0910_v4 をリプレイしたところ、墜落域で `|U_lin|` が **8599** に達し `nonfinite` が出た
（物理上限は √120×0.95 = 10.4）。`ws.U` は射影前で box に縛られない。機体を駆動しているのは `z` なので
線形化も `z` 周りが正しい。ホスト検証（新重み）:

| リプレイ | `U_lin=U` | `U_lin=z` |
|---|---|---|
| 0910_v4 \|U_lin\|max / nonfinite / λreset | 8599 / 1 / 7 | **4.25 / 0 / 3** |
| 0910_v5 | 8.34 / 0 / 4 | 4.27 / 0 / 2 |
| 0909_v2 | 19.2 / 0 / 13 | 4.57 / 0 / 6 |
| 実機 duty との平均差 | 0.020–0.027 | 0.018–0.027（同等） |

静的ゲイン・閉ループ応答は完全に同一。過去に却下した理由（[`20260909_admm_const_term_backsolve_divergence.md`](20260909_admm_const_term_backsolve_divergence.md)
「c を直接作れば不要」）は「単独では根治でない」であり、根治の上に重ねる堅牢化としては有効。

## 検証結果

- リプレイ 4 飛行: `nonfinite=0`、`|U_lin|max` ≤ 4.6、再構築 1〜1.5 回/秒。
- 検知器: 上表のとおりオフライン再現。
- `cmake --build build_fresh` 成功、`text 679384 / bss 422140`（RAM 512 KB 中 ~421 KB 使用、ヒープ 2 KB）。CRLF/LF 整合。
- **実機飛行は未検証。**
