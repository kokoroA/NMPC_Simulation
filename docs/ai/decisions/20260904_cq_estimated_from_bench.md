# CQ はベンチの電流と推力から推定できる。C_QT は 5.2 倍の過大評価だった

- **日付**: 2026-09-04
- **種別**: investigation
- **対象**: `Benzen_NMPC/nmpc_params.hpp`(CQ, C_QT), `nmpc_model.cpp`(B_c yaw), `docs/thrust_sysid_f1404.md`
- **タグ**: #Benzen_NMPC #sysid #CQ #C_QT #Ct #ヨー #反トルク #運動量理論 #フィギュアオブメリット

## 背景 / 症状

`nmpc_params.hpp` の `CQ = 3.0e-8f` には「未測定の仮値」の注記があり、
`C_QT = CQ/Ct` はヨーの操作権限（`B_c(4,k) = kS·C_QT·T_max/Iz`）を直接決める。
0904_v1 の飛行でヨーが Δu の 84.7 % を消費していたため、この値の妥当性が問われた。

**ユーザの問い**: `Ct = 5.21e-7` はどこから出た値か。`CQ = 3.0e-8` は推定できるか。

## 原因 / 判断根拠

**`Ct` の出どころ（確認済み）。**
`重量-推力計算.xlsx` シート「ヒコロボ」の `f1404 Kv2900 + GEMFAN-3630-3` 静推力ベンチ 7 点を
`T = Ct·ω²` で原点通過フィットしたもの。**Ct = 5.209e-7、R² = 0.9978。**
各点の `T/ω²` は 4.91e-7〜5.29e-7 に収まり、ばらつきは小さい。

**`CQ` は推定できる（確認済み）。** トルク計は無いが、独立な 2 経路がある。

- **経路A（電気入力）**: `CQ = η·V·I/ω³`。シートには電流が入っている（f1404 の行では列 11）。
  η=0.65 で 5.7e-9〜8.7e-9（高回転ほど小さい。**η を定数と置いた近似の限界**）。
- **経路B（運動量理論）**: `P_ideal = T^1.5/√(2ρA)`、`P_mech = P_ideal/FM`、`CQ = P_mech/ω³`。
  電気系の効率に依存しない。FM=0.55 で **5.32e-9**。
- **両経路の整合**: `P_ideal/P_elec = η×FM` は 0.20（目盛り6）→ 0.35（目盛り18）。
  小型モータ η≈0.6–0.7、小径プロペラ FM≈0.45–0.55 なら η×FM≈0.27–0.39。
  **実測はこの範囲に収まり、データは自己整合している。**

**飛行時の動作点**（ホバー 1 発 0.626 N → ω=1096 rad/s、目盛り 12–14 相当）:
経路A(η=0.65) 6.2e-9 / 経路B(FM=0.55) 5.4e-9 → **CQ ≈ 5.8e-9、C_QT ≈ 0.011 m**。

| | CQ | Ct | C_QT |
|---|---|---|---|
| 現行 | 3.0e-8（仮値） | 5.21e-7 | **0.0576** |
| 推定 | **5.8e-9** | 5.21e-7 | **0.0111** |

**`C_QT` を 5.2 倍 過大に見積もっている。**
1 発・duty 1 あたりのヨー角加速度は 1144 deg/s²（現行）に対し 221 deg/s²（推定）。

## 対応

`docs/thrust_sysid_f1404.md` に §7「CQ は推定できるか」を追記（両経路の表と整合性チェック）。
**`nmpc_params.hpp` は未変更。**

⚠ **`C_QT` を下げると、同じヨー誤差に対して制御器はより多くの duty を要求するようになる。**
0904_v1 では既にヨーが Δu の 84.7 % を食っていたので、
**先に `Psi_ref` のスケールを ±54 deg/s へ下げ（本日適用済み）、飽和が減ったことを確認してから
`CQ` を直す。** 順序を逆にすると飽和が悪化する。

**却下した案**: 経路Aだけで決める。η（モータ+ESC 効率）は負荷で変わり、
実際 CQ の推定値が高回転ほど下がっている。**経路Bと突き合わせて初めて信用できる。**

## 検証結果

- `Ct = 5.209e-7`（R²=0.9978）はベンチ 7 点からの直接フィット。**確定。**
- CQ は**推定値**。η と FM はどちらも仮定値で、両経路の一致は整合性の証拠だが
  **絶対値の保証にはならない。**
- **実機での検証は未実施。**

## 次に触る人へ

- **トルク計が無くても、電流と推力があれば反トルク係数は 2 経路で挟み込める。**
  経路A（電気入力 × 効率）と経路B（運動量理論 × FM）は独立なので、
  一致すればデータの自己整合が確認でき、一致しなければどちらかの仮定が破れている。
- **確実にしたいなら、機体を吊るしてヨー軸の応答を測るのが最短。**
  既知の duty 差動を与えて実測角加速度を取れば `C_QT·T_max/Iz` がまとめて同定でき、
  **二線振り子で推定した `Iz` の誤差も同時に吸収できる。** 追加のハードは要らない。
- `nmpc_params.hpp` の `C_QT` のコメント `// ≈ 0.03614` は `Ct=8.3e-7` 時代の値で**既に古い**。
  数値の根拠を追うときに間違える。
