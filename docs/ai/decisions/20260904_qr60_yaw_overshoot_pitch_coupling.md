# Q_r=60 はヨードリフトを改善したが、過渡飽和でピッチを崩した

- **日付**: 2026-09-04
- **種別**: investigation | tuning
- **対象**: `Benzen_NMPC/tools/0904_v7.csv`, `0904_100Hz.csv`, `nmpc_params.hpp`(Q_r)
- **タグ**: #Benzen_NMPC #飛行実験 #Q_r #ヨー #オーバーシュート #飽和 #ピッチ #100Hz

## 背景 / 症状

`Q_phi=Q_theta=150`, `Q_p=Q_q=20`, `Q_r=60`, `R_u=120` で飛行したところ、
`Q_r=20` の `0904_v6.csv` よりヨー追従は改善したが、ロール・ピッチが不安定に感じられた。

## 原因 / 判断根拠

**確認済み事実。**

- 自由飛行（`u_base>0.5`）の中立時ヨーレート平均は **+21.4 → +6.6 deg/s**、
  ヨー誤差 RMS は **32.1 → 21.9 deg/s**。`Q_r` 増加は定常ドリフトに有効だった。
- 一方で v7 の `q` RMS は **11.2 → 22.1 deg/s** と 2.0 倍になった。
  角度誤差 RMS もロール **4.30 → 5.79 deg**、ピッチ **4.93 → 5.36 deg** に悪化した。
  v7 の姿勢指令 RMS はロール 1.5 deg、ピッチ 1.1 deg と v6 より小さいため、
  操舵量が増えたことでは説明できない。
- 100 Hz ログの 16.0–17.8 s で、`psi_ref≈-20 deg/s` に対して
  `r` が逆向きに **+126 deg/s** までオーバーシュートした。その直後にモータ差動が大きく反転し、
  1 秒窓の飽和時刻率が **52–59 %**、`theta` は **−15 → +23 deg**、
  `q` は **+105 → −81 deg/s** となった。
- 全飛行平均の飽和時刻率は 16.6 % なので、平均値だけではこの局所的な権限喪失を見落とす。
- Δu の直交基底分解では v7 のヨー成分が変動エネルギーの **63.7 %**。
  高い `Q_r` が過渡時のモータ配分を支配している。
- 主な変動は 0.5–0.9 Hz。0831 の 4 Hz 高周波発振とは異なり、
  ヨーの低減衰過渡と、その飽和・実機非対称による軸間干渉として見える。
- 1 秒周期のフル再構築は約 38 ms。16.22 s の再構築はヨー最大値と重なったが、
  `r` は再構築前の 15.8–16.2 s に −14 → +110 deg/s と増加済み。
  **主因ではないが、過渡時の制御余裕をさらに悪化させる。**

**推定。**

`Q_r=60` でヨー角速度ループの減衰が不足し、モデルにないモータ遅れ・反トルク差・推力差により
ヨー過渡がオーバーシュートした。大きなヨー差動が box 制約に当たると、
実機の非対称性を介してロール・ピッチへ漏れた可能性が高い。
ログだけでは個々のモータ／プロペラ差まで切り分けられない。

## 対応

次の単独変更として **`Q_r=60 → 40`** を推奨する。`Q_phi/Q_theta/Q_p/Q_q/R_u` は固定し、
同じ ±20〜30 deg/s のヨー入力で中立ドリフト、最大 `r`、整定、1 秒窓飽和率、`q` RMS を比較する。

`Q_phi/Q_theta` の追加増加は保留する。今回のピッチ逸脱は角度重み不足ではなく、
ヨー過渡中の飽和と軸間干渉が先に起きているため。

## 検証結果

- `0904_v7.csv`（10 Hz）と `0904_100Hz.csv` の自由飛行統計はほぼ一致した。
- 100 Hz ダンプはシリアルデバッグ文字列の混入により **2033/2176 行（93.4 %）**のみ有効。
  119 箇所に欠損があるが、10 Hz ログとの一致と破綻前後の連続サンプルから主要結論は変わらない。
- `Q_r=40` は**未飛行・未検証**。

## 次に触る人へ

- 飽和率は全区間平均だけでなく、0.5〜1 秒の移動窓でも見ること。
- 「定常偏差が改善した」と「過渡追従が安定した」は別。最大値・整定・逆向きオーバーシュートを併記する。
- 100 Hz ダンプ中に受信機デバッグ出力が混ざって行欠損を作っている。次回はダンプ中の他の `printf` を止める。
