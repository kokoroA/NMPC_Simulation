# 既存飛行ログではCp/Cq/Crを識別できず、負値や0境界を採用しない

- **日付**: 2026-09-05
- **種別**: investigation | design
- **対象**: `0904_v12.csv`, `0904_v11.csv`, `0904_100Hz_v4.csv`, `Cp/Cq/Cr`
- **タグ**: #sysid #Cp #Cq #Cr #回帰 #識別不能 #50Hzチャタリング #閉ループ同定

## 判断

**確認済み事実。**

- `v12`はデータ0行。`v11`は10 Hzであり、既知の50 Hz指令duty反転がエイリアシングするため入力トルク回帰に使えない。
- `100Hz_v4`へ角運動方程式の積分形回帰を適用した。フィルタ2/3/5/8 Hz、入力遅延30/50/70/90/120 ms、積分窓100/200/500 msの60条件/軸を評価した。
- 非拘束二乗抵抗係数が正になった割合はRoll 6.7%、Pitch 36.7%、Yaw 0%。非負制約付き回帰では85.0%、95.0%、98.3%が`C=0`境界へ張り付いた。
- 推力トルク倍率中央値もRoll 0.032、Pitch 0.043、Yaw 1.306と軸間で整合しない。5分割block交差検証NRMSEは1.07/0.99/0.98で、別区間の予測性がない。
- 負値や0境界は物理係数ではなく、実モータ出力を持たない指令duty、50 Hzチャタリング、未同定モータ遅れ、閉ループ共線性を回帰が分離できない結果である。

**設計判断。**

- `nmpc_params.hpp`の`Cp=0.025, Cq=0.025, Cr=0.005`は変更しない。ただし同定済みとも扱わない。
- relaxed-hover探索では`Cp=0–0.05`, `Cq=0–0.05`, `Cr=0–0.01`を仮のストレステスト範囲として走査する。この範囲は信頼区間ではない。
- 特定のダンピング値でのみ成立する平衡を実飛行根拠にしない。
