# 定数項 c を勾配から逆算したことで線形化点が発散し、離陸数秒で墜落した

- **日付**: 2026-09-09
- **種別**: bugfix | investigation
- **対象**: `Benzen_NMPC/nmpc.cpp` `admm_solve` / `compute_gradient`、`0909_v5.csv`, `0909_100Hz_v2.csv`
- **タグ**: #ADMM #SR2 #TR1 #準ニュートン #線形化点 #U_lin #発散 #墜落 #勾配バグ #Benzen_NMPC

## 背景 / 症状

勾配修正 + `admm_max_iter=4` + `R_u=320` + 安全弁 3 段を焼いた飛行で、離陸から約 6.5 秒後に
振動して裏返った。ログヘッダで修正版の搭載を確認済み:
`#solver: lambda_reset=4 nonfinite=2 ekf_reset=0 admm_rho=1 admm_iter=4` / `R_u=320.0`。

破綻の形が特徴的だった。`t=12.25` から `12.34` までの **90 ms (9 サンプル)** で、
duty が釣り合った 0.55 付近から box の隅 `0.950/0.950/0.000/0.950/0.000/0.000` まで
単調に駆け上がった。そのときの姿勢誤差は `phi` 約 3.2°、`theta` 約 1°、角速度 60 deg/s 以下で、
**その指令を正当化する姿勢誤差が存在しない**。姿勢が壊れたのは指令が振り切れた後である。

## 原因 / 判断根拠

**確認済み事実。**

`admm_solve` は右辺に必要な定数項 `c` を、勾配から逆算して作っていた。

```
c = H*U_lin - g       （実装: admm_neg_c = M*U_lin - rho*U_lin - g）
```

この式が成り立つのは `g` が「同じ `H`」で作った勾配のときだけである。ところが本実装では

- `H`（`M` の中身）は **TR1/SR2 の準ニュートン近似**。`Su^T Q Su + R` を陽に作らないことが
  設計の前提そのもの（計算量的に禁じ手なので差分更新している）。
- `g` は `compute_gradient()` が**その時点の `Su` から作った厳密勾配** `H_exact*U_lin + c`。

したがって逆算の結果は

```
実装が使う -c  =  -(c + (H_SR2 - H_exact)·U_lin)
```

となり、**誤差が線形化点 `U_lin` に比例して増幅される**。しかも `U_lin = ws.U`（ADMM の
射影前の主変数）なので box に縛られておらず、誤差が大きいほど `U_lin` が伸び、伸びるほど
誤差が増えるという正のフィードバックになる。

**測定（記録された飛行状態をソルバへ再入力するリプレイ）。**

| 条件 | 右辺 `-c` の相対誤差 平均 / 最大 | \|U_lin\|max |
|---|---|---|
| 現行（TR1/SR2 近似 H, `reset_period=100`） | **21.5% / 740%** | **352** |
| 毎周期フル再構築で H を厳密化（`reset_period=1`） | 3.2% / 205% | 2.1 |
| `c` を定義から直接計算 | 0（構造上） | 4.59 |

`U_lin` は Δu をホライズン全段に並べたベクトルなので、物理的な上限は
`√120 × 0.95 = 10.4`。**352 はそれを 34 倍超えている。** 破綻直前の正常飛行区間
（`t=10.9-12.2`）でも右辺の誤差は瞬時 20-360% で推移していた。`|lambda| = 0` であり、
**box にも双対変数にも触れていない区間で右辺が壊れていた**。

毎周期フル再構築で誤差が 21.5% → 3.2% に落ちることが、原因を
「H と g の不整合」に確定させる（`U_lin` の大きさだけが原因なら再構築では改善しない）。

**閉ループ再現（プラント = モデル、ジャイロ雑音 0.010 rad/s = 0.57 deg/s、8 seed）。**

| 実装 | 破綻した seed | \|U_lin\|max | 姿勢 rms |
|---|---|---|---|
| 現行 | **3 / 8**（seed 1, 4, 6） | 38 / 174 / 431 | 1.9-7.0 deg |
| `c` 直接計算 | **0 / 8** | 0.022-0.036 | 1.73-1.77 deg |

雑音を 0 にすると現行実装でも破綻しない（`|U_lin|` 0.014）。**確率的にしか出ない**ため、
ホストのノイズなし試験では一度も捕まえられなかった。実機で「6.5 秒飛んでから 90 ms で
破綻」という出方をしたのはこのため。

**判断。**

`R_u` と `admm_max_iter` の問題ではない。ユーザの見立てどおり **ADMM 側の修正そのものが
間違っていた**。前回の修正は「勾配ではなく定数項を使う」という向きは正しかったが、
その定数項を**勾配から逆算**したため、TR1/SR2 という設計の中核と両立しなかった。

## 対応

`c` を定義から直接組み立てる。`U_lin` は式に現れないので増幅経路が消える。

```
c = Su^T Q̄ (Sx x0 - X_ref) - R̄ U_ref
```

副次的に **`g` が不要になった**（`scratch.g` は `admm_solve` 以外から参照されていない）。
結果として `Su * U_lin`（8,400 MAC）と `M * U_lin`（14,400 MAC）が消え、
**計算量は修正前より約 22,800 MAC 少なくなる**。実機の実測レート 1.0 ms / 14,400 MAC から
**約 1.6 ms の短縮**が見込める（未検証）。text も 678,224 → 677,784 B に減った。

`R_u = 320` と `admm_max_iter = 4` は据え置く。理由:

- 収束点では `H*U_lin - g = -c` が厳密に成り立つため、**定常の実効ゲインは変わらない**。
  姿勢誤差 8.6° に対する実効 \|Δu\| は 0.01643 で修正前後とも同値（飛べていた基準 0.01717）。
- 反復数は、`c` が正しければ 2-6 回で追従性能に差が出ない。ただし `u_hover=0.85` で
  box が張り付く条件では 3 回だと 3 seed 中 2 seed で 4 発同時飽和の過渡が出た（4 回では 0）。
  **4 を下限とする。**

**採用しなかった案。**

- `U_lin = ws.z`（射影済みの点で線形化）: `|U_lin|max` は 352 → 2.68 に収まるが、
  右辺の相対誤差は 21.4% のままで根治ではない。`c` を直接作れば不要（併用しても数値は変わらず）。
- `admm_rho` を上げて双対を安定化: そもそも `lambda = 0` の区間で壊れているので無関係。
- 毎周期フル再構築（`reset_period=1`）: 誤差は 3.2% まで落ちるが、1 周期 36 ms なので実時間で不可能。

安全弁 3 段（λ 上限 / 非有限検出 / EKF 再初期化）は残す。今回の飛行では
`lambda_reset=4, nonfinite=2` が実際に発動し、`t=12.35` と `t=12.66` の
「全 6 発が `u_base` ちょうど」= Δu=0 出力として観測できた。破綻の後始末としては機能している。

## 検証結果

- 実機と同一のソースをホストでビルドし、上表の再現・比較を実施。
- 出荷するソースそのもので 8 seed 再走: **破綻 0/8**、`|U_lin|max` 0.022-0.036、姿勢 rms 1.73-1.77 deg。
- `cmake --build build_fresh` 成功。`text 677784 / bss 352560`。CRLF 混入なし。
- **実機飛行は未検証。** `iter_us` / `loop_us` の実測も未取得。

## 次に触る人へ

- ⚠ **今回の飛行は `loop_us` 平均 10.33 ms、31.6% が 10 ms 超過**（NMPC 稼働中のみ集計）。
  修正で約 1.6 ms 戻る見込みだが、**プロペラを外して必ず実測すること**。
- ⚠ 周期フル再構築が **36-38 ms** かかる。`t=11.48 / 12.35 / 12.36 / 12.66 / 12.67` で観測。
  破綻の引き金ではないが、1 秒に 1 回 38 ms 無制御になるのは別途潰す必要がある。
- ⚠ 1 反復あたりのコストは実測 **約 1.0 ms**（`iter=2` 6.4 ms → `iter=4` 8.4 ms）。
  以前 decision に書いた 190-380 us/反復は 3-5 倍楽観的すぎた。机上見積もりを信用しないこと。
- `T_max` は `1.04f` のまま。0.81 は一度も焼かれていない。
- **教訓**: 準ニュートン近似 `H` を使う系で、`H` を含む式から別の量を逆算してはならない。
  近似は「解の探索方向」には使えるが、「等式の一方の辺」としては使えない。
