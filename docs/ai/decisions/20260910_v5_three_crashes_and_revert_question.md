# 0910_v5: 3 回の墜落は 3 つの別原因。「旧プログラムへ戻すべきか」への回答

- **日付**: 2026-09-10
- **種別**: investigation | design
- **対象**: `0910_v5.csv`, `0910_100Hz_v5.csv`、EKF（`kalman_filter` / `Phi_bias`）、`nmpc.cpp`、`nmpc_params.hpp`(R_u, Q_p)
- **タグ**: #Benzen_NMPC #EKF #姿勢推定ドリフト #接地バウンド #リプレイ #整合ゲイン #角速度ゲイン #旧プログラム #revert #4Hz

## 背景

TR1 の過大更新を捨てる修正（[`20260910_sr2_bad_c_rebuild_storm.md`](20260910_sr2_bad_c_rebuild_storm.md)）を焼いた飛行。
3 回とも離陸後に墜落。ユーザの問い: **根本原因がアクチュエータ遅れ未モデル化と gyro LPF 無しなら、
同じ条件で飛べていた 0904_v5 / 0909 のプログラムまで戻すべきか。**

## 確認済み事実

**再構築嵐は解消した。** 再構築 24 回 / 16.2 s（1.48/s、ホールド 5.4%）、`loop_us` 平均 9.5 ms・p95 9.7 ms。
`lambda_reset=5, nonfinite=1`。

**3 回の飛行は、それぞれ別の理由で落ちている。**

| 飛行 | 区間 | 推定ドリフト φ/θ [deg/s] | 何が起きたか |
|---|---|---|---|
| 1 | 0.8–6.4 | +1.48 / **+5.98** | ピッチ推定が浮上前から流れ、`t=5.5` に φ,θ −14° へ |
| 2 | 9.0–15.2 | **+4.50 / +2.70** | **接地中（9.0–11.6 s, u_base 0.16→0.53）に θ が 0→+19.5° へランプ。∫q = −0.4°、\|q\|max 4.3 deg/s。φ も 0→+7.4°（∫p +0.8°）。** 完全な偽の傾き。パイロットは θ_ref 14–22° で対抗しながら離陸し、`t=15.0` で破綻 |
| 3 | 17.0–21.2 | +0.85 / −0.61（正常） | 降下中（u_base 0.571→0.538）の `t=19.91` に **接地バウンド**: acc_norm 19.0→5.3→**1.5 m/s²**（自由落下）→10.3、`p` −0.1→184 deg/s（角加速度 7,200 deg/s²、破綻前の p99 5,400 超）。`t=20.1–20.46` は回復して静穏（φ≈5°, rate<12）。`t=20.47–20.50` に **FR duty が 0.415→0.291→0.197→0.000 と 4 周期で下限へ**（Δu = −u_hover、10 Hz テレメ `d_fr=−0.612` で確認）、`t=20.51` に 0.592 へ即復帰、その後ロール逸脱 |

**EKF の偽の傾きは今日だけで 3 回目**（0910_v2 飛行 2、0910_v5 飛行 1・2）。0904/0909 の全飛行では
ドリフト ≤1.05 deg/s だった。**ソルバとは無関係の欠陥**で、どのプログラムでも同じように落ちる。

**飛行 3 の FR→0 について。**
- `ftc = 0`（100 Hz・10 Hz とも）、`rx_flags = 0`。FTC/受信ではない。
- 記録状態をそのままリプレイすると再現しない（λ=0、box 非活性、弁も未発動、再現 FR は 0.59–0.63）。
- **実機と同じ再構築・TR1 スキップの経路を強制したリプレイ**では形が再現した:
  `t=20.43–20.49` に U(FR) が −0.025→−0.162 と 6 周期単調に伸び、`t=20.50` に −0.020 へ戻る。
  λ=0、box 非活性のまま。**制約・双対・安全弁ではなく、warm-start された RTI 解そのものの動き。**
  実機は同じ形でより大きく（−0.612 まで）動いた。機構は未特定。実機の周期ごとの `ws.U/z/λ` を
  100 Hz リングに残さない限りこれ以上は追えない。

**旧プログラムと新プログラムの「整合したコントローラ」の違い（ホスト、静的入力）。**

| | K角 [/deg] | K率 [/(deg/s)] | 率/角 [s] |
|---|---|---|---|
| 旧（バグ有, R_u=120） | 0.606e-3 | **0.487e-3** | 0.80 |
| 新 R_u=320 | 0.860e-3 | 0.525e-3 | 0.61 |
| 新 R_u=800（現行） | 0.496e-3 | **0.307e-3** | 0.62 |

`R_u=800` は角度ゲインを旧に合わせたが、**角速度ゲインは旧の 63% しかない**。遅れで限界にある
4 Hz モードに効くのは角速度（減衰）側である。飛行データ回帰でも旧 3 飛行の K率は 0.37–0.55e-3 で
安定して大きく、新は 0.15–0.37e-3 で小さい（R² は新側が低く、精度は劣る）。

両方を旧に合わせる重み（ホスト格子探索）: **`R_u ≈ 450–500, Q_p=Q_q ≈ 28–30`**
（`R_u=500, Q_p=30` → K角 0.570e-3, K率 0.503e-3, 率/角 0.88 s）。

## 判断: 「戻すべきか」

**戻すこと自体は「飛ばすための退避」として成立するが、根本には近づかない。理由:**

1. **今日の 3 回中 2 回（と 0910_v2 の 1 回）は EKF の偽の傾きで落ちている。** これは旧プログラムでも
   同じように起きる。戻しても 3 分の 2 は再発する。
2. 旧プログラムが「飛べた」のは、50 Hz ディザで実効ゲインが下がり、しかも角速度側が相対的に
   残っていたから（[`20260910_dither_was_masking_the_real_loop_gain.md`](20260910_dither_was_masking_the_real_loop_gain.md)）。
   その旧でも 4 Hz モードは出ていた（0904_v4: 54.9%）し、0909_v1 は墜落して NaN 固着した。
   **旧は「安定」ではなく「たまたま余裕側に倒れていた不健全な状態」**である。
3. 旧の性質は、健全なソルバ側で**再現できる**（上記 `R_u≈450–500, Q_p≈28–30`）。
   戻さずに旧と同じ整合ゲイン（角度・角速度の両方）を与える方が、比較実験として厳密で、
   NaN 固着・ディザによる推力損失・U_lin 発散を再び抱え込まない。

**採用する順序（推奨・未実施）。**

1. **EKF 偽の傾きの検知と可視化**（最優先・ソルバ非依存）:
   `Xe(4..6)`/`Beta` を 100 Hz リングに追加。`attitude_state_sane()` に
   「数周期窓での d(Phi)/dt と (Wp−Pbias) の差 > 3 deg/s で再初期化」を追加。
2. **ソルバ内部状態の 100 Hz 記録**: `‖λ‖`、box 有効数、`‖ws.U‖`、経路（再構築/スキップ）。
   飛行 3 の FR ランプはこれが無いと機構に到達できない。
3. **旧の整合コントローラを新ソルバで再現**（`R_u≈500, Q_p=Q_q=30`）して A/B。
   ここまでやっても旧だけが飛ぶなら、そのとき初めて「旧の何か」を疑い、旧へ戻す実験に価値が出る。
4. 根本: モータ遅れの実測と予測モデルへの組み込み、gyro LPF（変わらず）。

**今回はコード・パラメータを変更していない。** 直近 5 回の飛行がすべて私の変更後に墜落しており、
次の変更はユーザの判断で選ぶべきと考えたため。

## 検証結果

- 全区間の推定ドリフト、接地バウンドの acc_norm 系列、角加速度分布、FTC/受信フラグを確認。
- 記録状態リプレイ（素朴版・経路一致版）を実機ソースそのもので実施。経路一致版で FR ランプの形を再現。
- 旧/新の静的整合ゲイン（角度のみ 8.6°、角速度のみ 20 deg/s）をホスト計測。格子探索で一致点を算出。
- 未検証: FR ランプの機構、EKF 発散の原因、`R_u=500/Q_p=30` の実飛行。
