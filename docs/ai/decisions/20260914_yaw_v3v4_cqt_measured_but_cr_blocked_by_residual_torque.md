# v3/v4：`C_QT/Iz` は 3.3% 精度で測れた（ファームのヨー権限は 1.49 倍過大）。`Cr` は測れない — フェーズ④の「tau_z = 0」が成立していない

- **日付**: 2026-09-14
- **種別**: investigation | tuning
- **対象**: `tools/0914_100Hz_yaw_v3.csv` / `_v4.csv` / `0914_yaw_V3.csv` / `_V4.csv`、`tools/fit_yaw_damping.py`、`docs/20260905_yaw_damping_experiment_protocol.md` フェーズ①②④
- **タグ**: #Cr #C_QT #yaw #sysid #bench #tau_bias #ヨー権限 #CQ #Iz

## 背景

`Bench_mode = BENCH_YAW_EXCITE`、新パラメータ（`u0=0.35`, `u_start=0.20`, `t_ramp=1.5`, `r_max=250`:
[`20260914_bench_lower_u0_and_soft_ramp.md`](20260914_bench_lower_u0_and_soft_ramp.md)）で 2 本実施。
`fit_yaw_damping.py --selftest` は事前に通過（`Cr` 復元誤差 2.1%）。

## 結果 1（成功）：`C_QT/Iz = 5.99 ± 0.20`。ファームのヨー権限は **1.49 倍過大**

フェーズ②の立ち上がりは `r ≈ 0` なので減衰項が厳密に消え、**ここだけは前提が成り立つ。**

| 窓 | v3 `rdot` | v4 `rdot` | R² |
|---|---|---|---|
| ステップ後 0.10–0.90 s | 96.6 deg/s² | 92.8 deg/s² | 0.998–0.9996 |

`tau_bias`（後述）と微小な減衰を補正し、窓を 5 通り振った結果:

**`C_QT/Iz = 5.985 ± 0.200 [1/(kg·m²)]`（3.3%）。v3 平均 6.037 / v4 平均 5.933（両者 1.7% 一致）。**

ファーム（`B_c(4,k) = kS·C_QT·T_max/Iz`）との比較:

```
ファーム  C_QT*T_max/Iz      = 0.02956 * 0.81 / 3.0e-3 = 7.981  [1/s² per duty]
実測      (C_QT/Iz)*T'(0.35) = 5.985 * 0.894           = 5.350
実測 / ファーム = 0.670
```

**→ ファームのヨー権限は 1.49 倍大きすぎる。**

⚠ **この比は `Iz` にまったく依存しない。** 測っているのも使っているのも `C_QT·T_max/Iz` という
ひとかたまりだから（`nmpc_params.hpp` の注記どおり）。`Iz` が 3.9 倍不確かでも結論は動かない。

`Iz = 3.0e-3` と置けば `C_QT = 0.0180`（現行 0.0296）、`CQ = 9.35e-9`（現行 1.54e-8）。
**ただし `Iz` 次第なので、置き換えるなら `C_QT` 単独ではなく比で考えること。**

⚠ 測定点は duty 0.35。ホバーは 0.54、1 発停止 relaxed hover は 0.68 なので**外挿**。

## 結果 2（成功）：モータ OFF ベースラインは V1 と数 % で再現

| ラン | `\|r\|` 平均 | 実測 `−rdot` | V1 モデル | 差 |
|---|---|---|---|---|
| v3 モータ OFF | 121.6 deg/s | 2.38 deg/s² | 2.53 | −6% |
| v4 モータ OFF | 55.3 deg/s | 1.65 deg/s² | 1.63 | **+2%** |

V1 は別ラン・手回し（[`20260914_yaw_v1_baseline_offset_ok_fs_rate_latched.md`](20260914_yaw_v1_baseline_offset_ok_fs_rate_latched.md)、
`tau_f/Iz=2.0e-2, b/Iz=6.5e-3, Cr_base/Iz=2.3e-3`）。**治具・軸受・ベースラインは再現性がある。**

## 結果 3（失敗）：`Cr` は測れない。フェーズ④の前提が崩れている

`fit_yaw_damping.py --decay` は 4 本すべてで**自分のガードに引っかかった**（`Cr ≤ 0`、条件数 43〜19333）。
スクリプトは正しく拒否している。**この数値は使ってはならない。**

### 原因 (a)：`tau_bias ≠ 0`

フェーズ①（`u0` 保持、`Δ = 0` → `tau_z` は 0 のはず）で `r` が動く:

| ラン | フェーズ①の `rdot` |
|---|---|
| v3 | **+5.16 deg/s²** |
| v4 | **+2.18 deg/s²** |

v3 の減衰の実測平均は 3.5 deg/s² なので、**バイアスの方が信号より大きい。**

### 原因 (b)：残留トルクは定数ですらない — `r` が減って**また増える**

v3 の `r`（10 Hz シリアル、全シーケンス）:

```
t=25.5  239 deg/s  (フェーズ②終了、r_max で打ち切り)
t=37    38         ← 減衰
t=45    125        ← **増えて 125 付近で頭打ち**
t=45.6  モータ OFF → 125 → 106.7 (8 s で 2.3 deg/s²、ベースラインどおり)
```

V1 ベースラインを引いた「ロータ由来の寄与」を時間順に並べると符号が反転する:

| v3 窓 [s] | `\|r\|` | ロータ由来 |
|---|---|---|
| 0–2 | 168 | **+16.2** |
| 6–8 | 61 | **+19.4** |
| 10–12 | 59 | **−23.5** |
| 14–16 | 113 | −14.5 |

**`|r| ≈ 60` で寄与が +19.4 と −23.5 の両方を取る。** `r` の関数ではない。
スカラー ODE `rdot = f(r)` では `r` が非単調になれないので、**遅い隠れ状態がある。**
v4 も程度は軽いが `t = 23–25 s` で `r ≈ 175` の平坦部を作っている。

**機構は未特定。** 候補: 室内の空気が機体と一緒に回り始める（後流の再循環。要領書 §10 が
「床から十分離す」と警告している件）、吊り線のねじれ、電圧降下。**いずれも未検証。**

### 原因 (c) ではない：機体の傾き

傾き（`sqrt(p²+q²)/|r|`）は **v3 8.1° / v4 8.9°**（モータ OFF でも 7.7°、V1 は 7.1–8.2°）。
`u0` を 0.60 → 0.35 に下げても変わらない＝**幾何の問題**で、ユーザ申告どおり残っている。
ただしジャイロ結合 `(Iy−Ix)·p·q/Iz` は **±0.03〜0.07 deg/s²** しかなく、
**異常トルク ±20 deg/s² の 0.3%。傾きは原因ではない。**
（`q ≈ −0.15·r`、`p ≈ 0` なので 3 本のうち 1 本だけ長さが違う形）

## 結果 4：新ファームの機能確認

- ランプ動作（10 Hz サンプルの先頭が `u = 0.208 / 0.210`、`u_start = 0.20` から立ち上がっている）
- **`r_max = 250` が 2 本とも発火**。加振は `t_step = 6 s` ではなく **2.7 s / 3.2 s** で打ち切り、
  `r` は 249.4 / 249.5 deg/s で頭打ち。フェーズ③へ正しく遷移し、`t_decay` を丸ごと取れている
- `failsafe = 0`（加振中は姿勢・角速度とも無効化済み）
- ⚠ **100 Hz リングログはフェーズ②を 2 本とも取り逃した。** 全長が v3 で 27 s（18.48→45.68）、
  リングは 21.8 s。予告どおり（[`20260914_yaw_v1_...md`](20260914_yaw_v1_baseline_offset_ok_fs_rate_latched.md) の対応 4）。
  今回の `--step` は **10 Hz シリアルをリング形式へ変換**して回した（5〜9 点、R² = 0.998 以上）

## 対応（次のランでやること）

1. **`Bench_sign = -1` の対を取る。** 最優先。`tau_bias` は `r` の符号に依らない固定トルクなので、
   `±Δ` の減衰を同じ `|r|` で平均すれば 1 次で消える。要領書 §5 が元々指示しているのに
   **2 本とも `sign = +1` だった。** コード変更不要
2. **フェーズ②専用の短いランを別に取る。** `Bench_t_decay = 5.0` にすれば全長 ≤ 21.8 s で
   リングに収まり、`C_QT/Iz` を 100 Hz・R² 0.999 で取り直せる
3. **`Bench_t_decay` を伸ばして平衡点 `r_eq` を確実に取る。** v3 は 125 deg/s 付近へ寄ったが
   頭打ち途中、v4 は届いていない。`damping(r_eq) = tau_unknown/Iz` が 1 本増える
4. **異常トルクの切り分け**: 床から離す／広い場所で同条件を再実行し、時間波形が再現するかを見る。
   再現すれば空気の連れ回り、しなければ吊り具

### 却下した案

- **`--decay` の結果を採用して `Cr` を更新する**: スクリプトのガードが 4 本すべてで発火している。
  負の `Cr` を「小さい」と読み替えるのは、前提が壊れている区間のフィットを信じることになる
- **傾きを直してから再測定する**: 傾きの寄与は異常の 0.3%。直すべきだが、これを直しても `Cr` は出ない
- **`r_max` を上げて掃引比を稼ぐ**: 掃引比が小さいのは `r_max` のせいではなく、
  残留トルクが減衰を打ち消して減衰が止まるため。上げても同じ壁に当たる

## 検証結果

- `fit_yaw_damping.py --selftest` 通過（`Cr` 誤差 2.1%）
- `--baseline` / `--decay` を 4 系列で実行（本文の警告はスクリプト自身の出力）
- `--step` は 10 Hz シリアル → リング形式変換（`/tmp/v3_conv.csv`, `/tmp/v4_conv.csv`）で実行
- 窓 5 通り × 2 ラン で `C_QT/Iz` のばらつき 3.3%
- ⚠ 異常トルクの機構は**未特定・未検証**
