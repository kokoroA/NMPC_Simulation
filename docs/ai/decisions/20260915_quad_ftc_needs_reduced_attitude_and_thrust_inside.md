# クアッド 1 発停止は「回らないと浮けない」。現行の姿勢表現と「高度を外に出す」設計では成立しない

- **日付**: 2026-09-15
- **種別**: investigation | design
- **対象**: `docs/20260915_quad_ftc_with_nmpc.md`、`Benzen_NMPC` の状態表現と高度制御の分離方針
- **タグ**: #FTC #クアッド #reduced_attitude #relaxed_hover #B_c #混合行列 #NMPC優位性 #四元数

## 背景

「NMPC でクアッドの耐故障制御をやるなら現行アルゴリズムのままでは不可能か、直すなら何を」という問い。

## 判断根拠

### (1) クアッド 1 発停止に水平ホバー解は**存在しない**（厳密）

ヘキサで使ったのと同じ代数（`f_FR = 0` として鉛直・ロール・ピッチを釣り合わせる）を
クアッド X（`kXm=[+a,+a,−a,−a]`, `kYm=[+a,−a,+a,−a]`, `kS=[−1,+1,+1,−1]`）に当てると

```
ピッチ式 + ロール式  →  f_RL = 0、 f_FL = f_RR = mg/2
ヨー     →  Σk_S·f = f_FL + f_RR = **mg**（合計推力がまるごと残る）
```

生き残った FL と RR は**同じ回転方向**なので反トルクが足し算になる。
`m=250 g` で `τ_z = C_QT·mg = 0.0726 N·m`、打ち消す相手が居ない。
推力も `mg/2 = 1.226 N` で上限 `0.841 N` の **146%**。**ヨーでも推力でも二重に不可能。**

**ヘキサとの差は発数ではなく「生き残った発の回転方向が割れるか」。**
ヘキサは CW 2・CCW 2 に割れてヨーが自動的に釣り合う。クアッドは割れない。

### (2) 回転平衡（Mueller 型）なら成立するが、毎秒 2 回転する

`(φ,θ)` ごとに可解な `Ω` を求根し、`0≤f≤fmax` でピーク推力最小を取る
（`L=0.12, Ix=Iy=1.2e-3, Iz=2.4e-3, Cr=9.5e-5, fmax=0.841`）:

| 質量 | 非回転 `mg/2` | 回転平衡 `Ω` | `max f` | 余裕 |
|---|---|---|---|---|
| 250 g | 146% | 852 deg/s | 106% | −6.1% |
| **220 g** | 128% | **799 deg/s** | 94% | **+6.7%** |
| 200 g | 117% | 762 deg/s | 85% | +17.4% |

傾きは小さく（`φ=−4°, θ=−8°`）、効いているのは**回転数**。荷重が 2 発 → 3 発に散ることで成立する。

**`Cr` 感度（m=200 g）**: `Cr` 3e-5→1e-3 で `Ω` は 1373→302 deg/s と 4.5 倍動くが、
`max f` は 83〜88% でほぼ不変。**可否は推力律速、`Cr` は回転数を決めるだけ** ──
ヘキサで得た結論（[`20260914_ftc_is_thrust_limited_not_cr_limited.md`](20260914_ftc_is_thrust_limited_not_cr_limited.md)）が
クアッドでも同じ形で成り立つ。

### (3) ⚠ `B_c·1 = 0` は**健全な機体でしか成り立たない**

「高度は NMPC に入れない」という設計判断（`repository_rules` §3）の根拠は
`B_c·1 = 0`（共通モードと差分モードの分離）だった。しかし

| | `Σ1` | `ΣkXm` | `ΣkYm` | `Σk_S` |
|---|---|---|---|---|
| クアッド健全 | 4 | 0 | 0 | 0 |
| **クアッド FR 停止** | 3 | **−0.0849** | **−0.0849** | **+1** |
| **ヘキサ FR 停止** | 5 | **−0.085** | −0.05 | +1 |

**故障するとヘキサでも成り立たない。** スロットルを上げるだけで姿勢モーメントが出る。
ヘキサでは余裕を食うだけで済むが、クアッドは `Σk_S = +1` でヨーに直結するため致命的。

### (4) 現行実装が壊れる箇所

`Ω ≈ 800 deg/s` を前提にすると、深刻度順に:

1. **高度を外に出す設計**（上記 (3)）
2. **状態 `[φ,θ,p,q,r]`（オイラー角）** — ホライズン `N·dt=0.14 s` に **112° 回る**。RTI の 1 点線形化が無意味
3. **ヨーを追従する設計** — 回転平衡でヨーは制御量ではなく結果
4. **`φ_ref, θ_ref` を独立指令する設計** — 平衡は `(φ,θ,Ω,f)` が一体
5. **`FS_RATE = 360 deg/s`** — 即ラッチ
6. **TR1/SR2 の warm start** — 動作点の巨大移動に追随しない恐れ
7. **EKF・遅れ補償** — 100 Hz で 1 周期 8°、`delay_comp_steps=6` は 48° 分の外挿

## 対応（方針。実装はしていない）

**★最重要: 状態を reduced attitude（機体 z 軸の向き `n`、2 自由度）＋ `ω`（3）にする。NX は 5 のまま。**

- ヨーが状態から消えるので 3 が自動的に解決
- オイラー角の特異点が消える
- **速く回っているのは機体であって推力の向きではない**ので、2 のホライズン問題が大幅に緩む

次点で **推力を最適化の中に入れる**（(3) より不可避）、**オフライン平衡表**
（ヘキサの relaxed hover と同じ設計判断。`U_ref = u_eq − u_hover`）、フェイルセーフ再設計。

**ADMM の box 扱い・TR1/SR2・`η` を box 縮小で表す FTC の入れ方はそのまま使える。**
壊れるのは**モデルと参照の作り方**であってソルバではない。

### 却下した案

- **クアッドでも水平ホバーを狙う**: (1) より解が存在しない。制御則の問題ではない
- **オイラー角のままホライズンだけ短くする**: `N` を 1/3 にしても 37° 回る。かつ `N` は
  この機体で最重要の性能ノブ（`repository_rules` §4-2）で、短縮は予測能力を直接削る
- **`Cr` をクアッド機体で測り直してから設計する**: (2) より可否は `Cr` に依らない。回転数の予測精度のためだけに要る

## 検証結果

- (1) は代数（本文の 3 行）と数値の両方。残差 2.4e-16
- (2) は左零ベクトル `n`（`Aᵀn = 0`）に対する `nᵀb(φ,θ,Ω) = 0` を `Ω` について求根する方式。
  格子探索では可解集合が余次元 1 なので取りこぼす（最初に 0 個と出て方式を変えた）
- Mueller & D'Andrea (2014) と**定性的に一致**（高回転・ヨー放棄・3 発で荷重分散）。数値の直接照合は未実施
- ⚠ 諸元は**仮定した架空のクアッド**。`Cp=Cq=0.025` はヘキサの未測定の仮値の流用
- ⚠ **平衡の存在と推力余裕だけ。可制御性・安定性・到達可能性は未評価**

## ⚠ 2026-09-15 追記：本記録の (4)-2 と 4-1 を訂正する

「`Ω=800 deg/s` だとホライズン `N·dt=0.14 s` に 112° 回るのでオイラー 5 状態は使えない」は**誤り**。

**回転平衡では `φ, θ, p, q, r` がすべて一定**（ẋ = 0 を数値で確認）で、回っているのは
**状態に持っていない `ψ` だけ**である。したがって RTI の 1 点線形化は
「静止した動作点まわりの線形化」として成立する。ヘキサ側で平衡点の `A_c` を実際に組んで確認した
（固有値 `0±11.87j`（回転そのもの、中立）, `−0.744`, `−33.46±7.22j` ── 最大実部 0.000）。

したがって **reduced attitude は「必須」ではなく「推奨」へ格下げ**する。
ジンバルロック回避と見通しのための改善であって、必要条件ではない。
**必要条件として残るのは「推力を最適化の中に入れる」（`B_c·1 ≠ 0` のため）の方。**

代わりに**過小評価していた課題**が出た: **回転中の姿勢推定**。
IMU が回転軸から 20 mm ずれていると遠心加速度 2.8 m/s² が重力基準を 16° 傾ける。
`‖a‖` は 10.2 とほとんど変わらないので、`ekf_reinit_on_arm()` の `|‖a‖−g|<2.0` では**検出できない**。
詳細と対策: [`20260915_relaxed_hover_implementation_plan.md`](../../20260915_relaxed_hover_implementation_plan.md) §1-5, Step 5。
