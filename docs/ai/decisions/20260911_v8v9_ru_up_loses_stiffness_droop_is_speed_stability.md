# v8/v9: R_u を上げると減衰は買えず剛性だけ失う。「垂れ」の正体は速度比例の外乱（ブローバック）で、重みでは解けない

- **日付**: 2026-09-11
- **種別**: investigation | tuning
- **対象**: `tools/0911_100Hz_v8.csv`(R_u=1000), `tools/0911_100Hz_v9.csv`(R_u=800), `0911_100Hz_v6.csv`(620), `nmpc_params.hpp`(R_u, Q_phi, Q_p)
- **タグ**: #Benzen_NMPC #飛行実験 #R_u #Q_p #Q_phi #オーバーシュート #定常誤差 #速度安定 #ブローバック #積分器 #PIO

## 背景 / 症状

ユーザ報告: **R_u=800 も 1000 もそもそも水平を保てない。R_u=620 の方が水平も追従も良い。
ただし 620 はオーバーシュートがひどい。**

## 原因 / 判断根拠

### (1) R_u を上げると剛性だけが落ちる。減衰比は変わらない（実機実測、R² 0.71-0.93）

飛行ログから制御器のマップ `指令ロールトルク = K角·(φ_ref−φ) + K率·p` を直接回帰した。

| | K角 [e-3/deg] | 減衰 [e-3/(deg/s)] | 率/角 [s] | R² |
|---|---|---|---|---|
| **v6 R_u=620** | **0.852** | 0.216 | 0.25 | 0.93 |
| v9 R_u=800 | 0.665 | 0.175 | 0.26 | 0.86 |
| v8 R_u=1000 | 0.420 | 0.121 | 0.29 | 0.71 |

**`R_u` は K角 と K率 を同じ比で下げるだけで、率/角（相対減衰）は 0.25→0.29 s とほぼ動かない。**
つまり **`R_u` を上げてもオーバーシュートは直らず、剛性を失うだけ。**
ホストの外乱釣り合い剛性（1.0010 / 0.8815 / 0.7837e-3）とも向きが一致する。

水平保持の実測（`|ref|<2deg` の区間の姿勢 rms）も一直線に悪化している。

| | roll rms | pitch rms | 浮上 [s] |
|---|---|---|---|
| v6 620 | **3.01 deg** | **2.70 deg** | 20.4 |
| v9 800 | 5.81 | 4.59 | 9.2 |
| v8 1000 | 4.55 | **10.50**（最大 45.9 deg） | 11.1 |

**ユーザの体感は正しい。R_u は 620 に戻すべき。**

### (2) 「垂れ」の正体は **速度比例** の外乱（確認済み・これが本題）

未説明トルク（= 実測角加速度 − モデルの指令トルク）を **θ（傾き）** と **∫θdt（速度の代理）** で回帰した。

| | θ の係数 | **∫θdt の係数** | R²（両方） | R²（θのみ） |
|---|---|---|---|---|
| v6 roll | +3.2 | **−41.1** | 0.469 | 0.010 |
| v9 roll | +1.0 | **−32.1** | 0.273 | 0.001 |
| v6 pitch | −3.5 | **−12.4** | 0.133 | 0.013 |
| v9 pitch | +4.2 | **−15.9** | 0.176 | 0.024 |
| v8 pitch | −2.2 | **−17.3** | 0.138 | 0.008 |

**θ 単独ではほぼ何も説明できない（R² 0.001-0.024）のに、∫θdt を入れると R² が一桁上がる。
しかも係数は一貫して負。** これは**傾けて速度が乗るほど、傾きを戻す向きのモーメントが増える**ことを意味する
＝**速度安定（ブローバック）**。ローターの前進速度による誘導流の非対称で生じる、
マルチロータでは普通の現象である。

**姿勢 5 次元モデル（`x=[φ,θ,p,q,r]`）には並進状態が無いので、この項は原理的に入っていない。**
コスト関数は比例項だけ（積分器なし）なので、**この外乱は必ず定常誤差になる。**

### (3) 実機でそのまま見える（v6、θ_ref をほぼ一定に保った区間）

| 時刻 | θ_ref | 0.1-0.3 s 平均 | 0.7-1.0 s 平均 |
|---|---|---|---|
| 10.58 | +6.0 | +8.8（**147 %** 行き過ぎ） | +4.7（**78 %** へ垂れ） |
| 15.26 | +10.1 | +12.2（121 %） | +4.8（**47 %**） |
| 16.26 | +13.8 | +3.3（24 %） | −1.1（**−8 %**） |

**最初に行き過ぎ、そのあと垂れる。** 速度が乗るほど戻される（16.26 の区間は既に速度が乗っていて最初から届かない）。

### (4) 「オーバーシュート」と「水平を保てない」は同じ現象の表と裏

垂れる → パイロットは更にスティックを入れる → 速度が落ちた瞬間に溜まった指令が効いて行き過ぎる →
逆に倒す → 0.4-0.9 Hz の PIO（実測ピーク: v6 0.73 Hz、v9 0.65 Hz、v8 0.36 Hz）。
v6 の t=12.2-12.8 はこの往復そのもの（`phi_ref +5.7 → phi +11.5` の行き過ぎ直後にスティック 0 へ、`phi −22.8`）。

**`R_u` を上げると垂れが増えるので PIO はむしろ悪化する。** v8/v9 が飛ばなかったのはこれで説明がつく。

### (5) 重み（Q_phi / Q_p）では解けない — フロンティアを測った

`R_u=620` 固定でホストを走らせた（相対減衰 = `率/角`、剛性 = 外乱釣り合い時の指令トルク/誤差1deg）。

| | Q_phi / Q_p | 率/角 [s] | 剛性 [e-3] |
|---|---|---|---|
| **A = v6** | 500 / 20 | 0.348 | **1.0010** |
| B | 500 / 40 | 0.389 | 0.7200 |
| C | 750 / 40 | 0.283 | 1.0541 |
| D | 1000 / 60 | 0.311 | **1.0950** |
| E | 750 / 60 | 0.391 | 0.8329 |
| **F** | 1000 / 80 | **0.393** | 0.9094 |
| G | 1250 / 100 | 0.320 | 0.9653 |

**相対減衰を +13 %（0.348→0.393）稼ぐのに剛性を −9 % 払う**のが限界。
`Q_p` 単独増（B）は剛性を **−28 %** も失う（=「垂れ」が悪化する）ので**却下**。
**重みの範囲では、垂れとオーバーシュートを同時に良くする組み合わせは存在しない。**

## 対応

**パラメータは変更していない**（次に何を試すかはユーザの判断のため）。

**却下した案**:
- **`R_u` をさらに上げる**: (1) のとおり減衰を買えず剛性だけ失う。飛行 3 便で単調に悪化。
- **`Q_p` だけ上げて減衰を稼ぐ**: 剛性 −28 %。垂れが悪化して PIO が増える。
- **モデルに並進状態を足す**: 位置制御を捨てて姿勢 5 次元に縮約したのが本研究の主張
  （`repository_rules.md` §3）。ここを崩さない。

## 検証結果

(1)(2)(3)(4) は飛行ログから（回帰の R² を併記）。(5) はホスト（出荷ソース、params のみ差し替え）。
⚠ **ホストは実機のオーバーシュート／共振を再現しない**ことが既に分かっている
（[`20260911_v6_...`](20260911_v6_loose_motor_fixed_yaw_ok_roll_overresponds.md): Mp 実機 1.82 に対しホスト 0.86-0.91）。
**したがって (5) の表は「剛性と相対減衰の交換レート」を示すだけで、
どの組が実機で気持ちよく飛ぶかは机上では決められない。** 実機で測るしかない。

## 次に触る人へ

**本命は積分作用。** 外乱が速度比例である以上、比例だけの制御器では
「傾ければ傾けるほど、長く保つほど垂れる」のは**構造的に避けられない**。
ロール・ピッチの姿勢誤差にゆっくりした積分（τ 1-2 s、アンチワインドアップ、
`U_ref` へのトリムとして ±0.05 程度で飽和）を足すのが筋。
**積分が入れば「剛性を落として穏やかにする」ことが初めて可能になり、
R_u を上げてもオーバーシュートだけ減らせるようになる。** 今は両者が取り合いになっている。
ヨーの積分（[`20260911_v5_...`](20260911_v5_yaw_untrackable_steady_disturbance_not_gain.md)）と同じ実装で 3 軸まとめて入れられる。

**当面の 1 手（積分を入れる前に何か飛ばすなら）**:
- **`R_u` は 620 に戻す**（実測で最良。800/1000 は明確に悪い）。
- 減衰を少しだけ買いたいなら **F: `Q_phi=Q_theta=1000`, `Q_p=Q_q=80`, `R_u=620`**。
  相対減衰 +13 %、剛性 −9 %。**実機での効果は未検証。**
- **運用: 大きな傾きを長く保持しない。** 垂れは速度に比例するので、
  保持時間が長いほど・速いほど悪化する。
