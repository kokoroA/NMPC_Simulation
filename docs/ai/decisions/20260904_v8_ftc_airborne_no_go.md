# Q_r=40 は健全飛行候補だが、1発空中停止はまだ No-Go

- **日付**: 2026-09-04
- **種別**: investigation | design
- **対象**: `Benzen_NMPC/tools/0904_v8.csv`, `0904_100Hz_v2.csv`, FTC 実装
- **タグ**: #Benzen_NMPC #Q_r #FTC #耐故障 #FR停止 #推力余裕 #飽和 #SR2 #ランプ #NoGo

## 背景 / 症状

`Q_r=60` のヨー過渡を受け、`Q_r=40` で健全飛行を実施した。
次に空中で FR モータを完全停止する耐故障実験へ進めるかを判定した。

## 原因 / 判断根拠

**確認済み事実。**

- `Q_r=40` は `Q_r=60` より改善した。着地衝撃を除く100 Hzログで
  最大 `|r|` は **126 → 29 deg/s**、モータ飽和時刻率は **16.6 → 5.5 %**、
  `q` RMS は **22.1 → 13.6 deg/s**、Δu のヨー成分は **63.7 → 24.4 %**。
- ただし健全飛行でも 19 秒付近に、`theta_ref` が約 −4°から0°へ戻る過程で
  `theta=-18.8 → +10.9 deg`、`q=+92 deg/s` の低減衰な回復過渡が残った。
- 健全飛行中の6発 duty 合計は平均 **4.052**、p95 **4.484**。
  FRを停止し、実機配置のロール・ピッチトルクを0に保つ静的配分では、
  duty上限0.95のもとで合計最大は **3.80**（FR=RL=0、FL=MR=ML=RR=0.95）。
  平均要求でも上限を6.6%超え、等価4発 duty は平均 **1.013**。
  健全飛行サンプルの91%で等価4発 dutyが0.95を超える。
- `tools/*.csv` を走査したが、**`ftc=1` の実測ログは0件**。
  現行FTC経路はビルド・算術確認のみで、プロペラなしの実機確認も記録されていない。
- 現行実装は `Motor_eta[FR]` を **1→0へ即時変更**し、出力側も即座にFRを0へ落とす。
  最大10 ms、NMPCが新boxを認識する前にFRだけ停止し得る。
- `nmpc_set_motor_eta()` は warm-startを維持し、故障遷移時にSR2をリセットしない。
  Repository方針の「故障検知時はSR2を即時リセット」と一致していない。
- 通常ループp95は8.85 msだが、周期フル再構築は約35 ms。故障過渡と重なる余裕は小さい。

**制約付き計算。**

FR停止後の合計3.80上限は、線形dutyモデル、水平姿勢、定常ロール・ピッチトルク0に基づく。
実推力はdutyに完全比例しないため絶対的な高度予測ではないが、
NMPC自身が使うモデル上でも現在の実測duty要求に余裕がないことを示す。

## 対応

**空中での突然の1発停止は No-Go。** `Q_r=40` 自体は次段階の候補として維持する。

試験順序:

1. プロペラなしでFTC ON/OFFし、`ftc=1`, `u_fr=0`, 残り5発、復帰、フェイルセーフをログ確認。
2. 固定治具・低dutyで再配分方向を確認。
3. 係留または保護ケージ内で、まずηを段階的に下げて推力余裕と姿勢過渡を測る。
4. 健全時のピッチ回復過渡と、故障時のSR2/warm-start方針を解決してから低高度自由飛行へ進む。

完全停止を最終的に試す場合も、段階試験で安全域を確認してから行う。

## 検証結果

- `0904_100Hz_v2.csv` は2176/2176行、時刻欠損なし。`failsafe=0`, `ftc=0`。
- 10 Hz `0904_v8.csv` と100 Hzログは、ヨー改善と19秒付近のピッチ過渡の両方で整合した。
- FTCモードそのものは**未実機検証**。

## 次に触る人へ

- 健全飛行の平均飽和率だけでFTC可否を決めない。故障後の静的配分可能集合と比較する。
- 「6発中1発停止だから残り5発で6/5倍」ではない。配置とトルク釣合いにより、
  FR停止・水平姿勢では実質4発の推力上限になる。
- η変更時のランプ、出力ガード、SR2リセット、周期再構築を独立にせず、同じ故障遷移として設計する。
