# 0910_v10（遅れ補償）: 3–5 Hz 限界モードは消えた。墜落は EKF の偽の傾き（飛行 3）とパイロット過大入力（飛行 2）

## 確認済み事実

**遅れ補償は設計どおり効いた。** 浮上中の 2–5 Hz 帯占有率: 飛行 2 で p 21% / q 32%、飛行 3 で p 23% / q 18%。
遅れ補償なしの新ソルバ v7 は 82%/81%、v8 は 53%/45%。**新ソルバで初めて遅れ限界モードが消えた。**
`#delay_comp: steps=4 pred_nonfinite=0`。`loop_us` 平均 9.9 ms・p95 10.2 ms・超過 6.7%（予測 4 周期分 + 再構築 31 回。やや超過）。

**飛行 3（12.6–20.3 s、最も適した記録）の墜落は EKF の偽の傾き。**
`phi` 0 → −18.5°（12.6–19.4 s）に対し `∫p = +3.9°`、`|p|` rms 6.8 deg/s。推定ドリフト −3.55 deg/s。
`ekf_bias_reset` は飛行中に 6 回発火したが `ekf_dphi` は −2.5〜−4.3 deg/s のまま（バイアス状態は ≤2 deg/s）
→ **観測更新由来**の再確認。`phi_ref` ≈ 0（パイロットはロール舵を入れていない）。
制御器は偽の −20° を正そうと右へ押し続け（左−右 duty +0.009）、実機は右へ約 20° 傾いたまま横滑りし、
19.3 s からロールの振り回し（p −47 → +145 deg/s、周期約 0.3 s の 1 往復）で逸脱、20.0 s に overG（failsafe 5）。
接地衝撃ではない（acc 9–10 m/s²）。速度が乗った状態でのロール逸脱。

**飛行 2（5.7–10.1 s）**: `theta` が 7.7 → 17.8° に流れ（推定ドリフト +3.2 deg/s、`theta_ref` 0 → 10）、
パイロットが `phi_ref` を 33° まで入れて `p` 30–38 deg/s → 9.5 s に acc 128（衝突）。偽の傾き ＋ 過大入力。

**飛行 1**: ログ先頭 0–1.1 s は既に転倒中（リング先頭が切れている）。分析不能。

## 判断

- 遅れ補償は残す（`delay_comp_steps=4`）。制御ループとしては今日初めて「発振しない新ソルバ」になった。
- **次に直すのは推定器。** 今日 5 回（v2-2, v5-1, v5-2, v6-1/2, v10-2/3）に出た偽の傾きは、
  どのソルバでも同じように機体を横滑りさせて落とす。ソルバ側の作業はここで一旦止める。
- 報告書 `docs/20260910_why_old_solver_flew_report.md` を作成（学生向け、用語注釈付き）。
