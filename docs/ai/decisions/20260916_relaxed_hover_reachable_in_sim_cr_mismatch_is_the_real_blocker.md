# relaxed hover はシミュで到達できた。⚠ 律速は EKF ではなく **モデルの `Cr` が実機と合っているか**

- **日付**: 2026-09-16
- **種別**: investigation | design（2026-09-15 の「EKF が律速」判断の訂正）
- **対象**: `docs/20260915_relaxed_hover_implementation_plan.md` Step 2、平衡表と到達可能性シミュ
- **タグ**: #relaxed_hover #FTC #Cr #到達可能性 #EKF #遠心力 #平衡表 #シミュレーション

## 背景

計画書 Step 2（平衡表の生成＋ホバーからの到達可能性）を **`Cr = 1.0e-4` 仮定**で実行した
（実測範囲 9.5e-5〜3.7e-4 の下端寄り）。到達可能性は計画書が「最大の未知」としていた項目。

## 結果

### (1) 平衡表（`m = 285.3 g`、実飛行較正 `f_max = 0.7052 N`）

⚠ **計算バグを 1 件修正した。** 推力曲線の切片 `T(0) = 0.0452 N` が停止モータにも推力を与えていた
（校正域は duty 0.25–1.00 なので `T(0)` は外挿で物理的に無意味）。`Tf(0) = 0` に修正。

| 構成 | Ω | φ / θ | peak duty | **0.95 までの余地** |
|---|---|---|---|---|
| 静的 4 発（現行 FTC） | 0 | 0 | 0.9394 | **0.0106** |
| **採用平衡** | **723 deg/s** | −5.0° / −6.0° | **0.7172** | **0.2328（22 倍）** |

```
x_eq = [φ −5.0°, θ −6.0°, p +76.3, q −63.3, r +723.2 deg/s]
u_eq = [FR 0, FL 0.6881, MR 0.6930, ML 0.7123, RR 0.7172, RL 0.7068]
u_hover = 0.5862  →  U_ref = u_eq − u_hover = [−0.586, 0.102, 0.107, 0.126, 0.131, 0.121]
```

`‖ẋ‖` はファームのモデルで **1.4e−14**（＝厳密に平衡）。

### (2) ⚠ モデル不一致が定常外乱として残る

同じ `(x_eq, u_eq)` を**実推力モデル**（モーメントを `T(u)` で作る）に入れると `‖ẋ‖ = 0.537`:

```
ロール −12 deg/s² / ピッチ +28 deg/s² / ヨー +2 deg/s² の定常外乱に相当
```

ファームは「モーメント ∝ duty（`T_max·u`）」、実機は「∝ `T(u)`」。**この差が消えない偏差を生む。**

### (3) 到達可能性 — 全条件で回転には到達した

ホバー `x = 0` から参照を `x_eq` / `U_ref` に切り替えて閉ループ模擬（N=14, dt=10 ms, Q/R は実機値、box, `η`）。

| # | 条件 | 結果 |
|---|---|---|
| 1 | 理想ソルバ(200 反復)・モデル一致・ラグ無し・ステップ参照 | 収束（r の 90% 到達 0.80 s、max\|θ\| 14°） |
| 2 | 同上・参照 3 s ランプ | 収束（飽和 0%、max\|θ\| 24°） |
| 3 | **ADMM 4 反復 + warm start（実機と同じ）** | 収束（飽和 10%） |
| 4 | 理想ソルバ・**実推力プラント** | 収束（飽和 5%） |
| 5 | 理想ソルバ・**モータラグ 20 ms** | 収束（飽和 3%） |
| 6 | **実機フル条件**（ADMM4+warm+実推力+ラグ+遅れ補償6）ステップ参照 | r 到達、⚠ θ に **−8°** の定常偏差 |
| 7 | 6 ＋ 参照 3 s ランプ | 成立（飽和 0%、max\|θ\| 32°） |

**ランプ参照にすると duty 飽和が 0% になる。ステップは 9〜10% 飽和する。**

### (4) ★訂正★ 姿勢推定バイアスは律速ではなかった

回転 723 deg/s での遠心誤差（IMU オフセット 5/10/20 mm → 4.6°/9.2°/18.0°）を
**定常バイアスとしてフィードバックに注入**した:

| バイアス | 結果 |
|---|---|
| 5° | **成立** |
| 9° | **成立** |
| **18°** | **成立**（max\|φ\| 24°, max\|θ\| 29°, 飽和 0%） |

⚠ [`20260915_relaxed_hover_plan_equilibrium_is_representable_ekf_is_the_blocker.md`](20260915_relaxed_hover_plan_equilibrium_is_representable_ekf_is_the_blocker.md)
の「最大の実装課題は回転中の姿勢推定」という判断を**訂正する**。
遠心誤差は**機体固定のほぼ定常バイアス**なので、姿勢ループは再トリムするだけで持ちこたえる。

⚠ **ただしこれは「姿勢が保てる」であって「その場に留まる」ではない。**
推定が 18° ずれていれば機体は実際に 18° 傾いて**水平に加速し続ける**。
本シミュに位置は入っていない。**壁との距離＝実験場所の広さの問題として残る。**

### (5) ★新たに判明した真の律速★ モデルと実機の `Cr` 不一致

モデルは `Cr = 1.0e-4` のまま、プラントだけ変えた:

| プラントの `Cr` | 到達した r | duty 飽和率 | 判定 |
|---|---|---|---|
| 1.0e-4（一致） | **729 deg/s** | **0%** | 成立 |
| 3.7e-4（実測上側） | **533 deg/s** | **15%** | 大きな定常偏差 |
| 9.0e-4 | **388 deg/s** | **44%** | 大きな定常偏差 |
| 9° バイアス ＋ 3.7e-4 | 549 deg/s | 14% | 大きな定常偏差 |

**`Cr` が 3.7 倍ずれると回転数が 27% 落ち、duty 飽和が 0% → 15% に増える。9 倍で 44%。**
回転が足りないとジャイロ項が不足し、**relaxed hover の旨みそのものが消えて飽和へ戻る。**

## 対応

- 計画書 Step 0（`Cr` 同定）の優先度を**最上位で確定**。EKF 遠心補正（旧 Step 5）は**降格**
- 参照は**ステップではなく 3 秒程度のランプ**にする（飽和 10% → 0%）
- ⚠ モーメントを `T(u)` で作るモデル誤差（ピッチ +28 deg/s² 相当）は未解決。
  定常偏差 −8° として現れる。積分作用は v11/v12 で純損失と判明済みなので、
  **`u_eq` 側を実推力で解き直す**のが筋（未実施）

### 却下した案

- **EKF の遠心補正を先に実装する**: (4) より 18° のバイアスでも姿勢は持つ。
  `r_imu` の実測精度がそのまま誤差になる（5 mm の誤りで 4°）ので、投資対効果が低い
- **`Cr` を測らずに 1.0e-4 を入れて飛ばす**: (5) より、実測範囲の上端 3.7e-4 だった場合に
  飽和 15% まで戻る。範囲の両端で結果が変わる以上、測ってから進む

## 検証結果

- 平衡は `model_f()` と同一式（ジャイロ項＋2 乗ダンピング）で `‖ẋ‖ = 1.4e−14` を確認
- 閉ループは条件 1〜14 の 14 通り。ADMM は実機と同じ `rho=1`, box, warm start
- ⚠ **すべて机上。実機・HIL とも未実施**
- ⚠ **位置・速度は模擬していない。** 水平ドリフトと壁までの距離は評価対象外
- ⚠ `Cp`, `Cq` は未測定の仮値 0.025 のまま。平衡はこれに依存する
- ⚠ 遠心誤差を「定常バイアス」として入れたが、実機では回転数の立ち上がりに伴って
  バイアスが時間変化する。その過渡は未評価
