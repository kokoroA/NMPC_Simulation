# Perfect2025_v1 を Pico 2 W（RP2350）向けに移植

- **日付**: 2026-08-28
- **種別**: design
- **対象**: `program/pico/pico-sdk2/pico-sdk/Benzen_Perfect2025_v1/`（CMakeLists, pwm, board_led, pico_copter, control）
- **タグ**: #Benzen_Perfect2025 #Pico #pico2_w #RP2350 #E9 #CYW43 #board_led

## 背景 / 症状

`Benzen_Perfect2025_v1` はボード未指定のまま SDK デフォルト `pico`（RP2040）でビルドされていた。
既存 `build_fresh` の cache は `PICO_BOARD=pico`, `PICO_PLATFORM=rp2040`、UF2 family は `0xe48bff56`。
Pico 2 W のブートローダはこれを受け付けない。

## 原因 / 判断根拠

`20260825_benzen_new_pico2w.md` と同じ理由。確認済み事実:

- Pico 2 W は RP2350。RP2040 UF2 では起動しない。
- GPIO25 は Pico 2 W では **CYW43 の SPI CS**。`pico_copter.cpp` の `gpio_init(25)` と
  `control.cpp` の `gpio_put(LED_PIN, …)` は無線チップと衝突する。
- Pico 2 W の LED は CYW43 上。`cyw43_arch_gpio_put` は PWM IRQ（400 Hz）から呼べない。
- RP2350-E9: PWM ピンの入力バッファを無効化しないと出力が不安定になり得る。
- Pico 2 の既定 SYSCLK は 150 MHz。PWM `wrap=3124, clkdiv=100` は **125 MHz 前提の 400 Hz**。
  未固定だと制御周期が約 480 Hz になる。

対象は **Pico 2 W**（`pico2_w`）。非 W の Pico 2（`pico2`）には CYW43 が無く、この UF2 は
`cyw43_arch_init()` で止まる。Pico 1 には入れない。

## 対応

`Benzen_new` の Pico 2 W 移植を踏襲。Perfect2025 固有の ADC（GP26/27）・`payload_half`・
自動旋回・サーボ値は触っていない。モータ GPIO 割り当て（`set_duty_*`）もそのまま。

- `PICO_BOARD pico2_w` を CMake で FORCE。`SYS_CLK_KHZ=125000`。
- LED 用に `pico_cyw43_arch_none`。`board_led` を新設し、`board_led_init()` で
  `cyw43_arch_init()` する（Wi-Fi テレメが無いので NMPC / Benzen_new と違う）。
- 400 Hz 側は `board_led_request`、main で `board_led_poll`。
- PWM ピンの E9 workaround と `pwm_pins_early_init` を追加。
- Eigen の相対パス `../../eigen`（存在しない）を
  `/Users/kokoro/Documents/drone_project/pico/eigen` に変更（NMPC / Benzen_new と同じ）。

却下: GPIO25 を残す案（CS 衝突）。`pico_cyw43_arch_lwip_*` を足す案（飛行に不要。
Perfect2025 にテレメスタックも無い）。非 W の `pico2` にする案（機体は Pico 2 W）。

旧 `build_fresh` は RP2040 専用だったので消して作り直した（Benzen_new のように
別の `build/` が無い）。

## 検証結果

- `build_fresh` で `pico_copter` ビルド成功。
- `PICO_BOARD=pico2_w`, `PICO_PLATFORM=rp2350-arm-s`, Release。
- UF2 family ID `0xe48bff57`（RP2350-ARM-S）、サイズ 1,246,208 B。
- `arm-none-eabi-size`: text 622664 / bss **212436**（SRAM 520 KB の約 40.1%）。
- 実機書き込み・飛行は未検証。

## 次に触る人へ

書き込む UF2 は `Benzen_Perfect2025_v1/build_fresh/pico_copter.uf2`。Pico 1 には入れない。

```bash
export PICO_SDK_PATH="/Users/kokoro/Documents/research_project/program/pico/pico-sdk2/pico-sdk"
cd "$PICO_SDK_PATH/Benzen_Perfect2025_v1"
cmake -S . -B build_fresh -DPICO_SDK_PATH="$PICO_SDK_PATH"
cmake --build build_fresh --target pico_copter -j8
```

書き込み: BOOTSEL → `/Volumes/RP2350/`、または
`build_fresh/_deps/picotool-build/picotool load -f`（本ビルドでは picotool を再構成していない）。

オンボード LED が点かない場合は USB シリアルで `#board led init failed` を確認（CYW43 初期化失敗）。
Wi-Fi AP は出ない（`pico_cyw43_arch_none`）。
