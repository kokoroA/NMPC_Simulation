# v2: ヨー発散は直ったが、FTC ではロールの P が 4.2 倍・D が 0.54 倍になり 3.1 Hz で発散した

- **日付**: 2026-09-15
- **種別**: investigation | tuning
- **対象**: `tools/0915_100Hz_v2.csv`（`|U_lin|` ガード修正 + `U_ref` フォールバック + 対角下限 0 + 案 A を入れた初便）
- **タグ**: #FTC #発振 #限界周期 #Q_p #減衰 #ulin_reset #ヨー #FS_RATE_LIMIT #ゲイン

## 背景

`20260915_ulin_guard_misfires_under_ftc.md` の 4 つの修正を入れて、地上で FTC（FR 停止）ON → 離陸。
**離陸はしたが姿勢が振動し、パイロットは「ゲインが高い感じ」と報告。**

⚠ **フォールバックが釣り合い配分になったことをログで直接確認した。**
リセット周期の出力は `[0, 0.645, 0.645, 0.645, 0.645, 0]`（`u_base=0.430` の 1.5 倍、RL=0）で、
v1 の「健全 5 発すべて `u_base`」（ヨートルク +194 deg/s²）は消えている。

**対角 RL が実際に使われ始めた**（`RL>0.05` が 26%、最大 0.37。v1 は全飛行で 1 サンプルのみ）。
ロール・ピッチを動かすとランク落ちでヨートルクが出るので、それを打ち消すために持ち上げている
＝ solver が正しく振る舞っている。

## 新しい症状と原因

離陸（`t≈9.70`）の直後からロールが発散し、**`p = −373 deg/s` で `FS_RATE_LIMIT = 360` に当たって
`failsafe=4`**（`t=10.61`）。ゼロ交差から **ロール 3.13 Hz / ピッチ 2.68 Hz**。

### ⚠ 制御器ゲインを直接測った（プラントの仮定なし）

指令モーメント `M` を姿勢誤差と角速度で回帰（`M = K_angle·e + K_rate·ω`）:

| | `K_angle` (roll) | `K_rate` (roll) | R |
|---|---|---|---|
| **v10 健全飛行** | 0.0233 | **−0.01382** | 0.70 |
| **v2 FTC 発振** | **0.0974（4.2 倍）** | **−0.00743（0.54 倍）** | 0.75 |

ピッチは `K_angle` がほぼ同じ（0.0198 → 0.0197）で `K_rate` だけ 0.52 倍。

等価 2 次系に直すと（`G = T_max/Ix = 450`）:

| | ω_n | **ζ** |
|---|---|---|
| v10 健全 roll | 3.24 rad/s | **0.96** |
| **v2 FTC roll** | 6.62 rad/s | **0.25** |
| v10 健全 pitch | 2.98 rad/s | 0.94 |
| v2 FTC pitch | 2.98 rad/s | 0.49 |

**P が 4 倍、D が半分 ＝ 減衰比が 0.96 → 0.25。** パイロットの「ゲインが高い」は正しい。

### プラント側の測定（参考・信頼度低）

`ṗ` を指令ロールモーメントに回帰すると FTC 発振区間で **1563 rad/s²/unit（モデル 450 の 3.47 倍、
ラグ 5 周期 ≈ 50 ms、R=0.88）**。同じ手法で v10 健全は 0.52 倍（R=0.34）。
⚠ **この 2 つを直接比べてはいけない。** 閉ループでは指令が外乱を打ち消すため回帰は下方バイアスを受ける。
健全便は R が低く外乱支配（`20260911_v4...md` の「実測/モデル比 0.40–0.42、R²=0.10」と同じ）。
発振便は自励振動が支配的なのでバイアスは小さい。
⚠ 四隅ペアと中央ペアを分離しても比は 3.19 / 3.59 倍とほぼ一様なので、**モーメント腕の誤りではない。**
実測 0.89 s（3 周期分）しかないので、絶対値は当てにしない。

## 対応（未実施・次便の提案）

**`R_u` は誤ったノブ。** `R_u` は P と D を同じ比率で下げるので ω_n は下がるが **ζ は変わらない。**
問題は ζ なので **`Q_p` / `Q_q`（角速度の重み）を上げる**のが筋。

`K_rate ∝ Q_p` と仮定した見込み（⚠ 線形外挿・未検証）:

| `Q_p` | ζ 見込み |
|---|---|
| 80（現行） | 0.25 |
| 150 | 0.47 |
| **250** | **0.78** |
| 400 | 1.25 |

現行 `Q_phi/Q_p = 1000/80 = 12.5`。健全便の P/D 比 1.69 rad/s に対し FTC は 13.2 rad/s（7.8 倍）。

## 検証結果

- 解析のみ。**コード変更なし。**
- 実時間軸は `loop_us` から再構成（`t` 列は行番号 ×0.01 で実時間ではない）
- 接地衝撃・自由落下サンプル（`acc_norm` が 8.5–12 の外）は回帰から除外
