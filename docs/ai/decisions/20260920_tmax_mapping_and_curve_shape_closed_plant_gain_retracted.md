## 背景

追加実験ができない状況で、[`20260920_plant_gain_is_1_6_to_2x_the_model_not_a_thrust_shortage.md`](20260920_plant_gain_is_1_6_to_2x_the_model_not_a_thrust_shortage.md)
の ②③④ をリポジトリ内のデータだけで詰めた。**結果として ② は自分の誤りだった。**

## ④ PWM マッピング → **既に正しい。修正不要**

`docs/sysid_thrust.py` は**既定が `--map pwm`** で、`目盛り → 1000–2000 µs（テスタ） → (us−1100)/800（ファーム）`
をすでに実施している。`FW_MIN_US/FW_MAX_US` は `pwm.hpp` の `DUTYMIN=1375 / DUTYMAX=2375` 由来。

⚠ スクリプトは `TESTER_MIN_US, TESTER_MAX_US = 1000, 2000  # ★未確認★` としていたが、
**独立実験で検証できた**:

| | |
|---|---|
| 目盛り 18 → ファーム duty | **1.000（ちょうど）** |
| 単発実測 T(目盛り18) | 0.8731 N → ×6 = **534.0 g** |
| 6 発実験 実測（t=0–30 s） | **532 g** |
| **差** | **−0.4 %** |

`Ct` 検算（プロペラ物理でスロットル解釈に依存しない）: **5.416e-7** vs `params` の 5.21e-7 = 4 % 差。

⇒ **テスタ 1000–2000 µs / 全目盛り 20 の仮定は妥当。マッピングに直すところは無い。**

## ③ 曲線の形 → **私の「凸」仮説が誤り。実際は凹。修正不要**

`重量-推力計算.xlsx` の生データ（f1404 Kv2900 + GEMFAN-3630-3）をファーム duty 軸で再フィット:

| duty_fw | 0.250 | 0.375 | 0.500 | 0.625 | 0.750 | 0.875 | 1.000 |
|---|---|---|---|---|---|---|---|
| T [N] | 0.2904 | 0.4150 | 0.5131 | 0.6141 | 0.7063 | 0.7907 | 0.8731 |
| 区間の傾き | — | 0.997 | 0.785 | 0.808 | 0.738 | 0.675 | **0.659** |

| フィット | 式 | R² |
|---|---|---|
| 冪則 | `T = 0.8829 · u^0.789` | 0.99910 |
| 2 次 | `−0.2264u² + 1.0523u + 0.0453` | 0.99971 |

⚠ **`n = 0.789 < 1` ＝ 凹。** 傾きは duty とともに**単調に減少**する（0.997 → 0.659）。
2 次フィットは**これまで使ってきた曲線そのもの**で、既にファーム duty 軸だった。

動作点での `dT/du`:

| `u_hover` | 0.516（271 g） | 0.550 | **0.606（貨物あり）** | 0.644 |
|---|---|---|---|---|
| `dT/du` | 0.801 | 0.790 | **0.774** | 0.764 |

⇒ ⚠ **貨物で `u_hover` が 0.516→0.606 になると `dT/du` は 3.4 % “下がる”。**
**「凸だから貨物でループゲインが上がる」という私の仮説は成立しない。**

## ⚠⚠ ② プラントゲイン「1.6〜2 倍」を撤回する

**ベンチ実測の `dT/du@hover = 0.774–0.801` は、モデルの `T_max = 0.75–0.81` と数 % 以内で一致する。**

前回の 1.1–2.0 倍は `dp/dt` と `Δu` の静的回帰（**相関 0.35–0.52**）から出した。
より素性のよい推定（1 ステップ予測誤差最小化、ジャイロ項と減衰項を含め、モータ遅れ τ も同時推定）で検算した:

| ログ | 軸 | **γ（実測/モデル）** | τ | 残差分散比 |
|---|---|---|---|---|
| `0916_100Hz_v1` | roll / pitch | **−0.51 / −0.16** | 10 ms（探索下限） | 0.96 / 0.99 |
| `0919_v5` | roll / pitch | 0.75 / 1.27 | 105 / 155 ms | 0.96 / 0.96 |
| `0919_v8` | roll / pitch | **1.44 / 0.94** | 80 / 120 ms | 0.93 / 0.96 |

⚠ **γ が −0.51〜+1.44 に散らばり（負のゲインは物理的にありえない）、残差分散比 0.93–0.99
＝ モデルが説明できるのは 1–7 % しかない。τ も探索範囲の端に張り付く。⇒ 情報が無い。**

⚠⚠ **これはリポジトリに既に記録のある失敗である。**
[`20260905_damping_unidentifiable_flight_logs.md`](20260905_damping_unidentifiable_flight_logs.md) と
`docs/rotational_damping_sysid.md`（「入力トルクと機体応答の対応付けが成立していない」「推力倍率の中央値 0.032/0.043」）が
**閉ループ飛行ログからの回帰は成立しない**と結論していた。
`20260906_bench_excitation_mode.md` はまさにそれを避けるために開ループ加振モードを作った。
**私はその記録を検索せずに同じ回帰をやり、同じ穴に落ちた。**

⇒ **`T_max` は現状でよい。ループゲインが設計より高いという主張は、根拠が無い。**

## 実験なしで新しく分かったこと: v8 の Δu は 83 % が 5 Hz 超

`Δu` を モーメント写像 `B`（3×6）の行空間とヌル空間に分解し、スペクトルも取った:

| ログ | モーメント生成 | ヌル空間 | 0–2 Hz | 2–5 Hz | **5–15 Hz** | **15–40 Hz** | 40–50 Hz |
|---|---|---|---|---|---|---|---|
| `0919_v8`（貨物） | 90.8 % | 9.2 % | 10.5 % | 5.3 % | **46.6 %** | **36.7 %** | 1.8 % |
| `0919_v5` | 92.5 % | 7.5 % | **78.0 %** | 9.6 % | 16.1 % | 8.9 % | 0.5 % |
| `0916_100Hz_v1` | 64.9 % | **35.1 %** | 14.0 % | 10.7 % | 54.7 % | 17.4 % | 4.0 % |

- ⚠ 50 Hz チャタリング（`20260904_duty_chatter_50hz_nullspace.md`）は **v8 では解消**（40–50 Hz は 1.8 %）。
- ⚠⚠ **しかし v8 の `Δu` は 83 % が 5 Hz 超。** モータ遅れ 40–50 ms ＝ 帯域 3–4 Hz なので、
  **その帯域の指令は出しても機体は動かない。**
- ⇒ **v8 の「巡航 `|Δu|` 最大 0.336」は持続的なモーメント要求ではなく高周波の暴れ。**
  **box の余地を無駄に食っているだけ。** 前回「巡航ですら余地を使い切っていた」と書いた解釈は
  **「本当に必要だった」という意味ではない。**
- ⚠ これは回帰が失敗する理由でもある（入力エネルギーの大半が機体が応答できない帯域にある）。

## 対応（提案・未実装）

| # | 内容 | 根拠 |
|---|---|---|
| **1** | ⚠ **`T_max` は触らない。** 0.75 でも 0.81 でもベンチ実測と数 % 以内 | ③④ |
| **2** | **高周波指令を減らす。** ジャイロの LPF か `R_u` 引き上げ。⚠ LPF は位相遅れを足すので、入れるなら**帯域を 3–4 Hz より十分上**に置くこと | 本 decision の分光 |
| 3 | デサチュレーション（[`20260920_collective_sag_desaturation_design.md`](20260920_collective_sag_desaturation_design.md)） | 飽和の歪みを減らす |
| 4 | 貨物の取り付けを剛にする | 振り子仮説は依然未排除 |

⚠ **ゲインの同定はベンチ加振（`Bench_mode`）でしかできない。** 実験ができるようになるまで、
`T_max` / `R_u` を「同定結果」に基づいて動かすことはできない。

## 検証結果

- ④: `重量-推力計算.xlsx` の生データと 6 発実験で相互検証（−0.4 %）。**確定。**
- ③: 同データのフィット。**確定**（R² 0.999）。
- ②: **撤回**。grey-box の残差分散比 0.93–0.99 で情報が無いことを確認。
- 分光: 実ログ 3 便。⚠ **「高周波が悪さをしている」は相関であって因果の証明ではない。**
