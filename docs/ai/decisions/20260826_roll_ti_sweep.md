# ロール角度 PID の Ti は 10000 では効かない。実用値は 2〜5 秒

- **日付**: 2026-08-26
- **種別**: tuning
- **対象**: `Benzen_new/control.cpp:699`（phi_pid）, `program/sil/host/tune_roll_ti.py`
- **タグ**: #PID #ロール #Ti #積分 #チューニング #SIL #auto_maneuver #バンク角

## 背景 / 症状

M5 で「自動旋回のバンク角が指令 18deg に対し実 8.4deg（達成率 47%）」を発見し、
原因はロール軸の積分が旋回カップリングを打ち消せないことだと特定した
（[20260826_sil_m5_auto_maneuvers.md](20260826_sil_m5_auto_maneuvers.md)）。

これを受けてユーザーが `phi_pid` の `Ti` を **100000 → 10000** に変更した。
**しかし SIL で測ると達成率は 47% のまま、まったく変化しなかった。**

## 原因 / 判断根拠

`pid.cpp` の実装は標準 ISA 形式:

```c
m_integral = m_integral + m_h * (err + m_err) / 2 / m_ti;
return m_kp * (err + m_integral + m_differential);
```

`Ti` は**積分時間 [s]**。角度ループは `h = 0.01 s`。
1 ステップあたりの積分増分は `err * h / Ti` なので、

| Ti | 10 秒間（1000 step）での積分値 | 誤差 `err` に対する比 |
|---|---|---|
| 100000 | `err * 1e-4` | 0.01 % |
| **10000** | `err * 1e-3` | **0.1 %** |
| 5 | `err * 2` | 200 % |

**`Ti` が旋回時間（約 10 s）より桁違いに大きい限り、積分は存在しないのと同じ。**
100000 も 10000 も「積分なし」の側にいる。効き始めるのは `Ti` が
**maneuver の時間スケールに近づいたとき**である。

## 検証結果

`host/tune_roll_ti.py` で掃引した（Kp=1.0 固定、自動水平旋回の定常区間で平均）。

| Ti [s] | 実バンク | 達成率 | ステップ行過ぎ |
|---|---|---|---|
| 100000（元の値） | 8.39 deg | 47 % | 1.8 % |
| **10000（今回の変更）** | **8.39 deg** | **47 %** | — |
| 20 | 10.98 deg | 61 % | — |
| 10 | 12.88 deg | 72 % | — |
| **5** | **15.29 deg** | **85 %** | **13.5 %** |
| 2 | 17.55 deg | 98 % | 23.1 % |
| 1 | 17.91 deg | 100 % | 32.5 % |

**バンク達成率と行過ぎは明確なトレードオフ。**

### 推奨

**`Ti = 5` を出発点にする**（達成率 85%、行過ぎ 13.5%）。
バンク精度を優先するなら 3 付近まで下げられるが、行過ぎが 20% を超える手前で止めるのが妥当。
`Ti = 1` は達成率 100% だが行過ぎ 32.5% で、実機では姿勢の食いつきが強すぎる懸念がある。

**未検証**: 実機での挙動。SIL には ESC 一次遅れ・振動・センサノイズが入っていないので、
実機では行過ぎがこれより大きく出る可能性が高い。**保守側（Ti を大きめ）から入ること。**

## 対応

実機の `control.cpp` は**変更していない**（ユーザー判断待ち）。
代わりに SIL 側へ、実機を書き換えずにゲインを振れる仕組みを入れた。

- `sil_set_pid(which, kp, ti, td, eta, h)`: `phi/theta/psi/p/q/r` の PID を実行時差し替え。
  `phi_pid` 等は control.cpp の**非 static グローバル**なので外から触れる。
- `host/tune_roll_ti.py`: Ti 掃引。**1 プロセス 1 条件**（ファームがグローバル状態を持つため）
  なので条件ごとに子プロセスを起動する。

## 次に触る人へ

- ⚠ **`Ti` は「大きいほど積分が弱い」。** 桁を 1 つ動かした程度では何も変わらない。
  効かせたいなら **maneuver の時間スケール（秒オーダー）** まで下げること。
- ⚠ **SIL でゲインを変えても実機には反映されない。** `control.cpp:699-701` を手で直す。
- ピッチ側は既に `Ti = 10000` だが、こちらも同じ理由で積分は効いていない。
  ピッチが指令 -12deg に対し -15deg 行くのは積分ではなく `Kp=1.6` とカップリングの結果。
  **ピッチも同様に見直す価値がある。**
