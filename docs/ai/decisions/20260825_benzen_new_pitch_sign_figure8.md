# 前傾を機首下げにし、8の字を左右一周へ変更

- **日付**: 2026-08-25
- **種別**: design
- **対象**: `program/pico/pico-sdk2/pico-sdk/Benzen_new/auto_maneuvers.{hpp,cpp}`
- **タグ**: #Benzen_new #PID #auto_maneuver #pitch #figure8

## 背景 / 症状

正の `forward_pitch_deg` をそのまま `Theta_ref` に入れると機首上げになり、前進ではなく後退する。
8の字は `sin(2πt/T)` のため片ループの積分角が約 76° で、左右一周にならなかった。

## 原因 / 判断根拠

- ミキシング上、正の `Q_com` は前モータ増・後モータ減 → 機首上げ。前傾は負のピッチが必要。
- 正弦波ヨーの積分は `ω_max T / π`。デフォルトでは 360° に届かない。
- 左右一周にするには、各ループで `∫ r dt ≈ 360°` になるホールド付き波形が必要。交差点ではバンクとヨーを 0 へ戻す。

## 対応

- `forward_pitch_deg` は大きさのみ保持し、指令は `-deg`（機首下げ）で出す。
- 8の字を反対符号の協調旋回を2回連続する形に変更。各ループの envelope 積分が `turn_angle / yaw_rate` になるよう hold と交差ランプを組む。
- `loop_period_s` をやめ、`turn_angle_deg`（既定 360°）で一周を指定する。

## 検証結果

- `auto_maneuvers_test`: 前傾が負、交差点でロール/ヨー 0、第1ループ ≈ +360°、第2ループ ≈ −360° を確認。
- 実機軌道は未検証。

## 次に触る人へ

- `forward_pitch_deg` に負値を入れてもサニタイズで 0 になる。大きさは正で渡す。
- デフォルト 30°/s・360° だと片ループ約 12–13 s。周期を短くするなら `max_yaw_rate_deg_s` を上げる。
