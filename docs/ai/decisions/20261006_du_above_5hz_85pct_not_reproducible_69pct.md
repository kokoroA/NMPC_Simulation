# 「Δu の 85 % が 5 Hz 超」は再現しない。手順を固定すると 69 %。結論（0.336 は高周波の暴れ）は維持

- **日付**: 2026-10-06
- **種別**: investigation（数値の訂正）
- **対象**: `0919_v8.txt`（貨物あり巡航）／`20260920_tmax_mapping_and_curve_shape_closed_plant_gain_retracted.md` の帯域表
- **タグ**: #Benzen_NMPC #スペクトル #PSD #5Hz #モータ帯域 #du #再現性 #訂正 #v8

## 背景
会話で「v8 巡航の指令 Δu は約 85 % が 5 Hz 超」と述べた。ユーザから出どころとグラフでの提示を求められた。

## 出どころ（確認済み）
`20260920_tmax_mapping_..._retracted.md` の帯域表（v8: 0–2 Hz 10.5 / 2–5 Hz 5.3 / 5–15 Hz 46.6 / 15–40 Hz 36.7 / 40–50 Hz 1.8 %）。
- 85 % ＝ 46.6+36.7+1.8（40–50 Hz まで含めた合計）。decision 本文の見出しは 83 %（40–50 Hz を除いた値）。
- ⚠ **表を作った時の窓・FFT 設定は記録されていなかった。**

## 再計算（今回）
`du = u_i − u_base`、巡航 t=5.0–10.3 s、Welch（Hann 256 点・50 % overlap・セグメントごとに平均値を除去）、6 モータ平均。
スクリプトは `Benzen_NMPC/tools/du_spectrum.py`、図は `docs/figs/20261006_du_spectrum_v8.svg`。

| f 以上の割合 | 1 Hz | 3 Hz | **5 Hz** | 10 Hz | 20 Hz |
|---|---|---|---|---|---|
| v8 貨物あり | 83.4 % | 73.7 % | **69.2 %** | 51.9 % | 36.4 % |
| v6 巡航（t=4–14 s） | 75.2 % | 61.4 % | 53.8 % | 27.3 % | 17.7 % |

- 行空間の比率は **90.5 %**（記録値 90.8 %）で再現する ⇒ 窓はほぼ同じ。
- しかし帯域の割合は再現しない。全周期 FFT／Welch 512–32 点／du・行空間成分を総当たりしても 5–15 Hz は 30–38 %（記録値 46.6 %）。**5 Hz 超は設定次第で 67–84 % まで動く。**
- ⇒ **「85 %」は再現できない数値。手順を固定した値として 69 % を使う。**

## 設定に依らない根拠
FR モータの生の最大 |du| = **0.336** は、4 Hz の zero-phase LPF をかけると最大 **0.110**（約 3 分の 1）まで落ちる。rms は 0.0433 → 0.0238。
PSD のピークは 5–25 Hz にあり、モータ帯域 3–4 Hz の外側にある。
⇒ 「0.336 は持続的なモーメント要求ではなく、モータが追従できない高周波の暴れ」という結論は維持する。言い方は「約 7 割」に改める。
