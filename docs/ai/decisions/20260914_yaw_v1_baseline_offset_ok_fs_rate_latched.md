# 0914_yaw_V1：オフセットは無い（真の静止窓で −0.01 deg/s）。見えたのは実回転。FS_RATE がラッチしていた

- **日付**: 2026-09-14
- **種別**: investigation
- **対象**: `Benzen_NMPC/tools/0914_yaw_V1.csv`（逆さ吊り・モータ OFF・手回し）、`docs/20260905_yaw_damping_experiment_protocol.md` フェーズ⓪
- **タグ**: #Cr #yaw #sysid #bench #failsafe #bias #軸受 #tau_f #Pico

## 背景 / 症状

要領書フェーズ⓪（モータ OFF ベースライン）を実施。
「回転が止まった後も `r` が 1 くらい残っている気がする＝ジャイロオフセットがあるのでは」との申告。

ログは **10 Hz のシリアル `#nmpc_bench` CSV**（100 Hz リングログではない）、929 行、114.7 s。
`u_fr..u_rl` は全区間 0、`nmpc=0`、`loop_us≈1.6 ms` → 加振モードでモータ停止のまま手回し、で整合。

## 原因 / 判断根拠

### (1) オフセットは無い。申告された「1」は**機体が実際に回っていた**

| 区間 | `r` 平均 | std | 解釈 |
|---|---|---|---|
| t = 5–8 s | **−0.010 deg/s** | 0.133 | **真の静止窓。95% 区間 ±0.05 deg/s** |
| t = 9–13 s | +0.31 → **+0.96** | 0.07（プラトー部） | 4 秒かけて滑らかにランプし平坦化 |

定数オフセットはランプしない。**+0.96 は実回転**。
加えて **1 deg/s = 6 分で 1 回転**で、目視では完全に停止して見える。
本ログは `r = −42.5 deg/s` で終わっており**まだ止まっていない**（同定結果からの外挿で
42.5 → 1 deg/s にさらに 32 s）。

→ 要件（[`20260914_yaw_hang_test_poweron_orientation_and_failsafe.md`](20260914_yaw_hang_test_poweron_orientation_and_failsafe.md) の `ε ≲ 1 deg/s`）を**1 桁以上クリア**。
**逆さ吊りのまま静止させて電源投入、という手順が正しかったことの実測確認。**

### (2) 単一符号の減衰では、定数オフセットは `Cr` を**理論上まったく汚さない**

前回 `Cr` 誤差 ≈ 0.75·ε と見積もったが、**これは過大だった。**
減衰区間で `r` の符号が変わらない場合 `∫|r|dt = |∫r dt|` なので、`r̃ = r − ε` としたとき

```
col1 = dt                    （変化なし）
col2 = −∫r̃ dt  = col2 + ε·col1
col3 = −∫r̃|r̃|dt = col3 + 2ε·col2 + ε²·col1
```

と、**摂動が col1, col2 の張る空間に完全に収まる**。最小二乗の第 3 係数（`Cr/Iz`）は**厳密に不変**。
実データで ε = ±1 deg/s を入れ直しても `Cr/Iz = 2.18928e-03` が 6 桁一致した（数値的にも確認）。
ε は `b` と `tau_f` にのみ吸収される。⚠ **`r` がゼロを跨ぐと成立しない。**

### (3) ⚠ FS_RATE（角速度 360 deg/s）がラッチしていた

`t = 16.91 s`、`r = −408.2 deg/s` で `failsafe` が 0 → **4 (FS_RATE)** に遷移、以後最後まで 4。
`|r| > 360 deg/s` のサンプルは 49 個。ピークは −411.4 deg/s。

今回はモータ停止・手回しなので実害なし。ただし**加振モードでも角速度判定は生きている**
（無効化されているのは姿勢判定だけ）。本番のフェーズ②〜④で踏むとモータが止まり、
解除は一度ディスアームするまでできない。要領書 §10 の「250 deg/s を超えたら加振をやめる」は
安全上の話として書かれているが、**ファーム上の上限は 360 deg/s** であることを明記する必要がある。

### (4) 軸受は合格。`tau_f` はボールベアリング級

**411 → 42.5 deg/s に 97.5 s、なお回転継続。**
要領書 §8 の判定（10 s 以内で停止＝不合格 / 30 s 以上＝合格）を大幅にクリア。

積分形回帰（窓 4 s・50% オーバーラップ・欠測跨ぎ除外、n=38）:

| 量 | 値 | 窓幅 2/3/4/6 s での振れ |
|---|---|---|
| `tau_f/Iz` | **2.0e-2 rad/s²** (= 1.15 deg/s²) | 1.97–2.15e-2 |
| `b/Iz` | **6.5e-3 1/s**（時定数 ≈ 155 s） | 5.5–7.1e-3 |
| `Cr_base/Iz` | **2.3e-3 1/rad** | 2.1–2.5e-3（±15%） |

正規化後の条件数 **18.8**（生の条件数 82 は列スケール差によるもので、判定に使ってはいけない）。
残差 rms 2.1 deg/s。

絶対値換算（`Iz` が未実測で 3.9 倍不確かなため両方を書く）:

| `Iz` | `tau_f` | `Cr_base` |
|---|---|---|
| 3.0e-3（`nmpc_params.hpp`） | **5.9e-5 N·m** ← ボールベアリング級 (5.0e-5) | 6.9e-6 |
| 11.6e-3（`NMPC_REPORT.md`） | 2.3e-4 N·m ← 平軸受 μ=0.3 (1.8e-3) よりずっと良い | 2.7e-5 |

→ **機体単体の二乗減衰の床は `Cr ≲ 3e-5`**。飛行ログ上界 `2.1e-4` の 1/10、
`nmpc_params.hpp` の仮値 `0.005` の 1/200 以下。ロータ分がこれに上乗せされる。

### (5) ⚠ 要領書 §5-4 のサニティチェックは、摩擦が支配的だと使えない

`−rdot/|r|` vs `|r|` は **66–376 deg/s で平坦**（0.019–0.026、R² = 0.05、トレンド無し）。
要領書は「直線になればモデルの形が正しい / 曲がればモデルが違う」としているが、
今回は**モデルは正しいのに平坦**になった。Coulomb 項（この座標で右下がり）と
二乗項（右上がり）がほぼ相殺するため。3 項を代入すると平坦性が数値的に再現できる。

→ この判定法は**要領書 §5-4 が断っているとおり「摩擦が小さければ」の条件付き**であり、
今回のデータには適用できない。有効な判定は**残差 rms と窓幅感度**。

### (6) ⚠ 約 7.5° 傾いて吊れている

`sqrt(p²+q²)` / `|r|` の比が全速度域で一定:

| `\|r\|` [deg/s] | 40–80 | 80–130 | 130–200 | 200–280 | 280–420 |
|---|---|---|---|---|---|
| 傾き角 α [deg] | 7.6 | 7.4 | 7.3 | 7.1 | 8.2 |

速度に依らず一定＝**動的なぶれではなく固定的な幾何の傾き**（3 本の長さ違い）。
影響: `(Iy−Ix)·p·q / Iz` の**平均**が +3.1e-3 rad/s²（rms 6.2e-3）で、総減速の 7–16%。
理論上は零平均のはずが、10 Hz サンプリング（スピン ≈ 1 Hz）での位相バイアスと
コーニングの非円形性で残っている。**要領書の「3 本吊りで p=q=0 を構造的に作る」は未達成。**

## 対応

要領書へ反映すべき事項を確定した（本 decision が根拠、本文修正は未実施）。

1. §10 に「ファーム上の角速度フェールセーフは **360 deg/s**。手回しでも容易に超える」を明記
2. §5-4 に「摩擦が支配的なときは平坦になる。この判定は摩擦が小さいときのみ」を追記
3. §2 に「3 本の長さを揃え、傾き α を 2° 以下にする」を追記（今回 7.5°）
4. §9 のロギング指針を分ける:
   - **フェーズ②（立ち上がり 0.15–0.5 s）は 100 Hz リングログ**。10 Hz では 3–5 点しか取れず不足
   - **フェーズ⓪（モータ OFF ベースライン）は 10 Hz シリアル**。減衰が 100 s 級でリング 21.8 s に入らない
   - **フェーズ④（本計測）はリングで足りる見込み**。`Cr = 1e-4`・`Iz = 3.0e-3` なら
     200 → 90 deg/s は約 10.5 s（`t = (Iz/Cr)(1/r₁ − 1/r₀)`）。ロータ有りの減衰は
     今回のモータ OFF（同区間 38 s）より大幅に速い

### 却下した案

- **ベースラインも本計測も 3 パラメータで解いて引き算する**: `tau_f` は軸受由来でロータの有無に依らないので、
  同じ量を 2 回推定して差を取ることになり、誤差だけが 2 倍に増える。
  → **ベースラインは曲線のまま引き、残差を `(b_rot/Iz)r + (Cr/Iz)r|r|` の 2 パラメータで解く。**
  実データ上で摩擦列を落とすと正規化条件数が 18.8 → 6.0 に改善することを確認した（本計測は未実施なので見込み）。
- **`ε` を後処理で差し引く**: (2) より単一符号の減衰では `Cr` に影響しないので不要。
  `b`/`tau_f` の絶対値が要るときだけ行えばよい。
