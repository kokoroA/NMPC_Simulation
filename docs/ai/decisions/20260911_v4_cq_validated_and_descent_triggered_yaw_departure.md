# v4: CQ 補正は飛行データで裏付けが取れた（比 2.53 → 0.95）。後半の「ピクつき」は降下直後のヨー departure

- **日付**: 2026-09-11
- **種別**: investigation
- **対象**: `tools/0911_100Hz_v4.csv`, `nmpc_params.hpp`(CQ, delay_comp_steps, rebuild_max_u_hover, Q_r)
- **タグ**: #Benzen_NMPC #飛行実験 #0911_v4 #CQ #C_QT #ヨー #departure #降下 #後流 #フル再構築 #ストール #loop_us #追従性能

## 背景 / 症状

`CQ` 5.8e-9→1.2e-8 と `delay_comp_steps` 4→6 を入れた飛行
（[`20260911_cq_lumped_yaw_authority_and_delay_comp6.md`](20260911_cq_lumped_yaw_authority_and_delay_comp6.md)）。
ユーザ報告: **「追従性能と安定性は格段に上がった。しかし後半に少しピクつく／振動のような挙動」**。
19.2 s、`failsafe=0` 通し、`ekf_reset=0`、`lambda_reset=0`、`nonfinite=0`、`pred_nonfinite=0`、最後は着陸。

## 原因 / 判断根拠

### (1) 追従性能の改善は本物。しかも劣化は後半 3 秒だけに局在している（確認済み）

飛行区間を降下前後で割ると別物になる。

| 区間 | roll 相関 | 振幅比 | 追従誤差 rms | p rms |
|---|---|---|---|---|
| **t=6–15（降下前）** | **0.80** | **0.90** | **1.57 deg** | 7.1 deg/s |
| t=15–18（降下後） | 0.25 | 3.15 | 7.68 deg | 45.3 deg/s |

機種間比較（浮上区間全体、`u_base>0.45`）。**振幅比 1.0・相関 1.0 が理想。**

| | roll 相関/振幅比 | pitch 相関/振幅比 | p rms | 2–5 Hz 占有 | r 平均 |
|---|---|---|---|---|---|
| v2 (Q_phi=150) | 0.22 / 0.81 | −0.14 / 0.85 | 38.8 | 13 % | +2.3 |
| v3 (Q_phi=600, DC4) | 0.14 / 2.64 | 0.37 / 1.10 | 35.0 | 42 % | −6.7 |
| **v4 (CQ 2×, DC6)** | **0.45 / 1.71** | **0.41 / 1.70** | **23.9** | 17 % | −3.6 |

v3 の「振幅比 2.64・相関 0.14＝追従ではなく発振」が解消し、2–5 Hz 帯も 42 %→17 % に戻った。
**降下前だけを見れば相関 0.80・振幅比 0.90 で、新ソルバとして初めてまともに舵が効いている。**

### (2) `CQ` の 2 倍補正は飛行データで裏付けが取れた（確認済み）

同一手法（`r|r|` 減衰とバイアスを含む回帰）でヨー権限を再同定した。**実測/モデル比が 1.0 なら正しい。**

| ログ | モデルの `C_QT` | 実測/モデル比 | R² |
|---|---|---|---|
| 0911_v2 | 0.0111 | 1.61 | 0.19 |
| 0911_v3 | 0.0111 | 2.53 | 0.46 |
| **0911_v4** | **0.0230** | **0.95** | 0.24 |

「実測比 3 倍のうち 2 倍だけ寄せる」判断は結果的に正しかった。R² が低いのは
ヨー角加速度の大半が指令以外（外乱）で説明されるためで、比の推定そのものは 3 本で整合している。

### (3) 「ピクつき」の起点は降下 → ヨー departure（推測、ただし時系列は明確）

時系列（確認済み）:

| 時刻 | 何が起きたか |
|---|---|
| 〜14.9 s | 安定。`phi_ref −8 deg` を `phi −8.9 deg` で追従（誤差 1 deg 級） |
| **14.91 s** | **スロットル低下 `u_base` 0.612 → 0.567（−7 %、約 1 秒保持）= 降下** |
| 15.5–16.1 s | `r` が −3.6 → **−39.7 deg/s** へ departure。`psi_ref` は +1.8 deg/s（＝操縦ではない） |
| 16.1–17.2 s | ロール・ピッチが暴れる。`p` 最大 +153 deg/s、`q` +63 deg/s |
| 17.8 s | パイロットがスロットルを切り着陸 |

- **`|r|` が `|p|` の包絡を 0.75–1.00 s 先行する（相関 0.82–0.83）。** ヨーが先、ロールが後。
- 同じ大きさのスロットル低下は t=12.52 にもあったが、**即座に戻した**ため何も起きていない。
  14.91 の方は約 1 秒低いままだった。`acc_norm` の標準偏差も 0.61（t=6–15）→ 0.92（t=15–18）に増える。
- **推測: 降下で自機後流に入り、ヨーを主とする乱れを受けた。** 確定していない。
  対立仮説は外部外乱・機体の非対称（モータ/プロペラ）。**切り分けは次項の試験で行う。**
- ヨー差動 `Σ kS·u` は 0.024（t=6–12）→ **0.124 平均 / 0.267 p95 / 0.90 ピーク**（t=15–18）。
  釣り合いから逆算した未説明のヨートルクは **−25〜−87 deg/s²**。これは操縦入力では説明できない。
- `r` は EKF ではなくジャイロ直値（`Wr − Rbias`、`ekf_br` は 0.34 deg/s）。**推定器の問題ではない。**

### (4) フル再構築の 40 ms ストールは「増幅器」であって起点ではない（ホストで確認済み）

ログ中の `loop_us > 20 ms` は 30 回、**すべて `solver_code` の path=1（フル再構築）**で 37–41 ms。
`iter_us` を除いた通常周期は mean 8.4 ms / p99 10.2 ms と健全。

- 周期再構築（`reset_period=100` ＝ 1 秒ごと）7 回、SR2 由来の追加再構築 23 回。
  **追加再構築は荒れている時に集中**（t=16–18 の 2 秒に 8 回）。その直前 20 サンプルの `|p|` は
  飛行平均の 1.97 倍、`|r|` 1.59 倍、`ulin_norm` 1.53 倍 — **荒れが再構築を呼んでいる**（逆ではない）。
- **却下**: 「ストールが振動の原因だから周期再構築を止める」。
  ホストで指令を 40 ms ホールドする試験を行った（ロール ±8 deg/0.4 Hz 追従）:

  | ストール | ロール追従誤差 rms | p 最大 |
  |---|---|---|
  | 無し | 3.55 deg | 18.1 deg/s |
  | 1.0 s ごと | 3.56 deg | 18.2 deg/s |
  | 0.5 s ごと | 3.56 deg | 18.4 deg/s |
  | 0.25 s ごと | 3.57 deg | 18.2 deg/s |

  **静穏時には実質無害。** 飛行ログでも周期再構築の同期平均は `|p|` 偏移 2.2 deg/s に留まる。
  そもそも `rebuild_max_u_hover` を 0.30 に戻す案は 0831_v3 で**既に否決済み**
  （周期再構築を止めたら飛行時間とともに操作性が単調劣化、`cycles_since_reset` と姿勢誤差の相関 +0.70）。
- **ただし荒れている時は話が別。** ストール時の `|p|` は t=6–15 で平均 7.0 deg/s（40 ms＝0.3 deg の漂流）
  だが t=15–18 では平均 42 / 最大 123 deg/s（**1.7 / 4.9 deg の無制御漂流**）。
  追加再構築の直後の `|Δduty|` は 0.0395 と通常周期の 3.3 倍。
  **荒れる → 再構築 → 40 ms 凍結＋大きな指令段差 → さらに荒れる、という正帰還の疑いがある（未検証）。**

### (5) `Q_r` を下げてヨーの取り分を減らす案は却下（ホストで確認済み）

「ヨーが duty を食ってロール権限を奪っている」という仮説を直接試した
（ロール ±8 deg/0.4 Hz 追従＋一定ヨー外乱、現行パラメータ）。

| Q_r | 外乱 0 | 外乱 25 deg/s² | 外乱 50 deg/s² |
|---|---|---|---|
| 40（現行） | 誤差 3.67 / ヨー率 +0.0 | 3.67 / +4.5 | 3.67 / **+9.1** |
| 20 | 3.68 / +0.0 | 3.67 / +7.3 | 3.67 / +14.6 |
| 10 | 3.68 / +0.0 | 3.67 / +12.1 | 3.67 / **+22.7** |

**ロール追従誤差は Q_r に一切依存しない（3.67 deg で不変、飽和 0 %）。**
必要なヨー差動は 50 deg/s² の外乱でも 0.052 しかなく、duty を奪う量ではない。
`Q_r` を下げても**ヨードリフトが 2.5 倍悪化するだけ**。この方向は捨てる。

## 対応

**本ログに対するパラメータ変更は行っていない。** 降下前の飛行品質（相関 0.80 / 振幅比 0.90 /
誤差 1.57 deg rms）は現行パラメータの実力であり、これを動かす根拠がない。

次にやるべきは**切り分けの飛行**であって重みの調整ではない。

## 検証結果

上記 (1)〜(5) のとおり。ホスト試験は出荷ソース（`nmpc.cpp` / `nmpc_model.cpp` 無改変）に対して実施。
**降下＝後流という因果は未確定。** 現時点では「スロットルを約 1 秒下げたまま保持した直後に
ヨーが departure した」という時系列と、`acc_norm` のばらつき増加が根拠。

## 次に触る人へ

- **次の飛行は高度一定で行うこと。** スロットルを下げたまま保持しない。
  それでヨー departure が出なければ降下（後流）説が強まり、出れば機体の非対称・外乱側を疑う。
- **ヨー departure だけを狙った試験**: 高度一定・スティック中立で 30 秒ホバーし、`r` の
  ドリフト量と `Σ kS·u` を見る。定常で `Σ kS·u` が 0.05 を超えるなら機体に恒常的な反トルク非対称がある。
- **`loop_us` の 40 ms は残っている。** 静穏時は無害だが、荒れている時に 5 deg の漂流を生む。
  根治は `N` 短縮か**再構築の複数周期への分割**（`20260910_sr2_bad_c_rebuild_storm.md` 末尾と同じ結論）。
  `rebuild_max_u_hover` を下げる案は 0831_v3 で否決済みなので蒸し返さないこと。
- **ロール/ピッチの実測/モデル比は 0.40–0.42 と出た（R² 0.10 と低く未確定）。**
  もし本当なら設計より効きが 2.4 倍弱いことになり、`Q_phi=600` が必要だった理由と整合する。
  ヨーと同じく**吊るして既知の duty 差動を与える同定**で決着させるべき。
