# 再アーム時の EKF 再初期化と離陸ゲートを実装し、R_u を 1200→800 に戻した

- **日付**: 2026-09-10
- **種別**: design | bugfix | tuning
- **対象**: `control.cpp`(ekf_reinit_on_arm / 離陸ゲート / led_control / 400Hz 出力 / nmpc_run)、`nmpc_params.hpp`(R_u)
- **タグ**: #Benzen_NMPC #EKF #偽の傾き #再アーム #離陸ゲート #四元数 #加速度計 #R_u #遅れ補償

## 背景

[`20260910_v11_post_crash_ekf_and_slow_mode.md`](20260910_v11_post_crash_ekf_and_slow_mode.md) の提案 1・2 をユーザが選択。

## 1. 再アーム時の EKF 再初期化

**根本原因（コードで確認）**: `Arm_flag==3`（アーム解除中）では 100 Hz の `angle_control` が動かない
（`sem_release` は `Arm_flag==1/2` の枝にしかない）。**EKF は転倒姿勢のまま凍結し、再アームで
「転倒姿勢から水平へ収束し始める」。** 地上では `Phi_bias = Phi` が毎周期走るので姿勢表示は 0 に見えるが、
**収束の速度は消えない**。離陸で `Phi_bias` が凍結した瞬間、その速度（毎秒 3-8 度）が偽の傾きとして現れる。

**対応**: `LockMode 1 → 2`（アーム成立）で `ekf_reinit_on_arm()` を呼ぶ。

- **四元数を加速度計から復元**。EKF の観測式（`ekf.cpp observation_equation`）は
  `z(0..2) = g·[e13, e23, e33]`、Euler 抽出は `Phi = atan2(e23,e33)`, `Theta = atan2(-e13, hypot(e23,e33))` なので、
  静止時は `Phi = atan2(Ay,Az)`, `Theta = atan2(-Ax, hypot(Ay,Az))` で直接求まる。
  `|‖a‖ − g| < 2 m/s²` のときだけ採用（動いていたら水平とする）。
  **ヨーは現在の推定値を引き継ぐ**（0 に落とすと磁気残差が跳ね上がり、その収束が roll/pitch を揺らしてゲートが長引く）。
  ⚠ `Arm_flag==3` では `sensor_read()` が呼ばれず `Ax/Ay/Az` は墜落時の値のままなので、関数の先頭で読み直す。
- ジャイロバイアス状態を起動時静止平均 `Pbias/Qbias/Rbias` へ。
  ⚠ 既存の `ekf_reinit()` は `Xe(4..6)` を **0** にしており、これは「バイアスが 0」という誤った主張。
  静止平均を入れるのが正しい（`Arm_flag==1` の初期化と同じ）。今回の新関数では修正済み。
- 共分散 `P` を単位行列へ、ドリフト検出器の LPF と差分基準を再シード。

## 2. 離陸ゲート

再初期化から **1.5 s**（LPF τ=0.3 s の 5 倍）待ってから判定を始め、
`|d(Phi)/dt − φ̇_gyro| < 1 deg/s` かつ同ピッチが **1.0 s 連続**で成立したらゲートを開く。
開くまで **400 Hz 側で `motor_stop()`**（スロットルを無視）、LED は**赤の速い点滅（5 Hz）**。
NMPC も止める（warm-start と遅れ補償の duty 履歴が「出していない指令」で育つのを防ぐ）。
ベンチ加振モードは姿勢推定を使わないので対象外。
開かないまま飛べないのは意図した安全側の挙動。`#arm_gate: reinit= wait_ms=` をログヘッダに出す。

**閾値の妥当性（全 0910 ログの地上フェーズで照合）**: 「両軸とも残差 < 1 deg/s」の最長連続時間

| 飛行 | 両軸 <1 の割合 | 最長連続 | 飛行中ドリフト | 期待 |
|---|---|---|---|---|
| v7-1 / v7-2 | 100% / 89% | 0.9 s※ / **1.4 s** | 健全 | 通す |
| v8-1 | 96% | **3.8 s** | 健全 | 通す |
| v9-1 | 81% | **1.5 s** | 健全 | 通す |
| v6-1 / v6-2 | 0% / 7% | 0.0 / 0.1 s | ★偽の傾き | 止める |
| v10-2 / v10-3 | 4% / 8% | 0.1 / 0.1 s | ★偽の傾き | 止める |
| v11-1 | 49% | 0.5 s | ★偽の傾き | 止める |

※ v7-1 は地上フェーズ自体が 0.9 s で終わっている（記録の都合）。

**1.0 s の hold で健全（1.4-3.8 s）と偽の傾き（0.0-0.5 s）が完全に分離する。**
なお記録はいずれも**アーム時再初期化なし**の値なので、再初期化後は健全側の残差がさらに小さくなる見込み。

## 3. `R_u` 1200 → 800

遅れ補償で速いモードの余裕ができたので、姿勢側の減衰を戻す（v11 の 0.67 Hz の遅い振動対策）。
ホスト格子（遅れ補償 4 周期、モータ 50 ms、機体効き 2-3× × 純遅延 3-7 周期、計 6 条件）:

| R_u | 結果 | K角 / K率 [/deg, /(deg/s)] |
|---|---|---|
| 1200 | 6/6 収束 | 0.335e-3 / 0.287e-3 |
| **800** | **6/6 収束** | **0.432e-3 / 0.375e-3** |
| 500 | 4/6 収束、2 条件で発散傾向 | 0.570e-3 / 0.497e-3 |
| 320 | 同様 | 0.724e-3 / 0.635e-3 |

800 が「遅れに対する余裕を保ったまま最も姿勢ゲインが高い」点。

## 検証結果

- **四元数・加速度の符号規約を数値で確認**: 生成した四元数を `control.cpp` の Euler 抽出式へ通した往復誤差
  最大 **3.0e-7 rad**、`ekf.cpp` の観測式が返す加速度から逆算した roll/pitch の誤差 最大 **1.5e-7 rad**
  （φ,θ を ±60°、ψ を ±180° で走査）。右へ 20° ロール → `atan2(Ay,Az) = +20.00°` も確認。
- 出荷ソースのホスト検証: 整合ゲイン 0.432e-3 / 0.375e-3、閉ループ 6/6 収束、
  記録状態リプレイ（v8/v10/v11）で `nonfinite` 0-1・補償棄却 0-5 回・`|U_lin|max` 2.3-4.5。
- ゲート閾値を全ログの地上フェーズで照合（上表）。
- `cmake --build build_fresh` 成功、`text 682096 / bss 422356`。CRLF/LF 整合。
- **実機未検証。**

## 次に触る人へ

- ⚠ **アーム後、LED が赤の速い点滅の間はスロットルを上げても回らない。** 通常 2.5-4 秒で消える。
  消えない場合は推定器かセンサの異常なので、飛ばさずに電源を入れ直す。
- ⚠ 既存の `ekf_reinit()`（非有限時の最後の砦）は `Xe(4..6)=0` のまま残っている。
  発火したらバイアスが失われるので、そちらも静止平均へ直すべき（今回は範囲外）。
- v11 の 0.67 Hz の遅い振動（角速度と同相の未説明トルク）は未解決。`R_u=800` は緩和であって根治ではない。
