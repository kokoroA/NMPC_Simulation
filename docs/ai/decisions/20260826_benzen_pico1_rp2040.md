# Benzen_pico1 を Pico 1（RP2040）向けに切り出し

- **日付**: 2026-08-26
- **種別**: design
- **対象**: `program/pico/pico-sdk2/pico-sdk/Benzen_pico1/`
- **タグ**: #Benzen_pico1 #Pico #RP2040 #CYW43 #テレメ

## 背景 / 症状

`Benzen_pico1` は `Benzen_new`（Pico 2 W / RP2350）のコピーであり、`PICO_BOARD=pico2_w` のままでは Pico 1 に書き込めない。
UF2 family は Pico 2 W が `0xe48bff57`（RP2350-ARM-S）、Pico 1 は `0xe48bff56`（RP2040）。

## 原因 / 判断根拠

- Pico 1 は RP2040。CYW43 が無く、Wi-Fi AP + UDP テレメは動かない。
- Pico 1 のオンボード LED は GPIO25。Pico 2 W の CYW43 LED / `pico_cyw43_arch_*` は不要。
- RP2350-E9（PWM 入力バッファ無効化）は RP2040 には無い。
- Pico 1 既定 SYSCLK は 125 MHz。PWM `wrap=3124, clkdiv=100` の 400 Hz は既定のまま成立する。
- SRAM は 264 KB。`Logdata` は残した（制御に使う USB ダンプ経路）。Wi-Fi 削除後 bss=210,644 B で主 RAM 256 KB に収まる。

却下: `pico_w` のまま CYW43 を残す案（リアルタイムテレメを消す指示と矛盾）。`LOGDATANUM` 縮小は SRAM が余ったので不要。

## 対応

- `PICO_BOARD pico` を CMake で強制。CYW43 / lwIP / dhcpserver / `wifi_telemetry` を削除。
- `board_led` は GPIO25 直叩き。`request`/`poll` の呼び出し側は維持。
- PWM の E9 workaround と `pwm_pins_early_init` を削除。モータ GPIO 割り当ては変更しない。

## 検証結果

- `build_fresh` で `pico_copter` ビルド成功。
- `PICO_BOARD=pico`, `PICO_PLATFORM=rp2040`。
- UF2 family ID `0xe48bff56`（RP2040）。
- SRAM: text 397,804 / bss 210,644。RAM overflow なし。
- 実機書き込み・飛行は未検証。

## 次に触る人へ

- 書き込む UF2 は `Benzen_pico1/build_fresh/pico_copter.uf2`。Pico 2 W には入れない。
- 対象は **非 W の Pico 1**。Pico W が必要なら `PICO_BOARD=pico_w` と CYW43 LED が別途要る。
- 飛行ログは USB シリアルの `log_output()` のみ。Wi-Fi テレメは無い。
