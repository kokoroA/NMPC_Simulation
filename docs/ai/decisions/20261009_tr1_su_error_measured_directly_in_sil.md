## 背景

ユーザ依頼「Su を毎周期作り直す修正について詳しく解説する資料を作成して」。
前回の decision（`20261008_solver_bursts_come_from_tr1_sr2_updates_su_exact_fixes.md`）では、
「更新が Su/H を壊す」機構が**推測**どまりだった。資料で説明するために直接測った。

## 方法

`nmpc_step` で ADMM の直前に、同じ (x0, U_lin) から厳密な Sx・Su・H を作り、ソルバが使うものと比較した（ソルバの状態は不変。飛行結果はこれまでの SIL と同一）。
条件は full プラント・shake・seed 0〜2、`NMPC_SU_EXACT=0` と `1`。通常周期は約 5,500。

## 確認済み事実（TR1/SR2、中央値 / p95 / 最大）

- Su の相対誤差: 25 % / 119 % / 256 %。再構築からの周期数に比例して増え、1〜9 周期で 8 %、60〜100 周期で 40 %。
- **更新しない場合（直前の再構築の Su のまま）の誤差は 5.7 % / 23 % / 71 %。経過時間によらず約 6 %** → TR1 は「何もしない」の 1.2〜5.5 倍悪い。
- Su の右上（非因果）ブロックのエネルギー割合: 9 % / 30 % / 43 %（厳密値は 0）。
- H の相対誤差（SR2 更新）: 49 % / 336 % / 673 %。Su 厳密版の H（1 秒古いだけ）は 8.7 % / 23 % / 44 %。
- 制約なしの解の向き cos: TR1/SR2 0.959（中央値）、cos<0.9 が 37 %、最小 −0.40。Su 厳密版は 0.998、cos<0.9 が 0.05 %、最小 0.81。
- 逆向き指令（先頭段のモーメント、|s|>20 deg/s）: TR1/SR2 ロール 2.7 % / ピッチ 4.1 %。**Su だけ厳密にしても SR2 の H のままだと 1.4 % / 3.3 %**。Su 厳密版は 0 % / 0 %。
- 厳密 Su の 1 周期の変化: 4.2 % / 9.9 %。最良のランク 1 で表せる割合は 81 %（p5 52 %）。割線 ‖s‖² に占める s_x の割合は 75 %（p95 97 %）。

## 解釈

- 飛行中の真の Su は平均の周りを行ったり来たりする（1 周期 4 %、1 秒でも 6 %）。TR1 はその揺れをランク 1 で追いかけて、誤差を打ち消さずに積み上げる。
- 状態の変化（雑音を含む）が割線の大半を占めるのに、その残差を `r·s_uᵀ` として Su に書き込む（「状態由来の誤差を入力の効きの変化と解釈する」）。ここは数値の傾向と整合する**推測**。
- 外積は右上ブロックも埋める（測定で確認）。
- **H も SR2 で壊れるので、Su だけ直しても足りない**。今回の修正が H の差分更新もやめていることの根拠。
