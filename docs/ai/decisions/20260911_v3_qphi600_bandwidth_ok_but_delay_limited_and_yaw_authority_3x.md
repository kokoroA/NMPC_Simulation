# 0911_v3 (Q_phi=600): 帯域は狙いどおり 3 倍になり浮上 13.6 s（新ソルバ最長）。代償は 2 Hz の遅れ限界モード。ヨー権限はモデルの約 3 倍で、これがヨードリフトの正体

- **種別**: investigation | tuning
- **対象**: `0911_100Hz_v3.csv`、`nmpc_params.hpp`(Q_phi, Q_theta, Q_p, delay_comp_steps)、`physical::CQ`/`Iz`

## 結果: 狙いどおりに速くなった

| 指標 | v2 (`Q_phi=150`) | **v3 (`Q_phi=600`)** |
|---|---|---|
| 実効 K角（飛行回帰） | 0.428e-3 | **0.863e-3 (roll) / 0.908e-3 (pitch)** |
| 率/角 ＝ 閉ループ時定数 | 0.87 s | **0.30 s / 0.25 s** |
| ホスト step 63% / 90% | 0.74 / 1.76 s | **0.47 / 0.74 s** |
| 浮上時間 | 約 10 s | **13.6 s（新ソルバ最長）** |
| 推定ドリフト | −0.2/+0.3 | **−0.11 / +0.17 deg/s** |
| ソルバ | 健全 | `nonfinite=0`, `λ_reset=0`, loop p95 9.78 ms |

離陸ゲート（`wait_ms=2493`）も EKF も引き続き健全。**「追従が速くなった」というユーザの体感は測定と一致する。**

## 代償: 2 Hz の遅れ限界モードが戻った

浮上中の `p` は **ピーク 1.99 Hz、2–5 Hz 帯 41%**（v2 は 7%）。
ロールの振幅比は **2.62** で相関は +0.15 — **指令より 2.6 倍大きく動いているが指令とは無相関**、つまり追従ではなく発振。

理由は明快で、ゲインを上げて交差周波数が上がり、実効遅れ 40–50 ms が効く領域（1–3 Hz）に入ったため。
減衰比自体は悪化していない（ζ ≈ 0.78 → 0.89）ので、**ゲインの問題ではなく位相の問題**である。

**破綻 2 件。**
- `t=15.56`: `p` が 1 サンプルで +2 → **−76 deg/s**（−7800 deg/s²、モータ上限 2400 の 3 倍）。直前は完全に静穏（`λ=0`, `tau_x=−0.004`）。物理接触かセンサ異常。`acc` は 11.2 止まりで断定できない。
- `t=17.36–18.0`: **ヨーの暴走**。`psi_ref=0` なのに `r` が −27 → **−72 deg/s** へ走り、同時に `p` が +19 → +198、`phi` が −3 → +35°。以後タンブルして斜めに着地。

## ヨードリフトの正体: モデルがヨー権限を 3 倍過小評価している

指令ヨートルク proxy → ヨー角加速度を実測（遅れ掃引）:

| ログ | 遅れ | 実測 [deg/s²/unit] | モデル比 | R² |
|---|---|---|---|---|
| 0911_v3 | 10 ms | 572 | **2.59×** | 0.11 |
| 0911_v2 | 20 ms | 667 | **3.02×** | 0.21 |
| 0910_v12 | 20 ms | 267 | 1.21× | 0.04 |

モデル値は `C_QT·T_max/Iz = 0.0111×1.04/3.0e-3 = 220 deg/s²/unit`。**実機は 2.6–3.0 倍**（R² は低いが 3 飛行で符号・桁が一致）。

**帰結**: `R_u` 支配の領域では制御ゲイン `K ∝ B_model`。`B_model` が 3 倍小さいので
**ヨーのループゲインは設計値の 1/3** になる。ヨー軸だけ極端に弱い制御になっており、
小さな非対称トルクでも `r` が伸びてしまう。ヨードリフトの符号と大きさが飛行ごとにばらつく
（+2.7 / −1.4 / −20.7 / +5.0 / −6.8 deg/s）のも、固定の機体非対称ではなく
**弱い制御が毎回違う外乱に負けている**ことと整合する。

`CQ` は 2026-09-04 に `3.0e-8 → 5.8e-9`（1/5）へ下げられている（[`20260904_yaw_qr_not_psiref.md`](20260904_yaw_qr_not_psiref.md)）。
実測が 3 倍なら真値は `CQ ≈ 1.7e-8` 付近で、**このときの下げ幅が行き過ぎていた**可能性が高い。

## 対応案（未適用）

### 1. ヨー: `CQ` を実測へ寄せる（最優先・ヨードリフトの根治）

`CQ` 5.8e-9 → **1.7e-8**（`C_QT` 0.0111 → 0.033）。これだけでヨーのループゲインが 3 倍になり、
`Q_r` を触らずにドリフトを押さえられる。**`Q_r` を上げるより副作用が小さい**（`Q_r` を上げると
duty 配分をロール・ピッチから奪う。[`20260904_yaw_starves_roll_pitch.md`](20260904_yaw_starves_roll_pitch.md)）。
⚠ ベンチでの `CQ` 再測定が本筋。上記は飛行ログからの逆算（R² 0.11–0.21）なので、まず 2 倍程度に留めるのが安全。

### 2. ロール・ピッチ: 帯域は維持したまま 2 Hz を潰す

ホスト（ロール 30° step、9 条件ロバスト = 機体効き 2–4× × 純遅延 3–7 周期、`R_u=800`）:

| 設定 | step 63% / 90% | 9 条件 収束 | 外乱 rms 最悪 | 外乱釣り合い時の静的剛性 |
|---|---|---|---|---|
| v2 `Q_phi=150, DC4` | 0.74 / 1.76 s | 9/9 | 6.3° | 0.324e-3 |
| **v3 `Q_phi=600, DC4`（現行）** | **0.47 / 0.74 s** | 9/9 | **24.3°** | 1.022e-3 |
| **候補A `Q_phi=600, DC6`** | 0.85 / **1.07 s** | **9/9** | **4.0°** | **1.017e-3** |
| 候補B `Q_phi=600, Q_p=40` | 0.60 / 1.03 s | 8/9 | 6.2° | 0.862e-3 |
| 候補C `Q_phi=300, Q_p=30` | 0.53 / 1.23 s | 9/9 | 11.2° | 0.520e-3 |

**候補 A（遅れ補償 4 → 6 周期）が最有力。** 静的剛性（＝指令追従の強さ）を v3 とほぼ同じ 1.02e-3 に保ったまま、
外乱時の姿勢 rms を 24.3° → **4.0°**（v2 の 6.3° より良い）に下げる。90% 整定は 0.74 → 1.07 s とやや遅くなるが
v2 の 1.76 s よりずっと速い。理屈も合う: ゲインを上げて交差周波数が上がったぶん、予測を 40 → 60 ms に伸ばして位相を買い戻す。

⚠ 実効遅れの同定値は 40–50 ms なので 60 ms は**過補償側**。ホストでは過補償の害は出ていないが、
`pred_nonfinite` と 1–3 Hz 帯の占有率を次の飛行で必ず確認すること。

### 3. `t=15.56` の 1 サンプル −7800 deg/s² を切り分ける

物理接触なら対策不要（低空を避ける）。センサ異常なら重大。次の飛行で `acc_norm` と同時に出るかを見る。
