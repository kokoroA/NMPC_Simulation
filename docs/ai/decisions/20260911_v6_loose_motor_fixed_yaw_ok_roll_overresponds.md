# v6: 緩んだモータを締めてヨーは解決。残るロール過応答は機上データでは同定できない（T_max を動かすな）

- **日付**: 2026-09-11
- **種別**: investigation
- **対象**: `tools/0911_100Hz_v6.csv`, `tools/0911_v6.csv`, `nmpc_params.hpp`(R_u, T_max, CQ)
- **タグ**: #Benzen_NMPC #飛行実験 #0911_v6 #ヨー #モータ緩み #過応答 #閉ループ同定 #Mp #共振 #R_u #T_max

## 背景 / 症状

`0911_v5` と同じソフトで、**緩んでいたモータ 1 個を締め直して**飛行。墜落せず着陸。

ユーザ報告: **「ヨーのドリフトが収まり、ヨー目標値にもそれなりに追従する。
ただしロールとピッチが目標値に過度に応答する／ゲインが高いような挙動。」**

`lambda_reset=0`, `nonfinite=0`, `pred_nonfinite=0`, `ekf_bias_reset=2`（v5 は 8 / 1 / 1 / 5）。

## 原因 / 判断根拠

### (1) ヨーは機械要因だった。v5 の診断が当たっていた（確認済み）

| | v5（緩み） | **v6（締め直し後）** |
|---|---|---|
| `r` 平均 | −12.10 deg/s | **−0.99** |
| `r` rms | 28.48 | **9.59** |
| `r` と `psi_ref` の相関 | −0.06 | **+0.55** |
| 定常ヨー率誤差 | −5.39 deg/s | +4.48 |
| \|Σ kS u\| 平均（ヨーに使った操作量） | 0.0782 | **0.0574** |

**追従するようになり、しかも使う操作量は減った。**
[`20260911_v5_yaw_untrackable_steady_disturbance_not_gain.md`](20260911_v5_yaw_untrackable_steady_disturbance_not_gain.md)
で推定した「CW/CCW 推力差 2.5 %＝モータ傾き 0.4° 相当の定常ヨー外乱」が実体を持っていた。
per-motor 回帰で **RR が 2 便とも突出して弱かった**ことも、点検先の絞り込みとして機能した。

### (2) ロールの過応答は実データで裏付けられる（確認済み）

**指令→姿勢の閉ループ振幅比 |H|**（ETFE）:

| | 0.39 Hz | 0.78 Hz | 1.17 Hz | 1.56 Hz | ピーク |
|---|---|---|---|---|---|
| **v6 roll** | **1.37** | **1.70** | 0.83 | **1.82** | **1.82 @1.56 Hz** |
| v4 roll（ユーザが「格段に良い」と評した便） | 0.47 | 0.79 | 1.16 | 0.54 | 1.16 @1.17 Hz |
| v6 pitch | 0.50 | 0.98 | **1.30** | 0.92 | 1.30 @1.17 Hz |
| v4 pitch | 1.07 | 1.01 | 0.90 | 0.83 | 1.07 @0.39 Hz |

**|H| > 1 は「指令より大きく動く」**という意味。v6 は操縦帯域（0.4–1.6 Hz）で 1.4–1.8 倍動いている。
振幅比（時間領域）も roll **1.56**（v4 の良区間は 0.90）。
目標値の大きな変化に対するピーク応答は roll **155–373 %**、pitch **105–306 %**。

**ジャイロ雑音ではない。** 10–50 Hz 成分は v4/v5/v6 とも 1.5–2.6 deg/s で変わらず、
増えたエネルギーは 0.2–2 Hz の操縦帯域にある。

### (3) ⚠ ホストはこの共振を再現しない（確認済み。だからホストで対策を決められない）

ロール目標 ±6 deg の正弦掃引で閉ループ共振ピーク `Mp` を測った:

| 設定 | 実機効き | Mp |
|---|---|---|
| 現行 (T=0.81, R_u=620) | 1.0 / 1.9 倍 | 0.89 / **0.87** |
| R_u=800 / 1000 / 1200 | 1.9 倍 | 0.87 / 0.86 / **0.86** |
| T_max=1.55, CQ=1.28e-8, R_u=620〜2200 | 1.0 | 0.89〜**0.91** |

**どの設定でも Mp は 0.86–0.91 で単調に落ちるだけ。実機の 1.82 を再現しない。**
`R_u` を倍にしても Mp はほぼ動かない。**ホストのモデルに機構が入っていない**
（候補: EKF のループ内遅れ、40 ms 再構築ストール、パイロット自身のフィードバック）。
したがって**本件の対策量をホストで決めることはできない。**

### (4) ⚠ 機上データからプラントゲインは同定できない（前言の訂正）

`Σ k·u → 角速度` の ETFE を周波数分解すると、実測/モデル比は**周波数とともに増える**:

| | 0.4 Hz | 0.8 Hz | 1.2 Hz | 1.6 Hz | 2.0 Hz | 2.7 Hz | 3.9 Hz |
|---|---|---|---|---|---|---|---|
| v6 roll（coherence 0.85–0.97） | 0.24 | 0.68 | 1.45 | 1.93 | 2.04 | 2.14 | 2.13 |

純粋なゲイン誤差なら**周波数に依らず一定**になるはずで、なっていない。
決定的なのは次の点である。

> **v4（T_max=1.04）の 2–4 Hz 比は 2.24、v6（T_max=0.81）は 2.13。
> T_max が 28 % 違うのに比がほとんど同じ。**

もしこれがゲイン誤差なら v6 は 2.24×(1.04/0.81)=2.88 になっていなければならない。
**この推定量はプラントゲインを測っていない**（閉ループ同定のバイアス）。

**よって `T_max` を 1.5 級へ上げる案は採らない。**
本セッション中に「ロール/ピッチ 実測/モデル比 0.40」と書いた時間領域回帰（R² 0.10）も、
同じ理由で信用できない。**どちらの向きの結論も機上データからは出せない**というのが正しい。

## 対応

**本ログに対する変更は行っていない。**

**却下した案**:
- **`T_max` を 1.55 へ上げる**: 上記 (4) のとおり根拠にならない。ヨーが今うまく行っている
  `C_QT·T_max` も道連れに壊す（[`20260911_tmax081_requires_ru620_and_cq_rescale.md`](20260911_tmax081_requires_ru620_and_cq_rescale.md)）。
- **`R_u` をホストで最適化する**: (3) のとおりホストが症状を再現しないので最適化の対象にならない。

**推奨（1 手ずつ、飛ばして判定する）**:

1. **`R_u` 620 → 1000。** モデルに触れずに「姿勢誤差 1 deg あたりの指令トルク」だけを下げる唯一のノブ。
   ホストの外乱釣り合い剛性は **1.0010e-3 → 0.7837e-3（−22 %）**（`R_u=800` なら 0.8815e-3 = −12 %）。
   v4 は剛性 1.0168e-3 で快適に飛んでいたが、**当時はモータが緩んでいて実機側が弱かった**。
   機体が健全になった今、2 割落とすのは妥当な 1 手。
2. 効きすぎ感が残るなら `Q_phi=Q_theta` 500 → 400 を次の 1 手にする（同方向・別経路）。

## 検証結果

上記のとおり。ホスト試験は出荷ソース（`nmpc.cpp`/`nmpc_model.cpp` 無改変）に対し実施。
**`R_u=1000` の実機効果は未検証**（ホストが症状を再現しない以上、実機で測るしかない）。

## 次に触る人へ

- **プラントゲインを知りたいなら、機体を拘束して duty にチャープ／ステップを直接注入すること。**
  操縦桿だけを励振源にした閉ループ飛行データからは原理的に同定できない。
  v4 と v6 が T_max 28 % 違いで同じ比を返したことが、その動かぬ証拠である。
- **「モータが緩んでいた」は 3 便（v4/v5/v6）にまたがる交絡だった。**
  v4 までの解析（とくに「降下でヨーが departure」）も、この緩みの影響下にある可能性がある。
  v6 以降のデータで取り直すこと。
- 40 ms のフル再構築は v6 で **2.84 回/s**（v4 良区間は 1.67 回/s）。
  静穏時は無害だと確認済みだが（`20260911_v4_...`）、`Mp` が説明できない以上、
  **ループ内遅れの候補としてまだ消えていない。**
