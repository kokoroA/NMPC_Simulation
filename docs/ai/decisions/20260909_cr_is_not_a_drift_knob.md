# Cr はドリフトのノブではない。ホバー付近では原理的に効かず、効くのはヨー指令追従の定常誤差

- **日付**: 2026-09-09
- **種別**: investigation
- **対象**: `nmpc_params.hpp`(Cr), `nmpc_model.cpp`(A_c(4,4)), ヨードリフトと追従性能
- **タグ**: #Cr #ヨードリフト #Q_r #ヤコビアン #damping_eps #二乗減衰 #簡約モデル #チューニング

## 背景

「`Cr` の増減でヨードリフトや制御性能はどう変わるか」。`Cr` は実測がなく上界 `2.1e-4` だけが分かっており、
`nmpc_params.hpp` には根拠のない `0.005` が入っている。ドリフト対策のノブになるのかを確かめた。

## 原因 / 判断根拠

**確認済み事実（コード）。モデルの `Cr` はホバー付近では原理的に効かない。**

`nmpc_model.cpp` のヤコビアンは `A_c(4,4) = -Cr*(smooth_abs(r) + r*smooth_abs_d(r))/Iz`。
`smooth_abs(0) = damping_eps = 1e-3`、`smooth_abs_d(0) = 0` なので **`r = 0` では `Cr` によらずゼロ**。
`Cr=5e-3` でも `-0.002 [1/s]`（時定数 500 s）。**二乗減衰の微分は原点で消える。**

| `\|r\|` [deg/s] | `Cr=2e-4` | `Cr=5e-3` |
|---|---|---|
| 0 | −0.000 | **−0.002** |
| 30 | −0.070 | −1.745 |
| 57 | −0.133 | −3.316 |

**確認済み事実（簡約モデルの数値実験）。定常ドリフトを決めているのは `Q_r` であって `Cr` ではない。**

一定外乱 `tau_d = 0.0007 Nm` に対し、`Cr` を実機側・モデル側とも 25 倍（2e-4 ↔ 5e-3）振っても
**定常 `r` は 4.17〜4.40 deg/s でほぼ動かない**。`r ≈ 4 deg/s` では `Cr·r|r| = 1e-6 Nm` と、
外乱 `7e-4 Nm` に対して無視できるため。

一方 `Q_r` は効く: `Q_r = 6/20/40/60/120` で `21.5/7.3/4.40/3.46/2.53 deg/s`。
**`Q_r=40` の 4.40 は実測（v11 +5.2 / v4 +4.8）をよく再現する。**
`Q_r=20` は 7.3 と実測 +21 を過小評価するが、これは簡約モデルに**軸間の Δu 争奪が入っていない**ため
（v6 ではヨーが Δu の 29.3 %、v1 では 84.7 % を消費していた）。

**確認済み事実。`Cr` が効くのは「ヨーを積極的に回しているとき」の定常誤差。**

モデルが減衰を過大に信じていると、削られる分を先回りして余計にトルクを入れる。
実機にその減衰が無いので**指令より速く回る**。`r_ref` 30 deg/s ステップ（実機 `Cr=2e-4` 固定）:

| モデルの `Cr` | 立上り 63% | オーバーシュート | 定常誤差 |
|---|---|---|---|
| 2e-4 | 0.31 s | −0.7 % | **−0.21 deg/s** |
| **5e-3（現行）** | 0.31 s | **+9.8 %** | **+2.95 deg/s** |
| 2e-2 | 0.30 s | +47.9 % | +14.37 |

**立ち上がりの速さは `Cr` でほとんど変わらない**（0.30–0.31 s）。決めているのは `Q_r/R_u`。

**推定（未確定）。** 実測のヨー追従振幅比は v11 で 1.152、v4 で 1.074 と 1 を超えている。
「モデルの `Cr` が大きいほど振幅比が上がる」という**向きは一致する**が、
簡約モデルの予測（`Cr=5e-3` で 0.898）では 1.07–1.15 を説明しきれない。
**`C_QT` の誤差など別要因が混ざっているとみるべきで、`Cr` だけで説明しない。**

**確認済み事実。実機の `Cr` が小さいことは飛行には不利。**
開ループのつり合い `r = sqrt(tau_d/Cr)` は `Cr=2e-4` で **107 deg/s**、`5e-3` で 21 deg/s。
上界が正しければ**この機体のヨーには実質的な自己復元が無く、ドリフト抑制は全部制御器が担っている。**

## 対応

**コード・パラメータ変更なし。** 解析資料 [`docs/20260909_cr_effect_on_yaw.md`](../../20260909_cr_effect_on_yaw.md)。

**設計判断**: **`Cr` をドリフト対策のチューニングノブとして使わない。**
ドリフトのノブは `Q_r`、根治は物理（プロペラ／モータの不整合 ~0.0007 Nm）。
`Cr` は「合わせるべき物理定数」であって、ヨー吊り試験で測った値を入れる。
**測れば指令追従の定常誤差が +2.95 → −0.21 deg/s に減る見込みだが、ドリフトは変わらない。**

**却下した案**: ドリフトが出るので `Cr` を上げてモデルに減衰を持たせる。
ホバー付近ではヤコビアンが消えて効かず（§確認済み事実1）、
定常ドリフトも 25 倍振って 5 % しか動かない。**効果が無いうえに指令追従を悪化させる。**

## 検証結果

- ヤコビアンは `nmpc_model.cpp` の実装をそのまま評価。`damping_eps = 1e-3` を確認。
- 数値実験は**本体 NMPC の構造（凝縮形・N=14・dt=0.01・box `[−u_hover, 0.95−u_hover]`・
  `terminal_scale=10`・`R̄` は 6 発分）をヨー 1 軸に落とした簡約モデル**。
  `Q_r=40, R_u=120, u_hover=0.60` で実施。
- `Q_r=40` の定常ドリフト 4.40 deg/s が実測 4.8–5.2 と整合することで簡約モデルを検証した。
- ⚠ **軸間の Δu 争奪・50 Hz チャタリング・モータ一次遅れは含んでいない。**
  傾向と桁は信用してよいが、絶対値は実機で確認すること。
- **実機での確認は未実施。`Cr` の実測もまだ無い。**

## 次に触る人へ

- **「二乗の項は原点で効かない」を忘れない。** `C·x|x|` 型の項は微分が原点で消えるので、
  平衡点近傍の線形化には現れない。**平衡点付近の挙動を直したいときに二乗項を触っても無駄。**
- **同じ症状に見えても、原因が定常外乱なのかモデル誤差なのかで効くノブが違う。**
  定常外乱 → 重み（`Q_r`）か物理。モデル誤差 → その定数を測って合わせる。
- ヨー吊り試験（[`20260905_yaw_damping_experiment_protocol.md`](../../20260905_yaw_damping_experiment_protocol.md)）で
  `Cr` を測ったら、**ドリフトではなく「指令追従の定常誤差」が改善しているかを見ること。**
