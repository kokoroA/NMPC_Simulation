# 0910_v8 (R_u=1200): 旧と同じループゲインでも 3–5 Hz の遅れ限界モードで墜落。ゲイン調整では直らないことが確定。左傾きのトリムも 0910 から出ている

- **日付**: 2026-09-10
- **種別**: investigation | design
- **対象**: `0910_100Hz_v8.csv`、`nmpc_params.hpp`(R_u=1200, Q_p=30)
- **タグ**: #Benzen_NMPC #4Hz #遅れ #位相余裕 #R_u #トリム #左傾き #プロペラ損傷 #遅れ補償 #予測

## 症状

離陸後、だんだん振動し、最後に姿勢を崩して墜落。ログ 11.4–18.0 s、`R_u=1200 / Q_p=Q_q=30`。

## 確認済み事実

**健全性**: 推定ドリフト −0.01/+0.36 deg/s、バイアス ≤0.6 deg/s、`nonfinite=1`（破綻後）、`lambda_reset=1`、
再構築 7 回、`loop_us` p95 9.7 ms、逸脱前は `|λ|=0`・box 非活性。**v7 と同じく混じり物なし。**

**コントローラは設計どおり**: 飛行データ回帰（15.5–17.0）roll K角 0.335e-3 / K率 0.417e-3（R² 0.64）。
ホスト静的値 0.335 / 0.287 と角度側は一致。旧 0904_v5 のループゲイン（0.606e-3 × 393 = 0.24）に対し
0.335e-3 × ~700 = 0.23。**ループゲインは旧と同じ水準に戻っている。**

**それでも発振する**: 15.5–17.0 で `p` ピーク 3.33 Hz（2–5 Hz 帯 59%）、`tau_y` ピーク 4.67 Hz（49%）。
`p_rms` 4.8 → 4.3 → 11.4 → 18.5 と成長。pitch 回帰の K角は **−0.26e-3（負）**、
つまりピッチでは指令が角度誤差と同相 = 位相限界を越えている。

**逸脱**: `t=17.30–17.44`。`q` +19 → +48 deg/s（機首上げ）に対し RR が 0.590 → 0.762 → **0.950**（3 周期）、
`q` が −27 → −71 → −90 へ反転すると RR が 0.237 → **0.000**。100 ms で RR がフルスケールを往復。
角速度に対する応答が大きく遅れて届き、行き過ぎ → 逆向きにさらに大きく → 発散。**遅れ限界の教科書例。**
λ は box に当たった後だけ（0.42–0.85）、`|U_lin|` ≤ 1.0。ソルバのバーストではなく、閉ループの発散。

**左傾きのトリム（新事実）**: 破綻前の平均で `phi` −1.0° に対し `phi_ref` +6.4°（誤差 −7.4°）、
左（FL,ML,RL）− 右（FR,MR,RR）の平均 duty 差 **+0.022**、平均 `tau_x` +0.004。
コントローラは正のロールトルクを出し続け、機体は負に傾いたまま。パイロットは右スティックを 13° まで入れている。

| ログ | 左−右 duty 差 |
|---|---|
| 0904_v2 / v4 / v5 | −0.023 / +0.012 / 0.000 |
| 0909_v2 | +0.006 |
| 0910_v1 / v3 / v4 | +0.013 / +0.004 / +0.010 |
| **0910_v5 / v6 / v7 / v8** | **+0.022 / +0.025 / +0.021 / +0.022** |

0910_v5 以降、**左側の推力が右より約 3% 不足**する状態が固定している（左プロペラ／モータの損傷、腕の曲がり）。
静的ゲインが低い（R_u 大）ほど定常誤差は大きくなるので、パイロットの舵が増え、
大きな `phi_ref` と大きなロール誤差を抱えたまま限界モードに入っている。

## 判断

- **`R_u` を上げてループゲインを旧に合わせても直らない**（v7: R_u=500、v8: R_u=1200、同じモード）。
  ゲインを下げると角速度側の減衰も一緒に下がるので、位相余裕は増えない。**ゲイン調整はこれで打ち切る。**
- 旧が飛べた「余裕」はゲインだけでは再現できない。旧の 0904_v5 は D90S・バグ有・トリム無しの組合せで、
  同じ機体状態はもう存在しない。
- 残る手は**位相を作る**こと。実効遅れ 40–50 ms（同定値）を予測モデルで埋める。

## 対応（案・未適用）

1. **遅れ補償（x0 の前方予測）**: `nmpc_step` に渡す `x0` を、直近に出した duty で `model_f` を
   遅れ時間ぶん（計算 ~8 ms + ZOH ~5 ms + モータ ~30–40 ms ≈ 50 ms、5 周期）積分して進める。
   4 Hz での位相進みは ωT ≈ 2π·4·0.05 ≈ **72°**。標準的な MPC の遅れ補償で、コストは `model_f` 5 回。
   状態次元は増えない。遅れ量はパラメータ（`delay_comp_steps`）にして 0 で無効化できるようにする。
2. **プロペラ・モータの点検**: 左右差 3% は 0910_v5 から。全プロペラ交換、左腕の目視。
   トリムが消えればパイロットの舵が減り、限界モードへの入りにくさも戻る。
3. 上記 1 の実機前検証: ホストは 4 Hz モードを再現しないので、**位相の実測**（正弦掃引で
   コントローラの位相応答が 4 Hz で +60–70° 進むこと）と、リプレイで `nonfinite=0` を確認するに留まる。

## 検証結果

- v8 全区間の推定器・ソルバ内部状態・スペクトル・回帰・トリムを確認。コード・パラメータ変更なし。
