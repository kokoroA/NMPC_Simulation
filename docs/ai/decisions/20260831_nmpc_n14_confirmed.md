# N=14 + 飛行中の再構築復活で時間劣化が消えた。次の律速はスティック指令のスケール

- **日付**: 2026-08-31
- **種別**: investigation
- **対象**: `Benzen_NMPC/nmpc_params.hpp`(N), `control.cpp`(update_attitude_refs_from_sticks), `tools/0831_v4.csv`
- **タグ**: #Benzen_NMPC #飛行実験 #N #reset_period #TR1 #SR2 #数値漂流 #Phi_ref #スティック感度 #Q_phi_eff

## 背景 / 症状

`rebuild_max_u_hover` を 1.0f に戻し、`N` を 17→14 にして 3 回飛行（`0831_v4.csv`、79.6 s）。

## 原因 / 判断根拠

**確認済み事実。**

- **時間劣化は消えた。** `cycles_since_reset` は 0–100 に張り付き（v3 は 26–770）、
  姿勢誤差との相関は **+0.704 → −0.070**。経過時間との相関も +0.713 → +0.302。
  区間 3（24.5 s）は姿勢誤差が 10.51 → 10.99 と**横ばい**、飽和ゼロ。
  → **v3 の劣化原因は TR1/SR2 の数値漂流だったという仮説を支持。**
- **`N³` の見積もりが当たった。** フル再構築 58 ms → **34 ms**（予測 58×(14/17)³=32 ms）。
  `iter_us` 8.5→**6.43 ms**、`loop_us` 10.3→**8.27 ms**。**初めて 10 ms 予算内**（超過は 4/512 = 1 %、全て再構築の瞬間）。
- **34 ms の再構築は姿勢を乱していない。** ログに当たった 4 回すべてで前後に段差なし。
  → 「機体が静かな時だけ再構築」（前回資料 4-D）は**不要**と判断。
- **ヨーの片流れが止まった。** `r` の平均 −16.7 → **+0.5 deg/s**（`Q_r` 6→20 の効果と推定）。
- 飛行時間 7.1 s → **24.7 s / 24.5 s**。
- **前回の宿題 Q1 が解けた。** ログの `Q_phi_eff` 列にファーム内の実効 `Q_phi` が記録されており、
  **v1 も v3 も 50**、v4 が初めて 100。**これまでの解析の前提は正しかった。**

**次の律速。**

- `update_attitude_refs_from_sticks()` のスケールが **ロール `0.8f*π` = ±144°、ピッチ `0.3f*π` = ±54°**。
  **ロールがピッチの 2.67 倍。** ログの非対称（ロール指令 rms 20.13°/max 107.04°、追従誤差 rms 18.85° に対し
  ピッチは 8.30°/28.56°/8.32°）をそのまま説明する。
  **ロール軸の制御が悪いのではなく、2.67 倍強く指令されているだけ。**
- **107° の指令は姿勢 NMPC の線形化モデル（小角度・重力結合なし）の有効範囲外。**
  モデルの外で最適化しているので追従できないのは当然。

## 対応

解析資料 [`docs/20260831_nmpc_v4_n14_analysis.md`](../../20260831_nmpc_v4_n14_analysis.md)、
図 `plots/0831_v4_analysis.png`, `plots/0831_v4_compare.png`。**コードは未変更。**

推奨: **`Phi_ref` の係数を `0.8f → 0.3f`（ピッチと同じ ±54°）だけ変える。**
さらに緩めるなら両軸 `0.15f`（±27°）。ヨー率は `0.8f → 0.5f`（±90 deg/s）。
**これは重みの調整ではなく操縦感度の設定であり、重みより先に直すべき。**

**却下した案**: ロールの追従を改善するために `Q_phi` を上げる。
指令が ±144° でモデル有効範囲の外にある以上、重みをどう振っても追従しない。**入力側を直す。**

**却下した案**: 「静かな時だけ再構築」の実装。N=14 で 34 ms まで下がり、実測で姿勢を乱していないため不要。

## 検証結果

- すべて `0831_v4.csv`（660 点 / 10 Hz / 79.6 s）の静的解析。
- **スティック感度を変更した後の飛行は未実施。**
- ヨー改善が `Q_r` 6→20 によるものだという因果は**未検証**（同時に N と再構築ゲートも変わっている）。
- 区間 2・4 が 4 秒で終わった理由（着陸か制御喪失か）は**未確認**。
