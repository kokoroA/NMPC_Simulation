# 既存ログから Cr ≤ 2.1e-4 が言える。Cr=0.005 は物理的にありえず、前回の relaxed hover 判定は反転する

- **日付**: 2026-09-05
- **種別**: investigation | design
- **対象**: `nmpc_params.hpp`(CQ, Cp, Cq, Cr), `0904_100Hz_v3.csv`, `NMPC_REPORT.md` / `nmpc_params.hpp` の慣性モーメント
- **タグ**: #sysid #Cr #Cp #Cq #CQ #C_QT #上界 #ヨー吊り試験 #スイベル #自由減衰 #慣性モーメント #二線振り子 #ベンチ加振モード #relaxed_hover

## 背景

`F1404 + GEMFAN-3630-3` について `CQ` と `Cp/Cq/Cr` を「時間と手間をかけずに」同定する方法を求められた。
飛行ログからの回帰は [`20260905_damping_unidentifiable_flight_logs.md`](20260905_damping_unidentifiable_flight_logs.md)
で 180 条件を試して識別不能と確定済みなので、同じ手は使えない。

## 原因 / 判断根拠

**確認済み事実。追加実験ゼロで `Cr` の上界が出る。**

モデルの恒等式 `Cr·r|r| = tau_z − (Iy−Ix)pq − Iz·rdot` の右辺は全部ログにある。よって
`Cr ≤ (|tau_z| + |gyro| + Iz|rdot|)/r²` が**どの時刻でも**成り立つ。接触トルクが混じる接地
（`t = 19.15 s`）とフェイルセーフ後を除いた `t < 18.90 s` の 1890 点で最も厳しい点を取ると

- `C_QT` 推定値 0.01113 で **`Cr ≤ 2.10e-4`**（`t = 18.42 s`, `r = 220 deg/s`）。
- `C_QT` を 3.4 倍にした最悪ケースでも **`Cr ≤ 5.95e-4 〜 7.14e-4`**。
- **慣性モーメントの 3.9 倍の不確かさでも上界はほとんど動かない**（2.10e-4 で一致）。

**`nmpc_params.hpp` の `Cr = 0.005` は 2 桁大きく、物理的にありえない。**
その値だと減衰トルクは `r = 150 deg/s` で既にモータ最大ヨートルクの 122–165 %、
`259 deg/s` で 375–507 % になる。**機体は 150 deg/s より速く回れないはずだが、
実測では接地前に 259 deg/s まで回っている。**

**判断。前回の結論が反転する。**

[`20260905_relaxed_hover_eval_cr_decides.md`](20260905_relaxed_hover_eval_cr_decides.md) は
公称値 `Cr = 0.005` で「relaxed hover の利得はゼロ」と結論したが、**上界 2.1e-4 は
成立境界（約 1.1e-3）の 5 分の 1 で、成立側にある。**
`(Cp=Cq) × Cr` の 2 次元掃引では `Cr = 1e-4〜3e-4` で `rho = +9.7〜+16.0 %`。
⚠ ただし**成立解はどれも `Omega = 300〜610 deg/s` を要求し、現行フェイルセーフ 300 deg/s と正面衝突する。**
`Cr` が小さいほど必要 `Omega` は上がるので、単純に「`Cr` が小さくて嬉しい」話ではない。

**設計判断。ヨー軸吊り試験を最優先にする。**

- **go/no-go を決めるのは `Cr` だけ。** 掃引表より、`Cr ≥ 1e-2` ではどの `Cp/Cq` でも成立しない。
  **`Cr` が大きいと分かれば `Cp/Cq` を測る必要すらない。**
- **ファームが使う量がそのまま出る。** `nmpc_model.cpp` のヨー行は `kS·C_QT·T_max/Iz` と `−Cr·r|r|/Iz` で、
  **どちらも `Iz` との比**。吊り試験は比を直接測るので、**`Iz` の 3.9 倍の不確かさを迂回できる。**
- **1 軸拘束で `p = q = 0`** となり、ジャイロ結合項が消えて回帰が素直になる。

**却下した案**: 定常ヨーレートまで回して `Cr = tau_z/r_ss²` と読む。
`Delta = 0.05`・`Cr = 1e-4` で定常 `r` が約 300 deg/s（`Cr = 1e-5` なら 900 deg/s 超）になり、
吊った機体でそれを回すのは危険。**自由減衰なら同じ情報がより広い `r` 範囲で、より安全に取れる。**

**却下した案**: トルク計や専用の反トルク治具を作る。`CQ` は既に電気入力と運動量理論の
2 経路で推定済みで、吊り試験の立ち上がりが 3 経路目になる。3 つ揃えば十分。

**却下した案**: `Cp/Cq` を先に測る。`Cr` が決まるまで判断が進まない。

**却下した案**: 飛行ログの回帰をやり直す。識別不能が実証済み。

## 対応

計画書 [`docs/20260905_cq_damping_sysid_plan.md`](../../20260905_cq_damping_sysid_plan.md)。要点のみ:

- **治具は釣り用スイベル 1 個。機体を上下逆さに吊る**（推力が糸を張る向きに働くので、
  ホバー以上の回転数でも糸が緩まない。正立だと緩んで暴れる）。スイベルが無いと糸のねじり戻りが混じる。
- **加振は `u_i = u0 + s_i·Delta`（`s = kS`）**。`Sum s_i = 0` なので**合計推力が変わらず純ヨートルクだけ出る**。
  `tau_z ≈ 6·C_QT·T'(u0)·Delta`。
- **`r = 0` の瞬間は減衰項も `(Iy−Ix)pq` も厳密にゼロ**なので `rdot(0) = tau_z/Iz`。
  **`C_QT/Iz` が減衰モデルなしで直接出る。** 立ち上がり 0.3 s での減衰の寄与は 0.5–1.0 % で無視できる。
  同じステップ応答から**モータ一次遅れ `tau` も副産物として取れる**。
- **150–200 deg/s で `Delta` を 0 に戻し、自由減衰を記録**。`Iz·rdot = −b·r − Cr·r|r|` を回帰。
- **線形項 `b` を必ず入れる。** ロータの面内力（H 力）は小前進比で速度に比例するため、
  低回転域の減衰は物理的に `r` に線形。`r|r|` だけで当てはめると `Cr` を過大評価する。

**前提となるファーム側の小改造が本丸**: NMPC を通さず duty ベクトルを直接書く
ベンチ加振モード（現状無い。`ESC_calib` は固定値のみ）。`set_duty_*` は既にあるので数十行。
**これで前回の失敗原因 3 つ（閉ループ共線性・50 Hz チャタリング・モータ遅れ未同定）が同時に消える。**

## 検証結果

- 上界は `0904_100Hz_v3.csv` の 1890 点（`t < 18.90 s`）で計算。`C_QT` 2 通り × 慣性 2 通りの 4 条件で確認。
- `(Cp=Cq) ∈ {0.005, 0.025, 0.05, 0.1}` × `Cr ∈ {1e-4, 3e-4, 1e-3, 3e-3, 1e-2}` を
  慣性 2 セットで掃引（`relaxed_hover_equilibrium.py`）。
- 吊り試験の設計値（`tau_z`、`rdot(0)`、定常 `r`、減衰の寄与率）を GEMFAN の実測推力曲線で算出。
- **`Cr` は上界であって点推定ではない。実験は未実施。ファームウェアの変更もしていない。**

## 次に触る人へ

- **点推定が無くても上界は出せることがある。** 恒等式の右辺が全部ログにあるなら、
  絶対値を取って不等式にするだけでよい。**「同定できない」と「何も言えない」は別。**
  今回はこれだけで公称値が 2 桁間違っていることが分かり、前回の結論が反転した。
- **公称値の妥当性は「その値だと物理的に何が起きるはずか」で検算する。**
  `Cr = 0.005` なら 150 deg/s 以上回れないはず → 実測は 259 deg/s → 却下。ログ 1 本で足りる。
- **`Ix/Iy/Iz` が `NMPC_REPORT.md`（6.10/6.53/11.6e-3）と `nmpc_params.hpp`（1.8/1.9/3.0e-3）で
  3.4–3.9 倍食い違っている。どちらも実測記録が無い。**
  ファームは比しか使わないので吊り試験だけでヨー軸は正しくなるが、平衡計算には絶対値が要る。
  `bifilar_inertia_method.md` に手順書があり、糸とストップウォッチで 30 分。
- **relaxed hover が成立する条件は、同時にフェイルセーフに触れる条件でもある。** 対で設計すること。

## 2026-09-05追記: 軸受は「強度」ではなく「摩擦トルク」で選ぶ。事前チェック手順つき

**確認済み事実（計算）。** 逆さ吊りでの軸方向荷重は 重量 3.76 N + 推力 3.57 N（`u0=0.6`）= **7.33 N**。
市販スイベルの破断強度 56 kgf = 549 N に対し**安全率 75 倍**で、強度はまったく問題にならない。

**問題は摩擦トルクである。** 平軸受（バレル/ローリング型）の摩擦トルクは `mu·N·r_eff`。
`r_eff ≈ 0.8 mm`（自重 0.26 g クラス）、`mu = 0.15–0.6` として **8.8e-4 〜 3.5e-3 Nm**。
これは測りたい信号（`Cr=1e-4`, `r=200 deg/s` で **1.22e-3 Nm**、指令ヨートルク `Delta=0.05` で **2.61e-3 Nm**）
と**同じ桁**である。**「ローリングスイベル」は日本の釣具用語では平軸受であってボールベアリングではない。**

**モンテカルロ（40 回、ジャイロノイズ 0.5 deg/s rms、真値 `Cr=1.0e-4`、`r0=200 deg/s`）。**
回帰モデルに**クーロン摩擦の定数項を必ず入れる**前提での `Cr` 推定誤差:

| 軸受 | `tau_f` [Nm] | 減衰時間 | 誤差 中央値 | 90%tile |
|---|---|---|---|---|
| 平 mu=0.6 | 3.5e-3 | 2.7 s | 28.8 % | 52.5 % |
| 平 mu=0.3 | 1.8e-3 | 4.8 s | **11.4 %** | 28.2 % |
| 平 mu=0.15 | 9.0e-4 | 8.4 s | 9.8 % | 19.4 % |
| **ボールベアリング** | 5.0e-5 | 25 s | **4.6 %** | 9.8 % |

摩擦の定数項を**入れない**と誤差は 300–560 % になる。**必ず 3 パラメータ（定数・線形・二乗）で回帰する。**
`r0` を 400 deg/s まで上げれば平軸受でも 2.8 % まで改善するが、吊った機体をその速度で回すのは危険。

**設計判断。**

- **ボールベアリングスイベル（または 608ZZ 等の玉軸受）を使う。** 平軸受でも回帰は破綻しないが、
  精度が 1 桁落ちるか、危険な高回転を要求される。
- **フェーズ⓪（モータ OFF のベースライン計測）を手順に追加する。** モータを止めて手回しし、
  自由減衰を記録する。ロータ由来の減衰が無いので、得られるのは**軸受摩擦 + 機体空気抵抗**。
  これを本計測から差し引けば、ロータ由来の減衰だけを取り出せる。**軸受の良否判定も兼ねる。**

**事前チェック（工具不要・2 分）**: 200 deg/s 相当で手回しして手を離し、止まるまでを計時する。

| `tau_f` | `Iz=3.0e-3` | `Iz=1.16e-2` |
|---|---|---|
| 1.8e-3（平 mu=0.3） | 5.8 s | 22.5 s |
| 9.0e-4（平 mu=0.15） | 11.6 s | 45.0 s |
| 5.0e-5（ボール） | 209 s | 810 s |

**10 秒以内に止まったら摩擦が支配的なので軸受を替える。30 秒以上回り続ければそのまま使える。**
（比較: `Cr=1e-4` が `r=200 deg/s` で生む減速度は `Iz=3.0e-3` で 23 deg/s²、`Iz=1.16e-2` で 6 deg/s²）

⚠ この摩擦見積もりは `mu·N·r_eff` の概算であり実測ではない。実際の平軸受はスティックスリップを伴うので、
上表のシミュレーションは**楽観側**である。だからこそフェーズ⓪で実測する。
