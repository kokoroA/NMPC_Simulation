# v5: ヨーモデルは正しい。追従しないのは「積分器の無い NMPC + 46 deg/s² の定常ヨー外乱」

- **日付**: 2026-09-11
- **種別**: investigation
- **対象**: `tools/0911_100Hz_v5.csv`, `tools/0911_v5.csv`, `nmpc_params.hpp`(CQ, T_max, Q_r, R_u)
- **タグ**: #Benzen_NMPC #飛行実験 #0911_v5 #ヨー #追従しない #定常外乱 #積分器 #Q_r #CG #モータ傾き #ジャイロ結合

## 背景 / 症状

`T_max=0.81`, `Q_phi=Q_theta=500`, `R_u=620`, `CQ=1.54e-8` で飛行
（[`20260911_tmax081_requires_ru620_and_cq_rescale.md`](20260911_tmax081_requires_ru620_and_cq_rescale.md) の推奨どおり）。

ユーザ報告: **「水平には飛べる。しかし反時計回りのヨー目標値を与えても全く追従しない。
ヨー目標値を与えるとピクついてロール・ピッチの制御が不安定になる。」**

ログは 21.8 s（リングが一周しているので離陸前は入っていない）。
`lambda_reset=8`, `nonfinite=1`, `pred_nonfinite=1`, `ekf_bias_reset=5`（v4 はいずれも 0）。
最後の t=20 台で `failsafe=4`(rate)、`lam_norm` 28.7、飽和 14.8 %、`p` rms 300 deg/s。

## 原因 / 判断根拠

### (1) ヨーのモデルは正しい。パラメータ変更は当たっていた（確認済み）

**定常成分を除いた過渡ゲイン**で同定した（移動平均を引いて高周波だけで回帰＝定常外乱の影響を除去）。

| ログ | 除去する時定数 | 実測/モデル比 | R² |
|---|---|---|---|
| **v5**（CQ=1.54e-8, T_max=0.81） | 1.0 s / 0.5 s / 0.25 s | **0.98 / 1.05 / 0.95** | 0.47 / 0.46 / 0.34 |
| v4（CQ=1.2e-8, T_max=1.04） | 同上 | 1.26 / 1.37 / 1.38 | 0.36 / 0.40 / 0.37 |

**v5 でちょうど 1.0 に乗った。** 各モータ duty → ヨー角加速度 のリッジ回帰でも
符号は `kS` と **6/6 一致**（相関 0.92）。**配線・回転方向・符号の誤りではない。**

### (2) 追従しない理由は「定常外乱を消すのにヨー誤差の全予算を使い切る」から（確認済み）

準定常区間 t=5–8:

| | 値 |
|---|---|
| `psi_ref` | −10 〜 −15 deg/s（反時計回り指令） |
| 実 `r` | **+0.3 〜 +9.0 deg/s**（逆向き） |
| 制御が出している `Σ kS u` | **−0.112**（指令どおり負。モデル上 −51 deg/s²） |
| 実 `ṙ` | ≈ 0 |
| → 釣り合っている未説明トルク | **+40 〜 +80 deg/s²**（時計回り） |

**ヨー率ループの静的ゲインは `Σ kS u = 0.00688 / (deg/s)`**（実測）。
0.10 の差動を作るには **14.5 deg/s の定常ヨー率誤差**が要る。実測の誤差は 16.3 deg/s。
つまり**外乱を打ち消すだけで誤差予算を使い切っており、パイロットの −10 deg/s は誤差の内側に埋もれる。**

**ホストが同じ現象をそのまま再現した**（現行パラメータ、機体効き=モデル同等）。

| ヨー外乱 [deg/s²] | 0 | 5 | 10 | 20 | 30 | **46** |
|---|---|---|---|---|---|---|
| −10 deg/s 指令の追従率 | 98 % | 83 % | 68 % | 38 % | 7 % | **−41 %** |

ホストの静的ゲインは 0.00706 /(deg/s) で**実機の 0.00688 とほぼ一致**。
**制御器は設計どおりに動いている。外乱が大きいだけ。**

**NMPC には積分器が無い**（コストは `Q_r (r − Psi_ref)²` の比例項のみ）ので、
定常外乱は必ず定常誤差として残る。ヨーは指令が「角速度」で重力のような復元項も無いため、
誤差がそのまま「回らない」として見える。ロールは同じ病気が **−3 deg の定常バンク**として出ている。

### (3) `Q_r` では直らない（ホストで確認済み）

| Q_r | 40 | 80 | 160 | 320 |
|---|---|---|---|---|
| 外乱 46 での追従率 | −41 % | 1 % | 25 % | **39 %** |
| ロール追従誤差 rms | 4.78 | 4.77 | 4.77 | 4.77 |
| 飽和 | 0 % | 0 % | 0 % | 0 % |

**8 倍にしても 39 % にしかならない。** 必要な差動 0.10 は外乱で決まっていて `Q_r` では減らないため。
ロール誤差は `Q_r` に**完全に無反応**（4.77 deg で不変）なので「ヨーがロールを痩せさせる」説もここでは成り立たない。

⚠ なお `Q_r=60` は 0904 で**一度否決している**
（[`20260904_qr60_yaw_overshoot_pitch_coupling.md`](20260904_qr60_yaw_overshoot_pitch_coupling.md):
ヨー過渡が +126 deg/s までオーバーシュートし飽和率 52–59 % でピッチ崩壊）。
当時との違いは **`C_QT` が 0.0576（実測の 5.2 倍）だった**ことと `R_u=120`（現在の 1/5）であること。
**それでも上表のとおり費用対効果が低いので、`Q_r` を上げる案は今回も採らない。**

### (4) ロール・ピッチが崩れるのは「ヨー差動」ではなく「ヨー**レート**が大きいとき」（確認済み）

ホストで外乱を強くして `r` を走らせた:

| ヨー外乱 | 定常 `r` | ロール誤差 rms | `p` 最大 | \|Σ kS u\| 最大 |
|---|---|---|---|---|
| 46 | +4 deg/s | 4.78 deg | 17 | 0.10 |
| 100 | +19 | 4.75 | 16 | 0.20 |
| 200 | +44 | 4.65 | 16 | 0.32 |
| **400** | **+92** | **8.46** | **55** | 1.36 |

**差動が 0.32 まで増えてもロールは平気。`|r|` が 90 deg/s 級になって初めて崩れる。**
実機でも一致する: t=11–14 で未説明ヨートルクが **+46 から −82 へ符号反転**し、
`r` が **−103 deg/s** まで走ったその区間だけ `p` rms 48 / `q` rms 48 になっている。
機構はジャイロ結合 `(Iy−Iz)qr/Ix = −0.61·q·r`（q=0.5, r=−1.8 rad/s で +31 deg/s²）と大差動の重なり。
飛行ログの層別でも、`|Σ kS u|` 0.06–0.10 の区間は**むしろロール誤差が最小**（1.99 deg）だった。

### (5) 外乱の正体（推測）

| | 大きさ | 物理的に等価なもの |
|---|---|---|
| ヨー +46 deg/s² | 2.4e-3 N·m | CW/CCW 推力差 **0.081 N＝全推力の 2.5 %**、または全モータの **0.42° 傾き** |
| ヨー +80 deg/s² | 4.2e-3 N·m | 同 4.3 %、**0.73° 傾き** |
| ロール −50〜−200 deg/s² | 1.6e-3〜6.3e-3 N·m | **CG の横ずれ 0.5〜1.9 mm** |

**どれも「工作精度の範囲」で説明できる大きさ**である。特別な故障を想定する必要はない。
per-motor 回帰では **RR のヨー係数が 2 便とも突出して弱い**（v5 −0.18 / v4 −0.05、期待 −1.0）が、
閉ループ同定なので**個別モータの大きさは信用できない**。あくまで点検の優先順位付けに使う。

## 対応

**パラメータは変更していない。** これはゲインで解く問題ではないため。

**却下した案**:
- **`Q_r` を上げる**: 8 倍で 39 %。0904 の否決理由（過渡オーバーシュート）も残る。費用対効果が低い。
- **`CQ` をさらに動かす**: 過渡ゲインが 0.95–1.05 に乗っている。今動かすと**当たっている所を壊す**。
- **`R_u` を下げてヨーゲインを稼ぐ**: ロール・ピッチのループゲインまで上がる。軸ごとに効かないノブで軸別の問題を直さない。

## 検証結果

上記のとおり。ホストは出荷ソース（`nmpc.cpp`/`nmpc_model.cpp` 無改変）に対し、
`nmpc_params.hpp` だけ `Q_r` を差し替えて実施。実機の静的ゲイン 0.00688 と
ホスト 0.00706 が一致したことが、**モデル・制御器側に異常が無いことの最も強い証拠**。

## 次に触る人へ

**優先度 1: 機械側。制御パラメータより先にこれをやること。**

1. **吊るしヨー試験**: 機体をヨー軸で吊り、既知の `Σ kS u` を与えて `ṙ` を実測する。
   `C_QT·T_max/Iz` がまとめて確定し、`CQ` と `Iz` の押し付け合いも終わる。
2. **ホバー推力でのヨートルク実測**: 拘束した状態でホバー duty を出し、残るヨートルクを測る。
   2.4e-3 N·m 級の偏りがあるはず。**モータマウントの傾き（0.4–0.7° で説明できる）とプロペラの状態**、
   とくに **RR** を点検する。
3. **CG**: 横 0.5–2 mm のずれでロールの定常誤差 −3 deg が説明できる。バッテリ位置を振って確認する。

**優先度 2: 制御側（外乱が機械的に消せない場合）。**

4. **ヨーに積分作用を入れる**（`U_ref` にゆっくり適応するヨー差動トリム項を足す形が現実的。
   アンチワインドアップ必須、`±0.15` 程度で飽和させる）。
   **定常誤差を消せるのは積分だけで、比例ゲインをいくら上げても上表のとおり届かない。**
   ロールの −3 deg 定常誤差も同時に解決する。
5. それまでは **大きなヨー指令を入れて飛ばさないこと。** `|r|` が 90 deg/s を超えるとロール・ピッチが崩れる。
