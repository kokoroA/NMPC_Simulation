# 0904_v3 墜落: Psi_ref の変更は成功。破綻は t=31.03 のロール指令異常で、10Hz ログでは原因を特定できない

- **日付**: 2026-09-04
- **種別**: investigation
- **対象**: `Benzen_NMPC/tools/0904_v3.csv`, `nmpc_params.hpp`(Q_phi, CQ, admm_max_iter), `control.cpp`(failsafe)
- **タグ**: #Benzen_NMPC #飛行実験 #墜落 #ヨードリフト #Psi_ref #Q_phi #C_QT #ADMM #飽和 #failsafe #ログレート

## 背景 / 症状

`mass=0.35`, `Cp=0.02`, `Cq=0.02`, `Q_phi=Q_theta=200`, `Psi_ref` 係数 0.3 で 1 分弱の飛行。
**ヨーが前回より流れ、最後に急に姿勢が崩れて墜落。**

## 原因 / 判断根拠

**確認済み事実。**

- **`Psi_ref` ±54 deg/s は効いた。** 飽和した時刻の割合 39 % → **1 %**（墜落前）、
  Δu のうちヨーが占める割合 84.7 % → **67.9 %**、ドリフト平均 16.1 → 11.9 deg/s。
- **ヨードリフトは飛行中に単調に育った**（指令中立時の `r` 平均）:
  +8.5 → +13.4 → +20.4 → +27.3 → **+39.8 deg/s**。
- **制御器はヨーを正しい向きに打っている。** `τ_z` 平均 −0.0134 N·m に対し `r` 平均 +11.9 deg/s。
  Δu の平均ベクトルは `kS` にきれいに沿った純粋なヨートリム。**勝てていないだけ。**
- **墜落は t=31.03 のロール指令異常。** 誤差 +5.0°・p=+20 deg/s に対し **−1199 deg/s²**（逆向き、
  直前 4 サンプルの +134〜+419 の 14 倍）を指令。同時に 2 発が box 制約に到達。
  → p = −169 → −307 deg/s → 転覆。
- **フェイルセーフは正しく作動**（t=31.24、FS_RATE）。**実飛行での初の作動記録。**
  NMPC 出力が NaN になった t=31.89 より**先**に効いている。
- **`cnt_sr2_c = 13` はすべて t ≥ 31.89（墜落後）。** `Cp`/`Cq` の変更は原因ではない。
- `iter_us` 平均 7311 / `loop_us` 平均 9220 µs。**周期は健全。**
- **`u_rl` の Δu 変動だけ他 5 本の 2.8 倍**（0831_v4 は 1.47、0904_v1 は 1.51）。
  v3 では他 5 本が静かになったのに RL だけ静かにならず、全時間帯で 2.6–3.6 倍。

**⚠ 原因を特定できていない。** t=31.03 の異常は
(a) box 制約が効き始めた瞬間に `admm_max_iter = 2` では解が収束しなかった、
(b) サンプル間（制御周期 10 回分）の外乱に `Q_phi=200` の高いゲインで過反応した、
のどちらか。**10 Hz ログでは分離できない。**

## 対応

解析資料 [`docs/20260904_v3_crash_analysis.md`](../../20260904_v3_crash_analysis.md)、
図 `plots/0904_v3_crash.png`。**コードは未変更。**

優先順:
1. **100 Hz ログを取れるようにする。** `Logdata` / `log_output()` は既にある。
   **これが無いと同じ事象がまた特定できない。**
2. **`Q_phi`/`Q_theta` を 200 → 100 に戻す。** 今回ロール指令 rms が 2.6° しかなく
   **効果を評価できていない**のに、ループゲインだけ 1.4 倍になっている。
3. `CQ` 3.0e-8 → 5.8e-9（`C_QT` 0.0576 → 0.011）。飽和に余裕ができた今が入れどき。
4. フェイルセーフ時に `nmpc_reset_request()` を呼ぶ。
5. RL モータの物理点検。

**却下した案**: `Cp`/`Cq` の変更を疑って戻す。SR2 異常は全て墜落後で、飛行中は 0 だった。
**却下した案**: いきなり `admm_max_iter` を増やす。周期時間を食ううえ、RL の異常が
物理側かもしれない。**物理点検が先。**

## 検証結果

- すべて `0904_v3.csv`（318 点 / 10 Hz）の静的解析。**推奨した変更の検証は未実施。**
- **t=31.03 の異常の原因は未特定**（上記 ⚠）。
- ヨードリフトが「育つ」理由（電池電圧低下・プロペラの緩み・モータ発熱）は**切り分けていない**。
- `Q_phi=200` の効果は**評価不能**（操縦入力が小さすぎた）。

## 次に触る人へ

- **10 Hz のテレメトリでは 0.1 秒で起きる破綻の原因は絶対に分からない。**
  今回「指令が逆向きに 14 倍」までは見えたが、その 1 サンプル前に何があったかが見えない。
  **飛ばす前に 100 Hz ログの経路を用意すること。**
- **効果を評価できない飛行で重みを変えない。** 今回ホバリング中心でロール指令 rms 2.6°。
  追従性能を測りたいなら**意図的にステップ指令を入れる**こと。
  測れないまま変えると、ゲインだけ上がって発振余裕が減る。
- **モータ 1 本だけ Δu の分散が突出していたら疑う。** 配分の零空間が特定のモータに
  落ちている（ADMM の収束不足）か、物理的な異常。**他が静かになったのに 1 本だけ静かにならない**のは異常。
- **フェイルセーフは実飛行で作動し、NaN より先にモータを止めた。** 入れておいてよかった。
  ただし**作動後に NMPC の内部状態がリセットされない**ので追加すること。
