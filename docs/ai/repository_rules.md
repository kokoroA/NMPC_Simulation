## 1. プロジェクトの正体

小型ドローンの **非線形モデル予測制御（NMPC）** 研究リポジトリ。卒業研究テーマは
**「NMPC を用いたヘキサコプタの耐故障制御（FTC）」**、完成目標は 2026 年 9〜10 月。

最終ゴールは「モータが 1〜2 個停止しても姿勢を水平に保ち、高度を維持する」制御器を
**Raspberry Pi Pico 2 W 上で 100 Hz 実時間動作**させること。

## 3. アーキテクチャ方針（変更時は必ず理由を decisions に残す）

- **状態・入力**: NMPC は姿勢のみ `x = [φ, θ, p, q, r]`（NX=5）、入力は各モータ duty `∈[0,1]`（Hexa は NU=6 / Quad は NU=4）。プラント側のみ 11〜12 次元（高度・水平・ψ）に拡張する。
- **ソルバ**: 凝縮形 NMPC + **ADMM（ρ=1.0, 1 iteration = RTI）** + **SR2（Powell damped BFGS 相当）** による Hesse 行列のランク更新。`H = Suᵀ Q Su + R` の再構築は計算量的に禁じ手（`memo/研究メモ/rti_tr1_sr2_nmpc_control_flow.md` 参照）。
- **マルチレート**: プラント 1 kHz（RK4）/ NMPC・高度 PID 100 Hz（ZOH）、ホライズン **N=30**。
- **高度との統合**: **加算合成 `u_cmd = u_baseline + Δu`**（PKG-C）。Hexa-X の `B_c·1 = 0` により平均モード（高度＝PID 担当）と差分モード（姿勢＝NMPC 担当）が分離することが根拠。**NMPC の状態次元を増やして高度を入れてはならない。**
- **耐故障**: 故障はモータ効率 `η` として **box 制約（U_max 縮減）と U_ref シフト**で表現し、故障パターンごとの分岐や専用ミキシングは書かない。ソルバに再配分を最適化させる。故障検知時は SR2 を即時リセット。
- **バンプレス**: モード切替・故障発生時は必ず ramp / フェードイン（PKG-A, PKG-D）を通す。ステップ入力による推力急変は不具合として扱う。
- **実機リアリティ**: モータ一次遅れ・パラメータ不一致・センサ遅延・量子化などは PKG-E1〜E8 として**プラント側にのみ**適用する。NMPC 内部モデルは公称値固定。

## 4. 基本制約（守るべきこと）

1. **`sanity_checks()` の 24 項目を壊さない。** パラメータ・PKG を触ったら必ず実行して回帰確認する。
2. **Params と `nmpc_params.hpp` の対応を崩さない。** Python は移植前の仕様書を兼ねる。
3. 数値型は Python 側 float64。**Pico 2 移植時の単精度挙動は未検証**であり、精度前提の変更は要検証。
4. 計算負荷は常に「100 Hz で回るか」で評価する（現状 mean iter 1.5〜3.4 ms＝実効 270〜670 Hz）。
5. 大容量バイナリ（`venv/`, `*.pptx`, `.DS_Store`, `eigen/`, `pico-sdk2/`）はコミットしない。
6. ドキュメント・メモは**日本語**で書く。既存の記法（意図を必ず併記する形式）に合わせる。

## 5. 現在の到達点（2026-06-09 面談時点）

- Hexa 版シミュレータでシナリオ S1〜S8（健全 / 部分・完全故障 / FDI 既知・未知 / M5+M6 二重故障 / 外乱）を評価済み。S1 は rms_φ=0.003 rad、S4（二重故障）でも rms_φ≈0.004 rad。
