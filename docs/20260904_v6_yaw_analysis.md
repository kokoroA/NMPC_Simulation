# 0904_v6.csv 解析 — ヨーは「重みが足りない」側。`Psi_ref` ではなく `Q_r` を上げてください

- **ログ**: `Benzen_NMPC/tools/0904_v6.csv`（10 Hz、206 点 / 25.2 s、自由飛行 12.7 s）
- **図**: `plots/0904_v6_yaw.png`
- **この版**: `CQ` 3.0e-8 → **5.8e-9**（`C_QT` 0.0576 → **0.0111**）、`Q_phi=Q_theta=150`、`Psi_ref` ±54 deg/s

---

## 0. 結論 — `Q_r` を上げてください。`Psi_ref` は上げないでください

| 判断材料 | 値 |
|---|---|
| **ヨー軸の使用率** | **5 %**（作れる最大差動 ±2.85 に対し、実際は平均 −0.141） |
| ヨーの追従振幅比 | **−1.066**（相関 +0.21）＝ **指令にまったく追従していない** |
| ドリフト（指令中立時） | **+21 deg/s**（最大 +44.6） |
| 指令スケール | ±54 deg/s |

- **ヨー軸は飽和していません。押す余地が 20 倍あります。** → 重みを上げれば押せます
- **`Psi_ref` を上げても追従しません。** ドリフト +21〜44 deg/s は既に指令範囲 ±54 の内側で、
  **スケールが足りないのではなく、指令どおり回らないのが問題**です。
  スケールだけ上げると duty を食ってロール/ピッチが再び痩せます（v1 の再来）

---

## 1. 何が起きているか

### 1-1. 制御器は正しい向きに、しかし「足りるつもりの量」しか出していない

```
定常のヨー差動 ΣkS·Δu = -0.141   → 指令ヨートルク -0.00163 Nm = -31 deg/s²
```

モデル上は「31 deg/s² 出しているのだから 20 deg/s のドリフトは 1 秒で止まる」計算です。
**実際は止まらず、+21 → +33 deg/s と育っています。**

```
corr(指令ヨートルク, 実測ヨー角加速度) = +0.16 〜 +0.25
実効 1/Iz = -3 〜 -8   （モデル 1/Iz = 333）
```

**指令したトルクが、モデルどおりの角加速度を生んでいません。**

### 1-2. これは「小さな物理的不均衡」で説明がつきます

```
ホバー時の 1 発あたり反トルク = C_QT × T = 0.0111 × 0.634 = 0.00706 Nm
1 発だけ 10 % ずれると        = 0.00071 Nm の不均衡 → 13 deg/s²
```

**制御器が出している 31 deg/s² と同じオーダーです。**
プロペラのピッチ差・破損・緩み、モータ取付角のわずかなずれで、この規模の外乱は簡単に出ます。

### 1-3. 発振ではありません

`r` の範囲は **−5.7 〜 +44.6 deg/s**。**常に正側**で、一方向に回り続けています。
符号反転は平均まわりで 0.99 Hz 相当ですが、これは変動であって振動ではありません。

## 2. 対処

### 【第一手】`Q_r` を 20 → 60

```cpp
constexpr float Q_r = 60.0f;   // 20 → 60
```

- 定常偏差は概ね **√(R/Q_r)** に比例するので、3 倍で **指令は約 1.7 倍**
- ヨー差動は −0.141 → −0.24 程度。**上限 2.85 に対して 9 %** なので、まだ十分余裕があります
- 効きが足りなければ 100（指令 2.2 倍）まで上げられます

⚠ **ヨーは角速度のループ（1 重積分）なので、上げすぎるとモータ遅れで発振します。**
今回は発振の兆候が無いので上げられますが、**1 回に 1 段ずつ**にしてください。

### 【やらないこと】`Psi_ref` を上げる

- 追従振幅比 −1.066 ＝ **指令にまったく追従していません**。大きくしても同じです
- ドリフト +44.6 deg/s は既に ±54 の内側。**スケール不足ではありません**
- **duty を食ってロール/ピッチが痩せます。** 0904_v1 でヨーが Δu の 84.7 % を占めて
  ロール/ピッチが動かなくなったのと同じことが起きます

### 【本筋】物理的な不均衡を潰す

`Q_r` を上げるのは**症状の押さえ込み**です。0.0007 N·m 程度のずれで説明がつく以上、
まずここを見てください。

- 6 枚のプロペラのピッチ・破損・変形・**緩み**
- モータの取付角（わずかな傾きが反トルクの不均衡になる）
- **回転方向が `kS = [-1,+1,+1,-1,-1,+1]` と一致しているか**

### 【確認】`Iz` は実測値ですか

`Iz = 3.00e-3` が仮値だと、ヨーの見積り全体がずれます。
`docs/bifilar_inertia.py` / `analyze_Iz.py` で `Ix`/`Iy` は二線振り子で測っていますが、
**`Iz` も同じ方法で測っていますか。**

## 3. 他に見えたこと

### 3-1. `C_QT` の修正と `Q_phi=150` は効いています

| | v1 | **v6** |
|---|---|---|
| Δu のうちヨー | 84.7 % | **29.3 %** |
| ピッチの追従振幅比 | 0.05 | **0.291**（相関 +0.52） |
| ロールの追従振幅比 | 0.09 | 0.103（相関 −0.10、**指令 rms 2.1° で評価不能**） |

**ピッチは明確に改善しました。** ロールは操縦入力が小さすぎて評価できていません。

### 3-2. ⚠ `Q_phi` は 150 です（100 ではありません）

「100 に戻した」とのことでしたが、`nmpc_params.hpp` は `Q_phi = Q_theta = 150.0f` です。
ログの `Q_phi_eff` も 150 でした。**意図した値か確認してください。**

### 3-3. `common` 成分が Δu の 45 % を占めています

スロットル操作（`u_base` の上下）が大きく、`u_base` 平均 0.651 → **上向き余裕 0.299**。
飽和は 35 % で、これは v1（39 %）とほぼ同じです。
**機体を軽くするか、ホバー duty を下げないと、どの軸も痩せたままです。**

### 3-4. フェイルセーフが着陸時に作動しました

t=24.66、`u_base=0.094`（スロットルを絞った状態）、`|r|=73 deg/s`。**飛行中ではありません。**
接地時のバウンドと思われます。ラッチするので着陸のたびに再アームが要ります。
煩わしければ、判定に `common_duty >= Disable_duty` を加えてください。
