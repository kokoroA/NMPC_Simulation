## 2. 制御則の構造

- **状態** `x = [φ, θ, p, q, r]`（5 次元。**位置・高度・ψ は持たない**）
- **入力** 6 モータの duty ∈ [0, 1]
- **高度はスロットル手動**。`u_hover = T_ref × 0.7`、`T_ref = 0.5 × 7.4 × スティック割合`
  → **`u_hover = 2.59 × スティック割合`**
- **モデル**（連続時間、オイラー離散化 dt = 0.01）
  ```
  φ̇, θ̇ : オイラー角運動学
  ṗ = (−kYm·T_max/Ix)·u + (−(Iz−Iy)qr − Cp·p|p|)/Ix
  q̇ = (+kXm·T_max/Iy)·u + (−(Ix−Iz)rp − Cq·q|q|)/Iy
  ṙ = (+kS·C_QT·T_max/Iz)·u + (−(Iy−Ix)pq − Cr·r|r|)/Iz
  ```
  ⚠ **推力は duty に線形（`T = T_max·u`）と仮定**している。`T_max = 0.75`。
  `C_QT = 0.0296`、`Cr = 1.0e-4`、`Cp = Cq = 0.025`（⚠ **Cp/Cq は未実測の仮値**）
- **ソルバ**: 凝縮形 + RTI（1 反復）+ TR1（Su のランク 1 更新）+ SR2（Hessian のランク 2 更新）
  + **ADMM（ρ = 1.0、4 反復）**で box を処理
- **box**: `Δu ∈ [−u_hover, 0.95 − u_hover]`（＝**絶対 duty で [0, 0.95]**）
- **コスト**: `Q_φ = Q_θ = 1000`, `Q_p = Q_q = 80`, `Q_r = 40`, `R_u = 620`, 終端重み ×10、ホライズン **N = 14**
- **実装**: core1 = 100 Hz（EKF → 参照生成 → NMPC → duty）、core0 = 400 Hz（clamp・フェイルセーフ・ZOH 出力）
- **フェイルセーフ**: 姿勢 90°、角速度 **360 deg/s**、加速度 150 m/s²。成立すると全モータ停止しラッチ
- ⚠ **姿勢の積分（トリム）は無効**。比例のみ

## 3. ★確定している事実★

### 3.1 静推力（ベンチ実測。**独立実験で相互検証済み**）

firmware の duty 軸で測った f1404 + GEMFAN-3630-3 の単発推力:

| duty | 0.250 | 0.375 | 0.500 | 0.625 | 0.750 | 0.875 | 1.000 |
|---|---|---|---|---|---|---|---|
| T [N] | 0.2904 | 0.4150 | 0.5131 | 0.6141 | 0.7063 | 0.7907 | 0.8731 |
| 区間の傾き dT/du | — | 0.997 | 0.785 | 0.808 | 0.738 | 0.675 | **0.659** |

- フィット: **`T = 0.883·u^0.789`（R² = 0.9991）** / 2 次 `−0.2264u² + 1.0523u + 0.0453`（R² = 0.9997）
- ⚠ **凹（n < 1）。duty が上がるほど `dT/du` は下がる。**
- **相互検証**: duty 1.0 の単発 0.8731 N × 6 = **534.0 g** に対し、**6 発同時実験の実測 532 g（差 −0.4 %）**
- `Ct = 5.42e-7 N·s²/rad²`（`T = Ct·ω²`、R² = 0.998）
- ⚠ 6 発実験は **300 秒で 532 g → 470 g（−12 %）**まで低下。**電池電圧の影響は大きい**

### 3.2 推力収支（確定）

| 質量 | ホバー duty（計算） | ホバー duty（飛行実測） | 上向き余地 `0.95 − u_hover` | T/W |
|---|---|---|---|---|
| 285 g（貨物なし） | 0.550 | **0.5506** | 0.400 | 1.87 |
| **309.5 g（貨物あり）** | **0.610** | **0.606** | **0.344** | **1.72** |

⚠ **計算と飛行実測が一致している。推力そのものは足りている。**

### 3.3 飛行ログから確定していること（100 Hz、33 列、リング 19.8 秒）

**墜落便（貨物あり、実時間 9.1 秒）の経過**:

| t [s] | 事象 |
|---|---|
| 1.0–7.3 | **安定ホバー**。\|φ\|, \|θ\| ≤ 4°、\|Δu\| の p50 = 0.040 / p90 = 0.073 |
| 7.31–7.58 | 操縦者がロール指令 `φ_ref` 0 → **−7.7°**。⚠ **`φ` は +2.7° と逆方向**。同時に指令なしで `θ` が 0 → **−4.8°** |
| **7.59–7.65** | ⚠ **FR が duty 上限 0.95 に 6 周期連続で張り付き**（`\|Δu\| = 0.306 = 上向き余地ちょうど`）。この区間の飽和率 46 % |
| **7.68** | **31.5 ms のフル再構築（Hessian 再計算）がここに落ちた。** 解が不連続にジャンプ（FR 0.95→0.67、MR 0.60→0.80、`p` 15→36 deg/s） |
| 7.70–8.50 | **半周期 0.2–0.3 s の振動が振幅を倍々で拡大**（\|p\| 53 → 96 → 166 → **306** deg/s）。操縦者の指令も ±13〜20° で振れており **PIO が重畳** |
| **8.54** | `q` = −371 deg/s で **角速度フェイルセーフ（360 deg/s）がラッチ** → 全モータ停止 |
| 8.57–8.77 | 加速度 4.0 → **0.3 m/s²（自由落下）** |
| 8.82 | 加速度 112 m/s²（接地） |

**Δu の中身**（安定区間 3.5–7.3 s、モーメント写像 3×6 の行空間／ヌル空間に分解 + 分光）:

| | モーメント生成成分 | ヌル空間成分 | 0–2 Hz | 2–5 Hz | **5–15 Hz** | **15–40 Hz** | 40–50 Hz |
|---|---|---|---|---|---|---|---|
| 貨物あり便 | 90.8 % | 9.2 % | 10.5 % | 5.3 % | **46.6 %** | **36.7 %** | 1.8 % |
| 別の貨物あり便 | 92.5 % | 7.5 % | **78.0 %** | 9.6 % | 16.1 % | 8.9 % | 0.5 % |

⚠ **墜落便は指令 `Δu` のエネルギーの約 85 % が 5 Hz より上にある。**

**その他の確定事項**:
- **モータの実効遅れは 40–50 ms**（過去の複数便で同定済み）＝ **帯域 3–4 Hz**
- `B_c · 1 = 0`（健全時）。**全モータを同量だけ増減してもモーメントは厳密に変わらない**
- ソルバ健全性: 直近便は ADMM 双対リセット 0 回、非有限 0 回、線形化点ガード発火 0 回
- フル再構築（39 ms → 最適化後 28 ms）は飛行時間の 11 % → **4 %** に削減済み

## 4. ⚠ 「同定できない」と確定していること

- **閉ループ飛行ログから、入力行列 `B` のゲインや減衰係数 `Cp, Cq, Cr` は同定できない。**
  素朴な回帰（`dp/dt` を `Δu` に回帰）は相関 0.35–0.52 しか出ず、
  1 ステップ予測誤差最小化（モータ遅れ τ も同時推定）で検算すると
  **ゲイン比 γ が −0.51 〜 +1.44 にばらつき（負は物理的にありえない）、残差分散比 0.93–0.99
  ＝ モデルが説明できるのは 1–7 % だけ**、τ も探索範囲の端に張り付く。
  ⚠ **この失敗は過去に 2 回繰り返している。「飛行ログから回帰すればよい」は提案しないでほしい。**
- **`Cp, Cq`（ロール・ピッチ減衰）は一度も実測していない。**
- **`Cr`（ヨー減衰）の実測は 9.5e-5 〜 3.7e-4（4 倍のばらつき）。** 現在は暫定 1.0e-4。
- **電池電圧を機上で測っていない。**

## 6. 考えられる仮説（私の優先順。⚠ すべて未検証）

1. **モータ遅れ 40–50 ms に対する位相不足**
   帯域 3–4 Hz に対して発散が 2–3 Hz。予測モデルに**アクチュエータ動特性が入っていない**。
   過去 1 か月の複数の墜落でも「3–4 Hz 限界モード」が一貫して主犯候補に挙がっている。
2. **高周波指令が飽和余地を食っている**
   指令の 85 % が 5 Hz 超。機体は応答できないのに `duty` は動くので、
   `0.95` の上限に当たる確率だけが上がる。貨物で余地が 0.400 → 0.344 に減ったぶん顕在化した。
3. **飽和時の配分歪み**
   現状はモータごとに独立クリップしているので、**モーメントの「向き」ごと歪む**。
   （`B_c·1 = 0` なので全機を下げれば向きを保ったまま余地を作れるが未実装）
4. **貨物の振り子**
   2–3 Hz は長さ 3–7 cm の振り子と同程度。25 g が 10 cm 下なら Ix に +14 %。
   ⚠ 取り付けが剛かどうかを確認していない。
5. **慣性モーメントの誤り**
   Ix/Iy/Iz は **335 g のときの実測値**を 285–310 g で使い続けている。
6. **重心ずれ**
   積分（トリム）が無効なので定常偏差が残る。25 g が 2 cm ずれると 156 deg/s² の定常モーメント。
7. **PIO（操縦者による増幅）**
   発散中に操縦入力が ±13〜20° で振れている。
