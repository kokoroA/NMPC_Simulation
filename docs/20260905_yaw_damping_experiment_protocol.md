# ヨー軸吊り試験 実施要領 — `Cr`（ヨー回転減衰係数）の同定

- **目的**: `nmpc_params.hpp` の `Cr` を実測で決める。副産物として `C_QT`・モータ一次遅れ `tau` も得る
- **対象機体**: Hexa-X / F1404 Kv2900 + GEMFAN-3630-3
- **解析スクリプト**: `Benzen_NMPC/tools/fit_yaw_damping.py`（`--selftest` で手法検証可）
- **背景**: [`20260905_cr_upper_bound_and_yaw_hang_test.md`](ai/decisions/20260905_cr_upper_bound_and_yaw_hang_test.md)、
  [`20260905_cq_damping_sysid_plan.md`](20260905_cq_damping_sysid_plan.md)

---

## 0. なぜこれを測るのか

`Cr` は**耐故障（FTC）が成立するかどうかを 1 人で決めている値**である。
FR 停止時に残り 5 発を使う「relaxed hover（回転しながら釣り合う飛び方）」が成立するかは
`Cr` の 1 桁で反転する。現在 `nmpc_params.hpp` に入っている `Cr = 0.005` は**根拠の無い仮値**で、
既存ログから `Cr ≤ 2.1e-4` という上界が出ている（2 桁小さい）。**点推定が要る。**

飛行ログからの回帰は 180 条件を試して識別不能と確定済み。**専用の実験でしか決まらない。**

## 1. 用語集

| 用語 | 意味 |
|---|---|
| **`p, q, r`** | 機体座標系の角速度 [rad/s]。`p` = ロール（前後軸まわり）、`q` = ピッチ（左右軸まわり）、`r` = **ヨー（上下軸まわり）**。この試験で動かすのは `r` だけ |
| **`rdot`（`ṙ`）** | `r` の時間微分＝ヨー角加速度 [rad/s²] |
| **`Ix, Iy, Iz`** | 各軸まわりの**慣性モーメント** [kg·m²]。「回しにくさ」。`Iz` はヨー軸 |
| **`tau_z`（`τ_z`）** | **モータが機体に与えているヨー方向のトルク** [N·m]。§3 で詳述 |
| **トルク** | 回転させる力の効き具合 [N·m]。`トルク = 慣性モーメント × 角加速度` が回転版のニュートンの法則 |
| **`C_QT`** | 推力 1 N あたり何 N·m の反トルクが出るかの係数 [m]。`C_QT = CQ / Ct` |
| **反トルク** | プロペラが空気を回すと、その反作用で機体が逆向きに回されること。ヨーはこれで作る |
| **`Ct`** | 推力係数。`T = Ct·ω²`。実測済み **5.209e-7**（R²=0.998） |
| **`CQ`** | 抗トルク係数。`Q = CQ·ω²`。推定値 **5.8e-9**（未実測） |
| **`Cr`** | **ヨー回転の二乗減衰係数** [N·m·s²/rad²]。`Cr·r|r|` が回転を止める向きに働く。★同定対象★ |
| **`b`** | ヨー回転の**線形**減衰係数 [N·m·s/rad]。`b·r`。低回転域で効く |
| **`tau_f`（`τ_f`）** | **クーロン摩擦**トルク [N·m]。軸受（スイベル）由来。回転速度によらずほぼ一定 |
| **クーロン摩擦** | 滑り摩擦。大きさが速度にほとんど依存せず、向きだけが速度と逆になる摩擦 |
| **`u`（duty）** | モータへの指令値 0〜1。ファームでは 0.95 で頭打ち |
| **`u0`（common duty）** | 6 発全部に共通で与える duty。「全体の回転数の水準」 |
| **`Delta`（`Δ`）** | ヨーを作るための**差動量**。`u_i = u0 + s_i·Delta` |
| **`s_i`（`kS`）** | 各モータの反トルクの符号 `[-1, +1, +1, -1, -1, +1]`（順は FR, FL, MR, ML, RR, RL） |
| **`T(u)`** | duty から推力 [N] への実測曲線。GEMFAN は `-0.2265u² + 1.0525u + 0.0452` |
| **`H 力`** | 回転しているロータが横方向の風を受けたときに面内に出る抗力。多回転翼機のヨー減衰の主因 |
| **前進比（advance ratio）** | ロータが受ける横風速度 ÷ 翼端速度。小さいと `H 力` は速度に**比例**（＝線形減衰 `b`） |
| **スイベル** | 糸のねじれを逃がす釣具部品。ここでは「ヨーだけ自由にする軸受」として使う |
| **二線振り子（bifilar）** | 平行 2 本吊りでねじり振動させ慣性モーメントを測る手法。**復元トルクを作る装置なので本試験には使わない** |
| **条件数（cond）** | 最小二乗の解きやすさの指標。大きいほど「複数の項が似た形をしていて分離できない」 |

## 2. 実験装置

```
              天井 / スタンド
                   │
                   │  ← 上部ライン 1 本
              ［ベアリングスイベル］  ← ヨーの自由度はここだけ
                   │
                  ○ リング
                ╱ │ ╲              ← 機体側 3 本（1 点に集める）
          ────┴─┴─┴────         ← 機体（上下逆さ・プロペラ下向き）
               ↓ ↓ ↓ ↓ ↓            ← 推力は下向き＝ラインを張る向き
```

### 各部の役割

| 部品 | 役割 | 選定理由 |
|---|---|---|
| **機体側 3 本** | ロール・ピッチを止める | 3 点から 1 点への距離が固定されると機体は剛に固定される。**`p = q = 0` を構造的に作る**のが目的 |
| **スイベル** | ヨーだけ自由にする | 糸のねじり戻りトルクを消す。**ボールベアリング型を使うこと**（§8） |
| **上部ライン 1 本** | 吊り下げ | 長めに取り、床から離す（プロペラ後流の再循環を避ける） |

### ⚠ 逆さに吊る理由

プロペラを下向きにすると**推力が機体を下へ押す＝ラインを張る向き**になる。
正立で吊ると、推力がホバー相当を超えた瞬間にラインが緩んで機体が暴れる。
逆さなら**ホバー以上の回転数でもラインが張ったまま**で、ロータを飛行時と同じ動作点で回せる。

### ⚠ 平行 2 本吊りにしてはいけない

それは**二線振り子**そのもので、**意図的にねじり復元トルクを作る装置**である
（慣性モーメント測定用。`bifilar_inertia_method.md`）。減衰を測る本試験では復元トルクは邪魔になる。

## 3. 物理モデル — 式と各項の意味

### 3-1. 元の式

ファームウェアの [`nmpc_model.cpp`](../program/pico/pico-sdk2/pico-sdk/Benzen_NMPC/nmpc_model.cpp) が持っているヨー軸の運動方程式は

```
Iz·rdot = tau_z − (Iy − Ix)·p·q − Cr·r·|r|
```

これに実験特有の項（軸受摩擦・線形減衰・オフセット）を足したものが同定モデルになる。

```
Iz·rdot  =  tau_z  −  (Iy−Ix)·p·q  −  tau_f·sign(r)  −  b·r  −  Cr·r·|r|
 ①          ②           ③              ④              ⑤        ⑥
```

### 3-2. 各項の意味

| 項 | 名前 | 単位 | 意味 | この試験での扱い |
|---|---|---|---|---|
| ① `Iz·rdot` | 慣性項 | N·m | 「回しにくさ × 角加速度」。回転版の `ma` | ログの `r` から得る |
| ② `tau_z` | **入力トルク** | N·m | モータが作るヨートルク。§3-3 | フェーズ②で校正、フェーズ④で **0 にする** |
| ③ `(Iy−Ix)·p·q` | ジャイロ結合項 | N·m | ロールとピッチが同時に回ると出る見かけのヨートルク | 治具で `p = q = 0` にして**構造的に消す** |
| ④ `tau_f·sign(r)` | クーロン摩擦 | N·m | 軸受（スイベル）の滑り摩擦。**速度によらずほぼ一定**、向きだけ逆 | 定数項として**回帰で推定する** |
| ⑤ `b·r` | 線形減衰 | N·m | ロータの `H 力` 由来。**低回転域で支配的** | 回帰で推定する |
| ⑥ `Cr·r·|r|` | **二乗減衰** | N·m | 空気抵抗型。**高回転域で支配的** | ★これが欲しい★ |

> **なぜ `r|r|` で `r²` ではないのか**: `r²` は常に正なので、逆回転のときに「加速させる向き」の力になってしまう。
> `r|r|` は大きさが `r²` で符号が `r` と同じなので、**常に回転を止める向き**になる。

> **なぜ ⑤ と ⑥ の両方が要るのか**: 物理的には、ロータの `H 力` は**前進比が小さいうちは速度に比例**する
> （＝線形 ⑤）。⑥ だけで当てはめると、低回転域の線形分を無理に二乗項へ押し込み、**`Cr` を約 10 % 過大評価**する。

### 3-3. `tau_z` とは何か

**モータが機体に与えているヨー方向のトルク**である。プロペラが空気を回す反作用（反トルク）の合計。

```
tau_z = C_QT · Σ s_i · T(u_i)
              i=1..6
```

| 記号 | 意味 |
|---|---|
| `T(u_i)` | モータ `i` が出している推力 [N]。duty から実測曲線で換算 |
| `s_i` | そのモータの回転方向の符号 `[-1, +1, +1, -1, -1, +1]` |
| `C_QT` | 推力 1 N あたりの反トルク [m]。`= CQ/Ct`、推定値 0.01113 |

つまり **「時計回りのモータの推力合計」と「反時計回りの推力合計」の差**に `C_QT` を掛けたものが `tau_z`。
全部同じ推力なら `Σ s_i = 0` なので `tau_z = 0` になる。**これが後で効く。**

### 3-4. 加振のしかた — なぜ「差動」なのか

```
u_i = u0 + s_i · Delta        (i = 1..6)
```

- `Σ s_i = 0` なので、**合計推力はほぼ変わらない**（ラインの張力・傾き・ロータ動作点が一定に保たれる）
- `tau_z ≈ 6 · C_QT · T'(u0) · Delta` （`T'` は推力曲線の傾き）

「3 発だけ回して回す」ではダメな理由:
合計推力が変わって吊りの状態が動くうえ、2 グループのロータ動作点が離れて
**「どの回転数での `C_QT` / `Cr` なのか」が曖昧になる**。

### 3-5. なぜ `Cr` そのものではなく `Cr/Iz` が出るのか

式全体を `Iz` で割ると

```
rdot = (tau_z/Iz) − (tau_f/Iz)·sign(r) − (b/Iz)·r − (Cr/Iz)·r|r|
```

**測れるのは `rdot` と `r` だけ**なので、出てくるのは全部 `Iz` との比になる。

これは**むしろ好都合**である。`nmpc_model.cpp` のヨー行は

```cpp
B_c(4,k) = kS[k] * C_QT * T_max / Iz;              // 入力
xdot(4)  = Bu(4) + (-(Iy-Ix)*p*q - Cr*r*ar) / Iz;  // 減衰
```

と、**どちらも `Iz` との比の形でしか使っていない**。
`Ix/Iy/Iz` は `NMPC_REPORT.md`（6.10/6.53/11.6e-3）と `nmpc_params.hpp`（1.8/1.9/3.0e-3）で
**3.4〜3.9 倍食い違っており、どちらも実測記録が無い**が、
**この試験はその不確かさを通らずにファームを正しくできる。**

絶対値の `Cr` が要るのは relaxed hover の平衡計算のときだけで、そこで初めて `Iz`
（二線振り子、糸とストップウォッチで 30 分）が必要になる。

## 4. 実験手順

前提として **NMPC を通さず duty を直接書く「ベンチ加振モード」** が要る（§9）。
機内 100 Hz リングログを回した状態で行う。

### フェーズ⓪ — ベースライン（モータ OFF）

1. **モータを完全に止めた状態**で、手で `r ≈ 200 deg/s` まで回して手を離す
2. 止まるまで記録する

**得られるもの**: `軸受摩擦 tau_f` + `機体だけの空気抵抗`。
ロータが回っていないので**ロータ由来の減衰は含まれない**。

**このフェーズには 2 つの役目がある。**

- **軸受の良否判定**（§8）
- **本計測から差し引くベースライン**。`ロータ由来の減衰 = 本計測 − ベースライン`

### フェーズ① — 静止確認

全 6 発を `u0` に置いて数秒保持する。`Sum s_i = 0` なので `tau_z = 0` のはず。
`r` が動くならモータ個体差や取り付け角のオフセットがある → `tau_bias` として記録する。

### フェーズ② — ステップ投入（`C_QT/Iz` を取る）

`Delta` をステップで入れ、**立ち上がり 0.15〜0.5 s の `r` の傾き**を測る。

`r = 0` の瞬間は

```
Cr·r|r| = 0     b·r = 0     (Iy−Ix)·p·q = 0
```

が**厳密に**成り立つので、残るのは

```
rdot(0) = tau_z / Iz
```

だけ。**減衰について何も仮定せずに入力ゲイン `C_QT/Iz` が決まる。**

> 0.15 s より前を使わないのは、モータ一次遅れ（`tau ≈ 50 ms`）で推力がまだ立ち上がりきっていないため。
> **逆に、この立ち上がり波形そのものから `tau` を読める**（副産物）。

> 0.5 s より後を使わないのは、`r` が育って減衰が効き始めるため。
> `Cr = 2e-4` なら 0.3 s 時点での減衰の寄与は **0.5〜1.0 %** で無視できる。

### フェーズ③ — 加速（待つだけ）

`r` が 150〜200 deg/s になるまで待つ。

### フェーズ④ — 自由減衰（★本計測★）

**`Delta` を 0 に戻す**（`u0` は保持したまま）。すると

```
tau_z = 0        ← 推定するのではなく「ゼロだと分かっている」
```

なので式は

```
Iz·rdot = − tau_f·sign(r) − b·r − Cr·r|r|
```

**減衰だけが残る。** 止まるまで（または `r` が 1/3 以下になるまで）記録する。

### フェーズ⑤ — 条件を変えて繰り返す

- `u0` を 3 水準（0.35 / 0.45 / 0.60）→ **減衰がロータ回転数に依存するか**が分かる
- `Delta` の符号を正逆両方 → 左右非対称性と `tau_bias` の分離

## 5. どうやって `Cr` を求めるか

### 5-1. 微分せず、積分する

`rdot` を数値微分するとノイズが増幅される。代わりに区間 `[t0, t1]` で積分した形を使う。

```
r(t1) − r(t0) = − (tau_f/Iz)·(t1−t0)
                − (b/Iz)·∫r dt
                − (Cr/Iz)·∫r|r| dt
```

左辺も右辺も**測定値の積分と差分だけ**で書けている。未知数は 3 つ。

### 5-2. 最小二乗に並べる

窓幅 0.5 s、50 % オーバーラップで窓を切り、各窓 1 行として

```
        ┌ −(t1−t0)   −∫r dt   −∫r|r| dt ┐  ┌ tau_f/Iz ┐     ┌ r(t1)−r(t0) ┐
   A =  │    ...        ...       ...     │, x = │ b/Iz     │, y = │     ...     │
        └    ...        ...       ...     ┘  └ Cr/Iz    ┘     └     ...     ┘
```

を `A x = y` として最小二乗で解く。**`x` の 3 番目が求める `Cr/Iz`。**

### 5-3. なぜ 3 項が分離できるのか

3 つの基底関数の比は

```
r|r| / r = |r|          r / 1 = r
```

なので、**`r` が広い範囲を掃けば 3 本は明確に別方向を向く**。逆に `r` がほぼ一定だと
3 本が平行に近づいて分離できない。**掃引範囲がすべて**である。

| 記録時間 | `r` の範囲 | `Cr` 誤差 | 条件数 |
|---|---|---|---|
| 3 s | 200 → 145 deg/s | 30.3 % | 40.5 |
| 5 s | 200 → 122 | 7.5 % | 24.6 |
| **10 s** | **200 → 88** | **0.9 %** | 13.8 |

（合成データ、ジャイロノイズ 0.5 deg/s rms、摩擦なし）

**`200 → 90 deg/s` を 10 秒で掃ければ `Cr` は 1 % 精度。**

### 5-4. 目で見るサニティチェック

摩擦が小さければ、両辺を `r` で割ると

```
−rdot/r = b/Iz + (Cr/Iz)·|r|
```

**`|r|` の 1 次式＝直線**になる。切片が `b/Iz`、傾きが `Cr/Iz`。

- 直線になる → モデルの形（`r|r|`）が正しい
- 曲がる → モデルの形が違う。指数を変える等の検討が要る
- 切片が大きい → 摩擦か線形減衰が支配的

```bash
python3 tools/fit_yaw_damping.py yaw_test.csv --decay 12.0 25.0 --iz 3.0e-3
```

```bash
python3 tools/fit_yaw_damping.py yaw_test.csv --step 5.0 5.5 --prop GEMFAN-3630-3
```

## 6. 設計値（何が起きるはずか）

GEMFAN-3630-3、`tau_z ≈ 6·C_QT·T'(u0)·Delta`:

| `u0` | 6 発合計推力 | `T'(u0)` | `Delta` | `tau_z` |
|---|---|---|---|---|
| 0.45 | 2.84 N (289 g) | 0.849 N/duty | 0.02 | 0.00113 N·m |
| 0.45 | 〃 | 〃 | 0.05 | 0.00283 N·m |
| 0.60 | 3.57 N (364 g) | 0.781 N/duty | 0.02 | 0.00104 N·m |
| 0.60 | 〃 | 〃 | 0.05 | 0.00261 N·m |

フェーズ②の立ち上がり（`Delta = 0.05`）:

| `Iz` | `rdot(0)` | 0.3 s 後の `r` |
|---|---|---|
| 3.0e-3 | 50 deg/s² | 15 deg/s |
| 1.16e-2 | 13 deg/s² | 4 deg/s |

⚠ **定常回転まで待つ方法は取らないこと。** `Delta = 0.05`・`Cr = 1e-4` だと定常 `r` は
**約 300 deg/s**（`Cr = 1e-5` なら 900 deg/s 超）になる。吊った機体をその速度で回すのは危険で、
しかも自由減衰なら同じ情報がより広い `r` 範囲で安全に取れる。

## 7. 判定基準

| 見るもの | 良好 | 要対処 |
|---|---|---|
| 条件数 | 10 前後 | 50 超 → `r` の掃引範囲を広げる |
| `Cr/Iz` の符号 | 正 | 非正 → 掃引不足か摩擦支配。フェーズ⓪を確認 |
| `−rdot/r` vs `|r|` | 直線 | 曲がる → モデル形が違う |
| 残差 rms | ジャイロノイズと同程度 | 大きい → 振り子の揺れや `p, q` の混入を疑う |
| `p, q` | ほぼ 0 | 大きい区間は捨てる（ジャイロ結合項が入る） |

**そして最終的な分岐:**

```
Cr > 1e-3   → relaxed hover は No-Go。ここで終わり。Cp/Cq は測らなくてよい
Cr ≤ 3e-4   → 成立側。ただし必要な回転速度が 300〜610 deg/s で
              現行フェイルセーフ 300 deg/s と衝突する → しきい値の再設計が要る
```

## 8. 軸受（スイベル）の要件 — ここが最大の弱点

**強度ではなく摩擦トルクで選ぶ。**

逆さ吊りでの軸方向荷重は `重量 3.76 N + 推力 3.57 N = 7.33 N`。
市販スイベルの破断強度 56 kgf = 549 N に対し**安全率 75 倍**で、強度は問題にならない。

問題は摩擦。平軸受（バレル型／ローリング型）の摩擦トルクは `mu·N·r_eff` で、
`r_eff ≈ 0.8 mm`、`mu = 0.15〜0.6` として **8.8e-4 〜 3.5e-3 N·m**。
測りたい信号（`Cr=1e-4`, `r=200 deg/s` で **1.22e-3 N·m**）と**同じ桁**である。

> ⚠ 日本の釣具用語の**「ローリングスイベル」はボールベアリングではない**。平軸受の一種である。
> パッケージの「ローリングの約 2 倍の強度」は**強度**の話で、回転の滑らかさとは無関係。

モンテカルロ 40 回（摩擦の定数項を入れて回帰、真値 `Cr=1.0e-4`、`r0=200 deg/s`）:

| 軸受 | `tau_f` | 減衰時間 | `Cr` 誤差 中央値 | 90%tile |
|---|---|---|---|---|
| 平 mu=0.6 | 3.5e-3 | 2.7 s | 28.8 % | 52.5 % |
| 平 mu=0.3 | 1.8e-3 | 4.8 s | 11.4 % | 28.2 % |
| **ボールベアリング** | 5.0e-5 | 25 s | **4.6 %** | 9.8 % |

**→ ボールベアリングスイベル（または 608ZZ 等の玉軸受）を使う。**

### 2 分でできる事前チェック

**モータ OFF で `200 deg/s` 相当まで手回しし、手を離して止まるまでを計時する。**

| `tau_f` | `Iz=3.0e-3` なら | `Iz=1.16e-2` なら |
|---|---|---|
| 1.8e-3（平 mu=0.3） | 5.8 s | 22.5 s |
| 5.0e-5（ボール） | 209 s | 810 s |

**10 秒以内に止まったら軸受を替える。30 秒以上回り続ければそのまま使える。**

（比較: `Cr=1e-4` が `r=200 deg/s` で生む減速度は `Iz=3.0e-3` で 23 deg/s²、`Iz=1.16e-2` で 6 deg/s²）

## 9. ファーム側のベンチ加振モード（実装済み・2026-09-06）

**NMPC を通さず duty を直接書くモードを `control.cpp` に実装した。**
飛行ログ回帰の敗因（**閉ループ共線性・50 Hz チャタリング・モータ遅れ未同定**）は
開ループで duty を直接書くことで 3 つとも同時に消える。

### 設定（`control.cpp` の 1 ブロックだけ）

```cpp
uint8_t Bench_mode   = BENCH_OFF;  // ★ここを BENCH_YAW_EXCITE / BENCH_MOTORS_OFF に★
float   Bench_u0     = 0.60f;      // common duty
float   Bench_delta  = 0.05f;      // 差動量
float   Bench_sign   = 1.0f;       // 差動の向き (+1 / -1)
float   Bench_t_spin  = 3.0f;      // (1)   u0 のみ [s]
float   Bench_t_step  = 6.0f;      // (2)(3) 差動投入 [s]
float   Bench_t_decay = 20.0f;     // (4)   自由減衰 [s]
```

| `Bench_mode` | 動作 |
|---|---|
| `BENCH_OFF` (0) | 通常飛行。**既定値。以下の処理は一切効かない** |
| `BENCH_YAW_EXCITE` (1) | ヨー差動加振。フェーズ①〜④を自動で進める |
| `BENCH_MOTORS_OFF` (2) | モータを止めたままログだけ取る（**フェーズ⓪**） |

### 運用手順

1. `Bench_mode` を書き換えてビルド・書き込み
2. 通常どおりアーム。**LED が全周ピンクの速い点滅（10 Hz）**になる（通常飛行との取り違え防止）
3. **LOG スイッチを ON**（100 Hz リングバッファはこのスイッチで回る）
4. **スロットルを少し上げるとシーケンス開始。**`u0` はスティックではなく `Bench_u0` で決まるので、
   スロットルは「開始・中断」だけを担う（**デッドマンスイッチ**）
5. スロットルを下げると**その場で停止し、シーケンスは頭出しに戻る**。何度でもやり直せる
6. 終わったら通常どおりログを吸い出す

### ログヘッダ

`Bench_mode != BENCH_OFF` のとき、ダンプの先頭に条件が出る。**後から条件を取り違えない。**

```
#bench: mode=1 u0=0.600 delta=0.050 sign=+1 t_spin=3.0 t_step=6.0 t_decay=20.0
```

### ⚠ 加振モード中だけ変わる安全動作

| 項目 | 通常飛行 | 加振モード |
|---|---|---|
| 姿勢の脱出条件（実体 90°） | 有効 | **無効** |
| 角速度の脱出条件（実体 360 deg/s） | 有効 | **無効**（`r` が実験量そのもの。手回しでも超える） |
| 過大G・受信途絶 | 有効 | **有効のまま** |
| `minimum_duty` (0.1) の持ち上げ | 有効 | **無効**（指令をそのまま出す） |
| スロットル下限での `motor_stop()` | 有効 | **有効のまま** |

姿勢と角速度を外すのは、**逆さ吊りで `|phi|` が 180° 付近になり、ヨーは 360 deg/s を実験として超える**ため。
機体は治具で拘束されていて飛び去らない。過大 G と受信途絶だけ残す。
⚠ 要領書の旧表記「姿勢 60° / 角速度 300 deg/s」は誤り。ファームの実体は 90° / 360 deg/s。

⚠ **リングバッファは 22 列で 21.8 s しか持たない。** `Iz` が大きく `Cr` が小さいと
自由減衰が数十秒かかることがある。その場合は `200 → 100 deg/s` の部分減衰で打ち切ってよい。

## 10. 安全

- プロペラを付けたまま機体を回す。**必ず保護メガネを着用し、回転面に人を入れない。**
- 送信機または電源で**即座に止められる状態**を確保してから始める。
- ラインとスイベルは**実験前に必ず引っ張って確認**する（強度は 75 倍あるが、結び目は別）。
- 床から十分離す（プロペラ後流の再循環を避ける目的も兼ねる）。
- `r` が 250 deg/s を超えたら加振をやめる。**定常回転まで回さない。**

## 11. まとめ — 何がどこで消えているか

| 飛行ログ回帰の敗因 | この試験での対処 |
|---|---|
| `tau_z` が未知（チャタリング、指令≠実推力） | **フェーズ④で `tau_z = 0`**（開ループ・ベンチ加振モード） |
| `(Iy−Ix)·p·q` が混入 | **3 本吊りで `p = q = 0`** |
| 入力ゲインと減衰のトレードオフ | **フェーズ②で `r=0` を使い、入力ゲインを先に確定** |
| `r` の範囲が狭い | **200 → 90 deg/s を掃く** |
| （新規）軸受摩擦 | **定数項として回帰に入れ、フェーズ⓪で実測して差し引く** |
| （新規）`Iz` が未実測で 3.9 倍不確か | **比 `Cr/Iz` のまま使う。ファームもその形** |
