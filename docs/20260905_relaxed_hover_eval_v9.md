# relaxed hover 設計の評価 — v9 は設計を検証していない。GEMFAN 交換でも FR 停止ホバーは成立しない

- **評価対象**: [`docs/ai/decisions/20260904_relaxed_hover_equilibrium_design.md`](ai/decisions/20260904_relaxed_hover_equilibrium_design.md)
- **ログ**: `Benzen_NMPC/tools/0904_100Hz_v3.csv`（100 Hz, 2176 行 = 21.8 s）/ `0904_v9.csv`（10 Hz テレメ）
- **状況**: 地上で FTC ON → FR 停止を確認 → そのままスロットル上昇 → 姿勢破綻 → スロットルを戻した
- **プロペラ**: v9 は **betaFPV-D90s-3**、次回から **GEMFAN-3630-3**
- **図**: `Benzen_NMPC/tools/plots/0904_v9_ftc_thrust_margin.png`

---

## 0. 結論（3 行）

1. **v9 は relaxed hover 設計を検証していない。** 設計が仮定した推力より 26 % 弱いプロペラで飛ばしており、
   軌道も定常回転の条件にまったく乗っていない。設計の可否判定に v9 を使ってはいけない。
2. **GEMFAN への交換では FR 停止ホバーは成立しない。** 設計の予備探索は**既に GEMFAN の推力値
   （0.84 / 0.873 N）で行われていた**。プロペラ交換は「これから改善する要素」ではなく、既に織り込み済みである。
3. **relaxed hover が静的 4 発配分に勝てるかどうかは `Cr` だけで決まり、その境目は現在の推定値のすぐ隣にある。**
   設計が「未確定」と書いた `Cr` は付帯的な注意ではなく、**可否そのもの**である。

## 1. 設計の数値を独立に再現した

設計の 2026-09-05 追記の方法（外側で `phi, theta, Omega` を探索、内側は推力について線形）を実装した。
**等式行列は「どのモータが死んでいるか」だけで決まり `(phi,theta,Omega)` に依存しない**ので、
擬似逆行列とヌル空間は 1 回だけ計算すればよい。健全 5 発・等式 4 本なのでヌル空間は 1 次元、
余裕最大化は 10 本の直線の下側包絡線の頂点を全部評価すれば厳密に解ける（`scipy` 不要）。

設計は最小二乗残差、こちらは余裕 `rho` の最大化と目的が違うが、**同じ結論に到達した**。

| 条件 | 設計の記述 | 本評価 |
|---|---|---|
| `fmax = 0.84 N/発` | 平衡解を得られなかった（鉛直力 0.070 N 不足） | **rho = −2.1 %**（解なし） |
| `fmax = 0.873 N/発` | `phi=0.03°, theta=-0.05°, r=34.1 deg/s`、2 発が上限直前 | **rho = +0.9 %**、`Omega = 20 deg/s`、推力 `[0, 0.863, 0.863, 0.845, 0.845, 0.018]` |

⚠ `nmpc_params.hpp` のコメント `C_QT ≈ 0.03614` は古い。現行値は **`C_QT = 5.8e-9 / 5.21e-7 = 0.01113`**。

## 2. v9 はこの設計を検証していない

### 2-1. 使ったプロペラが設計の仮定より 26 % 弱い

`sysid_thrust.py` を両プロペラで実行した実測フィット:

| プロペラ | `T(duty)` | duty 0.95 | duty 1.0 |
|---|---|---|---|
| **betaFPV-D90s-3**（v9） | `0.0904u² + 0.5431u + 0.0243` | **0.622 N** | 0.658 N |
| **GEMFAN-3630-3**（次回） | `−0.2265u² + 1.0525u + 0.0452` | **0.841 N** | 0.871 N |

**設計の予備探索が使った `fmax = 0.84 / 0.873` は GEMFAN の値である。**
v9 の実機はそれより 1 発あたり 26 % 弱い。**設計が「解なし」と判定した条件より、さらに悪い条件で飛ばした。**

### 2-2. そもそも浮ける推力が出ていない

ログの duty を D90S の実測曲線で N に換算した（`u` は 0.95 で clamp）:

| 区間 | 合計推力 平均 | 最大 | `u_base` |
|---|---|---|---|
| FTC ON 低推力 `8.23–12.09 s` | 0.582 N (59 g) | 0.700 N | 0.158 |
| スロットル上昇 `12.09–15.46 s` | 1.412 N (144 g) | 2.413 N | 0.432 |
| 上限超過後 `15.46–17.00 s` | 2.197 N (224 g) | 2.619 N | 0.705 |
| 破綻 `17.00–18.94 s` | 2.541 N (259 g) | 3.111 N | 0.796 |

**FTC 区間全体の最大合計推力は 3.111 N = 317 g。質量 350 g に必要な 3.434 N の 91 % にしか届いていない。**
しかもこれは 3 軸のトルク釣合いが既に壊れた状態での値である。
**姿勢を保ったまま出せる上限は `4 × 0.622 = 2.487 N = 253 g`** で、必要量の **72 %** でしかない。

**「少し上がった」のは地面効果と機体の部分的な荷重抜けであって、ホバーではない。**

### 2-3. 軌道は定常回転条件にまったく乗っていない

設計の運動学 `p = −Omega sin(theta)`, `q = Omega sin(phi) cos(theta)`, `r = Omega cos(phi) cos(theta)` に対し、
各サンプルで `Omega = r/(cos phi cos theta)` と置いたときの `p, q` の残差:

| 区間 | \|p 残差\| rms | \|q 残差\| rms | 実測 \|(p,q)\| | **残差/実測** |
|---|---|---|---|---|
| 上昇中 | 2.4 | 2.1 deg/s | 2.8 | **1.15** |
| 上限超過後 | 8.1 | 13.4 deg/s | 12.9 | **1.22** |
| 破綻中 | 41.6 | 53.2 deg/s | 74.6 | **0.91** |

**残差が実測と同じ大きさ = 定常回転の構造がまったく無い。**単に転んでいるだけである。

### 2-4. `Cr` はこのログからは同定できない

`Iz·rdot + (Iy−Ix)·p·q = tau_z − Cr·r|r|` を `t = 15.0–18.94 s`（394 点、`|r|` 最大 263 deg/s）で回帰:

```
tau_bias = -0.00190 Nm,  Cr = -0.000249    R^2 = 0.027
```

**`Cr` が負（物理的にありえない）で `R²` もほぼ 0。同定できていない。**

原因は明白で、**`Iz·rdot` の rms 0.00911 Nm に対し、指令ヨートルク `tau_z` の rms は 0.00268 Nm しかない**。
**実測のヨー加速度をモータのヨートルクが 3.4 倍も説明できていない。**

読み方は 2 通りある。**どちらかを確定させないと relaxed hover の平衡は解けない。**

- **`C_QT` が小さすぎる**: 同じ比を `C_QT` で吸収するなら `C_QT ≈ 0.038`（`CQ ≈ 2.0e-8`）。
  偶然にも `nmpc_params.hpp` の古いコメント `0.03614` に近く、旧値 `CQ = 3.0e-8` の 66 % にあたる。
- **未モデル化のヨートルクが支配的**: 過去の解析（`0904_v6`）でも
  `corr(指令ヨートルク, 実測ヨー角加速度) = +0.16〜0.25` と低く、こちらの可能性も高い。

⚠ どちらにせよ **`CQ = 5.8e-9` は疑わしい**。ただし v9 は転倒・接地を含む区間なので、これ単独では断定できない。

## 3. GEMFAN に替えても FR 停止ホバーは成立しない

### 3-1. 静的（水平・3 軸 0 トルク）4 発配分

`20260904_ftc_yaw_relaxed_hover.md` の一般解 `FL=a, MR=c+e, ML=c, RR=a−e, RL=e` で
合計推力は `4·fmax − e`、すなわち **RL を回すほど上限が下がる**。最大は `e = 0`（RL も止める）。

| 質量 | 必要 `f/発` | D90S 必要 duty | GEMFAN 必要 duty | GEMFAN 余裕 `rho` |
|---|---|---|---|---|
| 350 g | 0.858 N | **1.268（物理的に不可能）** | 0.979（>0.95 で不可） | **−2.1 %** |
| 383 g | 0.939 N | **1.372（不可能）** | 1.119（不可） | **−11.7 %** |

**GEMFAN でも足りない。** duty 上限 0.95 での 4 発合計は `3.363 N = 343 g` で、質量 350 g に 7 g 足りない。
duty 1.0 まで使い切って `3.484 N = 355 g`、余裕 +0.9 %。**使い物にならない。**

### 3-2. どこまで持っていけば良いか

余裕 `rho` を確保する条件は `fmax ≥ mg / (4(1−rho))`。

| 質量 | `rho = 0 %` | `10 %` | `20 %` |
|---|---|---|---|
| 350 g | 0.858 N | 0.954 N | **1.073 N** |
| 383 g | 0.939 N | 1.044 N | **1.174 N** |
| 320 g | 0.785 N | 0.872 N | 0.981 N |
| 300 g | 0.736 N | 0.818 N | 0.920 N |

GEMFAN の 0.841 N に対し、**350 g で 20 % 余裕を取るには推力を +28 %、383 g なら +40 % 必要。**

逆に GEMFAN（0.841 N）で許される質量:

| 目標余裕 | 許容質量 |
|---|---|
| 0 %（ぎりぎり浮くだけ） | **343 g** |
| 10 % | **309 g** |
| 20 % | **274 g** |

**質量を 76〜109 g 落とすか、推力を 3〜4 割上げるかの二択。**

### 3-3. ただし健全飛行には劇的に効く

| 質量 | D90S ホバー duty | GEMFAN ホバー duty |
|---|---|---|
| 350 g | **0.880** | **0.571** |
| 383 g | **0.956（0.95 の clamp を超える）** | **0.640** |

**383 g・D90S ではホバー duty が duty 上限 0.95 を超えており、健全 6 発でも実質飛べない機体だった。**
GEMFAN 交換で `u_base` が 0.88 → 0.57 に下がる。`Delta u` の上側余裕は `0.95 − u_base` なので
**姿勢制御に使える範囲が 0.07 から 0.38 へ 5 倍以上に増える**。健全飛行の操縦性はこれで大きく変わるはずである。

## 4. relaxed hover が勝てるかは `Cr` だけで決まる

`(phi, theta, Omega)` を `±40° × 0–800 deg/s` で全探索した結果、
**現行の推定値 `Cp = Cq = 0.025, Cr = 0.005` では最適解は常に `Omega = 0`（静的 4 発配分）だった。**
つまりこの係数の下では **relaxed hover の利得はゼロ**である。

ところが `Cr` を振ると結論が反転する（GEMFAN duty 0.95, `m = 350 g`, `Cp=Cq=0.025`）:

| `Cr` | 最良 `rho` | そのときの `Omega` | RL 推力 |
|---|---|---|---|
| 1.0e-4 | **+14.9 %** | 550 deg/s | 大 |
| 2.9e-4 | **+11.1 %** | 320 deg/s | 大 |
| 4.9e-4 | **+8.1 %** | 280 deg/s | **0.773 N** |
| 8.4e-4 | +1.4 % | 220 deg/s | — |
| **1.4e-3 以上** | **−2.1 %** | **0** | **0** |

**境目は `Cr ≈ 1.1e-3`。現行推定値 `0.005` のわずか 4.5 分の 1 の位置にある。**
`Cr` は一度も実測されていないので、**現時点では「relaxed hover が成立するかどうか分からない」が正確な状態**である。

### 有利側のケースの中身（`Cr = 5e-4`, GEMFAN 0.95, `m = 350 g`）

```
rho = +8.1 %   phi = -18 deg   theta = -16 deg   Omega = 280 deg/s
p = +77   q = -83   r = +256 deg/s
f[N] = [FR 0.000, FL 0.772, MR 0.772, ML 0.734, RR 0.704, RL 0.773]   合計 3.756 N (383 g 相当)
```

**合計推力 3.756 N は静的上限 `4×0.841 = 3.363 N` を 12 % 上回っている。**
傾けた分 `cos18°·cos16° = 0.914` を失って鉛直成分は 3.43 N = 350 g でちょうど釣り合う。
**RL が 0.773 N（ほぼ全開）で働いており、狙いどおり「5 発を使う」解になっている。**

⚠ ただし **`|omega|max = 256 deg/s`。現行フェイルセーフの角速度しきい値 300 deg/s の 85 %** を定常で使う。
`Cr` がもっと小さければ `Omega = 550 deg/s` まで上がり、**成功している最中にフェイルセーフが発動する。**
設計が「300 deg/s フェイルセーフとジャイロ範囲は再設計が必要」と書いた点は、数値で裏付けられた。

## 5. v9 で判明した実装上の問題

### FTC の `U_ref` が推力上限を自ら下げていた

現行の故障時 `U_ref` は健全 5 発へ均等に `+u_hover/5` を配る。しかし FR 停止時の 0 トルク最適配分は
**RL を 0 にする 4 発配分**である。v9 では RL が実際に回っていた:

| 区間 | RL 推力 `e` | 0 トルク上限 `4·fmax − e` |
|---|---|---|
| 上限超過後 | 0.239 N | 2.248 N（229 g） |
| 破綻中 | 0.273 N | 2.214 N（226 g） |

**RL を回したことで、ただでさえ足りない上限 2.487 N をさらに 10 % 削っていた。**
`20260904_v9_ftc_ground_takeoff_departure.md` が指摘した「小規模配分器」の必要性が実測で裏付けられた。
ただし**これを直しても 226 → 253 g にしかならず、推力不足そのものは解決しない。**

## 6. 次にやること

### すぐやる

1. **GEMFAN に交換したら、まず健全飛行のみ。** `u_base` が 0.88 → 0.57 に下がるので、
   姿勢の追従・飽和・チャタリングを取り直す。**FR 停止の自由飛行は引き続き No-Go。**
2. **機体質量を実測して確定する。** 350 g なのか 383 g なのかで結論が変わる。
   現在 `nmpc_params.hpp` は `mass = 0.35`。
3. **FTC の `U_ref` を「FR 停止なら RL も 0 へ落とす」配分に直す。** 故障パターン分岐ではなく、
   `eta` と制御効果行列から 0 トルク最大推力配分を解く形にする（`repository_rules §3` に整合）。

### relaxed hover を目指すなら、その前に

4. **`Cp / Cq / Cr` を実測同定する。** 設計の追記どおり、自由減衰 1 本ではなく
   正逆両方向・複数 common duty で既知差動入力を与え `tau_bias + b*omega + C*omega|omega|` を回帰する。
   **`Cr` の 1 桁が可否を決める。ここが決まるまで relaxed hover の実飛行判断はできない。**
5. **`CQ` を測り直す。** v9 では実測ヨー加速度がモータのヨートルクの 3.4 倍あり、
   `CQ = 5.8e-9` は疑わしい。反力トルクを直接測れるベンチがあれば `C_QT` を固定した方が識別性が高い。
6. **フェイルセーフのしきい値とジャイロ範囲を再設計する。** 成立する平衡が 256〜550 deg/s を要求する。
   現行 300 deg/s のままでは、成功しても止められる。

### 推力・質量

7. **20 % 余裕には GEMFAN からさらに +28 %（350 g）／+40 %（383 g）の推力**、
   または **質量 274 g（20 %）／309 g（10 %）**。プロペラ交換だけでは届かない。

⚠ 未解決の持ち越し: `Iz = 3.00e-3` の出所、モータ一次遅れ未モデル化、
duty 指令の 50 Hz チャタリング（[`20260904_duty_chatter_50hz_nullspace.md`](ai/decisions/20260904_duty_chatter_50hz_nullspace.md)）。
チャタリングは実効舵を 1/3 に落とすので、**FTC の余裕評価にも効く。**
