## 2026-10-06 時点のメモ（⚠ 一部誤り）
- 「6 発の duty が同一・100Hz ログ 0 行 → core1 が回っていない疑い」は**誤り**だった。
  core1 は回っていた。同一 duty は雑音ゼロで姿勢が厳密に 0 だから。ログ 0 行は読み出しが loop_us≠0 で行を拾っていたため（仮想時間で常に 0）。
