# モータ一次遅れモデルの導入とシステム同定 — 分析

対象: `Benzen_NMPC`（Pico 2 W / Hexa-X 姿勢 NMPC）
目的: NMPC の予測モデルに**モータ一次遅れ系**を組み込み、時定数 τ、ゲイン K、慣性モーメント I を実験から同定する。
作成日: 2026-06-30

---

## 0. 現状の整理

- 予測モデル `model_f`（`nmpc_model.cpp`）は **入力 u を即時推力として扱う**。
  角加速度は `xdot[2:5] = B_c·u + (慣性 + 空力ダンピング)`、状態は5次元 `x=[φ,θ,p,q,r]`。
- 一方、**シミュレーション側 `nmpc_simulation.py` はプラントとして一次遅れを既に実装済み**（PKG-E1）:
  `u_actual += α(u_target − u_actual)`,  `α = dt/(τ+dt)`,  `tau_motor = 0.05 s`。
  ただしこれは**プラント（真の機体）側**だけで、**NMPC の予測モデルには遅れが入っていない**（モデル化誤差として扱われている）。
- つまり今回の作業は「シミュのプラントに既にある一次遅れを、**NMPC の予測モデル側にも反映**し、その τ・K・I を実機同定値で埋める」こと。

## 1. 一次遅れモデルの定式化

### 1.1 連続時間モデル

各モータ i の実推力（正規化）を状態 $\omega_i$ とし、指令 duty を $u_{c,i}$ とする一次遅れ:

$$
\dot{\omega}_i = \frac{1}{\tau}\,(K\,u_{c,i} - \omega_i), \qquad i = 1\dots 6
$$

- $\tau$: モータ＋ESC＋プロペラ慣性の時定数 [s]（同定対象）
- $K$: 定常ゲイン（指令→実推力）（同定対象）

姿勢ダイナミクスは、**入力 u の代わりに実推力状態 ω** を使う:

$$
\dot{p} = (B_c\,\omega)_p + \frac{-(I_z-I_y)qr - C_p\,p|p|}{I_x}, \quad (\dot q,\dot r \text{ も同様})
$$

> **K の置き方に注意（二重計上の回避）**
> 現状 $B_c$ は `T_max`（duty=1 の推力 [N]）を内部に含む（`B_c[2,k] = -y_k T_max/I_x` …）。
> したがって状態 ω を**正規化推力 (0..1)** で持つなら **K = 1** とし、推力ゲインは引き続き $B_c$ 内の `T_max` が担う。
> 逆に ω を**物理推力 [N]** で持つなら $B_c$ から `T_max` を外し、$K \approx T_{max}$ として K に推力ゲインを担わせる。
> **推奨は前者（ω = 正規化推力, K=1）**：既存 `B_c` を変えずに済み、ADMM の Box 制約 $0\le u_c\le 1$ もそのまま使える。
> K を独立同定したい場合のみ後者を採る。

### 1.2 状態拡張

$$
x = [\,\phi,\ \theta,\ p,\ q,\ r,\ \omega_1,\dots,\omega_6\,]^T \in \mathbb{R}^{11},\qquad
u = u_c \in \mathbb{R}^6
$$

`NX: 5 → 11`、`NU` は 6 のまま。

### 1.3 ヤコビアン（解析）

$A_c = \partial f/\partial x \in \mathbb{R}^{11\times11}$:

- 左上 5×5: 現状の姿勢ブロックをそのまま流用（運動学・慣性・ダンピング）。
- **新規** $A_c[2{:}5,\ 5{:}11] = B_c^{\text{att}}$ … 角加速度が ω に依存する項（＝従来 $B_c$ の姿勢3行 ×6 列）。
- **新規** $A_c[5{:}11,\ 5{:}11] = -\frac{1}{\tau} I_6$ … モータ自己減衰。

$B_c = \partial f/\partial u_c \in \mathbb{R}^{11\times6}$:

- 姿勢行は **0**（指令は姿勢に直接効かない）。
- **新規** $B_c[5{:}11,\ :] = \frac{K}{\tau} I_6$ … 指令がモータ状態に効く。

### 1.4 離散化

Euler（既存 `discretize_euler`）でよい。$dt=0.01,\ \tau=0.05$ なら $dt/\tau=0.2<1$ で安定。
精度を上げるならモータ状態のみ厳密離散化:

$$
\omega_{k+1} = a\,\omega_k + (1-a)K u_{c,k},\quad a=e^{-dt/\tau}\ (\approx 0.819\ \text{vs Euler } 0.8)
$$

## 2. NMPC への影響（重要）

| 項目 | 変化 | コメント |
|---|---|---|
| $S_x$ (NX·N × NX) | 85×5 → 187×11 | TR1 更新対象。約2倍 |
| $S_u$ (NX·N × NU·N) | 85×102 → 187×102 | 約2.2倍（≈76 KB） |
| $\bar Q$ 対角長 | 85 → 187 | ω 状態の重みは 0（または微小）|
| **$H=S_u^T\bar Q S_u+\bar R$** | **102×102 のまま** | **NU 依存なので不変**。Cholesky O(102³) は**増えない** |
| ロールアウト/勾配 | NX_TOTAL 比例で ≈2.2倍 | iter_us の主な増加要因 |

**要点**: 凝縮形は入力 U に縮約するため、最も重い Cholesky の次元は NU で決まり**不変**。状態拡張のコストはロールアウトと $S_u$ 乗算の増分のみ。現状 iter ≈ 7.5 ms に対し **+1〜2 ms 程度**の増加見込み。10 ms 予算が厳しければ `N=17→13〜15` で吸収。

### 2.1 コード変更チェックリスト

- `nmpc_params.hpp`
  - `mpc::NX = 5 → 11`、`NX_TOTAL` 自動更新を確認。
  - `physical::tau_motor`, `physical::K_motor`（=1.0 推奨）を追加。
  - `cost::` に ω 状態の重み（0 か微小値）を追加し、Q ベクトル生成箇所を NX=11 対応に。
- `nmpc_model.cpp`
  - `model_f`: `Bu = B_c*u` → `Bu = B_c*x[5:11]`（実推力）。末尾に `xdot[5+i] = (K*u[i]-x[5+i])/τ`。
  - `model_jacobians`: 上記 1.3 のブロックを追加。
  - `model_B_const`: 役割が変わる。「姿勢×duty」だった行列は、いまや**姿勢×ω**（A の部分ブロック）。命名・用途を見直す。
  - ⚠ **`model_sanity` の `bottomRows<3>()` は破綻する**（姿勢行はもう最下段ではない）。`middleRows<3>(2)`（行2..4）に修正。`B_c·1=0` チェックも姿勢×ω ブロックに対して行う。
- `nmpc.cpp` / `nmpc.hpp`
  - `mpc::NX` 経由で寸法は自動追従するはずだが、`StateVec`/`StateMat` の固定次元参照・`bottomRows`/`segment` 等の**ハードコード添字**を全数確認。
- `control.cpp`
  - `x0` のモータ状態 `x0[5:11]` の与え方（→ 2.2）。
  - 出力は従来どおり `U_opt(0..5)` を `FR_duty..RL_duty` に割当（u_c の先頭ブロック）。

### 2.2 モータ状態の可観測性（要検討）

EKF が出すのは姿勢のみで、**ω はセンサで測れない**（PWM 直接駆動、RPM/ESC テレメtrは無い前提）。対策:

- **(推奨) 内部モデル伝播**: コントローラ内に $\hat\omega$ を持ち、毎周期 $\hat\omega_{k+1}=a\hat\omega_k+(1-a)K\,u_{\text{applied}}$ で更新し、`x0[5:11]=ω̂` とする。τ・K が正確なら補正なしでも追従（安定・高速系のため）。
  - **遅れを予測モデルに入れる本質的利点**：たとえ ω を測れなくても、コントローラが**アクチュエータ遅れを見越して**指令を出せる（位相遅れ補償）。
- ESC テレメトリ（DShot 等）や光学タコメータがあるなら測定値を投入すると更に良い。

### 2.3 より軽量な代替案（比較用に言及）

- 入力レート penalty / move-blocking（遅れの近似、状態拡張不要）。
- Smith 予測器的な遅延補償。
- → ただし**状態拡張が最も素直**で、既存 NMPC コア（NX 依存で自動拡張）を再利用できる。本研究では状態拡張を推奨。

## 3. システム同定の実験計画

実験は**相互干渉を避けるため分離**して行う。順序は ① 静推力 → ② 時定数 → ③ 慣性。

### 3.1 ① 静推力試験 → T_max・ホバー duty・(K)

- 単発モータ＋プロペラをロードセル付き推力スタンドに固定。
- duty を 0→1 で階段状に掃引し、**定常推力 $T(\text{duty})$** を記録。
- 得られるもの: `T_max`（duty=1）、`hover_duty`（= $T_{hover}$ 相当の duty）、線形/非線形性。
  - 多くの小型プロペラで $T \propto \text{duty}$ から外れる（RPM∝duty 近似 → $T\propto \text{RPM}^2$）。必要なら affine か2次で補正。
- K の扱い: ω を正規化推力にするなら K=1（推力ゲインは T_max が担う）。物理推力にするなら $K=T_{max}$。

### 3.2 ② 時定数 τ の同定

**励起入力**: 単発モータに duty ステップ（例 0.3→0.5, 0.5→0.7）と、できれば**チャープ / PRBS**。
**計測**: 推力（ロードセル）または RPM（光学タコ/ESCテレメトリ）を**高レート**で記録。

> ⚠ ログレートに注意。現状ベンチログは **10 Hz** で τ≈50 ms の同定には**全く不足**。
> ≥200〜500 Hz でRAMリングバッファに溜め、後で USB/UDP ダンプする等の改修が必要。
> 代替として外部 DAQ / オシロ + タコメータでもよい。

**フィッティング**（複数法でクロスチェック）:

1. **ステップ 63.2 %**: 最終値の 63.2 % 到達時間 ≒ τ。最も簡便。
2. **離散最小二乗 / ARX(1)**: $\omega_{k+1}=a\,\omega_k+b\,u_k$ を回帰 →
   $\tau=-dt/\ln a$,  定常ゲイン $K=b/(1-a)$。指令と出力の両方が要る。
3. **周波数応答**: チャープ/PRBS から ETFE → Bode。−3 dB コーナー $f_c$ より $\tau=1/(2\pi f_c)$。

**検証**: 学習に使っていないデータで予測 vs 実測（VAF / fit %）を確認。

> 注: 推力 ∝ RPM² の非線形があるため、**B_c に渡す信号（正規化推力）そのものの遅れ**を同定するのが整合的。
> モータ個体差があるので 6 個すべてで取り、代表 τ（平均）と 1〜2 個の検証を推奨。

### 3.3 ③ 慣性モーメント I の同定

- **二線式（bifilar）ねじり振り子**が簡便。機体を平行2本の糸（長さ $L$、間隔 $d$）で吊り、微小ねじり振動の周期 $T_{osc}$ を計測:

  $$
  I = \frac{m\,g\,d^2\,T_{osc}^2}{16\pi^2 L}
  $$

  軸（$I_x, I_y, I_z$）ごとに該当軸を鉛直にして測定。三線式（trifilar）でも可。
- **CAD / 質量分布モデル**で独立に概算しクロスチェック。
- 妥当性目安: 現状 $I_x{=}6.10\!\times\!10^{-3}$, $I_y{=}6.53\!\times\!10^{-3}$, $I_z{=}1.16\!\times\!10^{-2}$（平面ヘキサで $I_z\approx 2I_x$ は妥当）。
- （別法）NMPC を切り、既知の差動推力で既知トルクを与え、ジャイロから角加速度 α を測り $I=\text{torque}/\alpha$。ただしトルクは $B_c$（=T_max・幾何・I 依存）に絡むため、I 単独同定には振り子法が clean。

## 4. 推奨ワークフローと論文への接続

1. **同定実験**: ① 静推力 → ② τ → ③ I を実施し、`nmpc_params.hpp` の `T_max`/`tau_motor`/`Ix,Iy,Iz` を実測値で更新。
2. **予測モデル拡張**: 第2章のチェックリストで NX=11 化（まず sim で検証 → 実機）。
3. **検証**: sim のプラント τ（PKG-E1, 0.05 s）を**同定値に差し替え**、予測モデルにも同 τ を入れて、遅れ補償の有無で姿勢追従/位相遅れを比較。
4. **論文**: 「システム同定」小節として、τ・K・I の同定手順と値、遅れ補償の効果を記載できる。現行 paper.typ の TODO（`N, dt, 重みの小表`、実機パラメータ）を埋める材料になる。

### リスク / 留意点

- iter_us の増加で 100 Hz 予算超過の可能性 → `N` 縮小で調整。
- ω 非可観測のため、τ・K の同定精度がそのまま予測精度に効く（内部モデル伝播のため）。
- 静推力の非線形性が強い場合、B_c の線形 T_max 近似の妥当範囲を明記。
- モータ個体差・電圧依存（バッテリー電圧で τ・K が変わりうる）→ ホバー近傍で同定。
