## 2. 揺れの大きさを実機に合わせる（`calib.py`, `real_vs_sim.py`）
静かなホバーのロール角速度 rms は 実機 7.0–8.6 deg/s に対しシミュ 1.2 deg/s（6〜7 倍の差）。
機体外乱（プロセス雑音）を **10 倍**、ジャイロ雑音を 3 倍にすると p rms 8.6 deg/s・帯域の内訳・指令 du の rms（0.025）まで実機に一致した（`real_vs_sim_bands.png`）。
この「実機並みに揺れるシミュ」で 1 の 8 構成を回し直しても **墜落 0/24、張り付き 0〜1.7 %**（`proc_x10/`）。

## 3. 唯一残った不一致: 指令のスパイク
| | du rms | du の最大 |
|---|---|---|
| 実機 0919_v5 / v6 / v8 | 0.015–0.025 | 0.13 / 0.15 / **0.32** |
| シミュ（揺れを実機に合わせたもの） | 0.025 | 0.11 |
0919_v8 の最大 0.336（t=7.88）は**通常経路**（TR1 棄却でも再構築でもない）で、機体は静か（p,q 数 deg/s）。
4 周期かけて 0.04→0.34 へ育ち、直後のフル再構築（t=7.91）で 0.05 に戻った。
0919_v8 では「最後の再構築からの周期数」が増えるほど指令が大きくなる（p95 0.06→0.15）が、v5/v6 には同じ傾向は無い → **仮説**。

## 結論
物理条件（推力・質量・遅延・再構築停滞・雑音・外乱・貨物・操縦入力・効き 2 倍）はシミュでは単独でも組み合わせても墜落を起こさない。
シミュと実機の差は、シミュが持っていない **制御器の中身**（単精度・Cholesky の rank 更新/ダウンデート・TR1 棄却時に古い Su のまま最大 8 周期走る運用・EKF）と、
**人間の操縦ループ（PIO）**、**地上からの離陸**にあると見られる。
